演習 03 — enp0s18 を nmcli で DHCP につなぐ                           影響度 B / 目安 10分

  練習機（linuc）の中で作業します（外で ssh linuc）。システム全体を触ります。

【いまの状態を見てください】

    nmcli device status
    nmcli connection show

  NetworkManager が持っている NIC は enp0s18 だけです（ほかは unmanaged）。
  enp0s18 は disconnected で、接続（プロファイル）は1つもありません。

【やること】

  nmcli で enp0s18 の接続を作り（名前は lab-dhcp を勧めます）、有効にしてください。
  アドレスは DHCP で借ります。このネットワーク（10.0.4.0/24）には DHCP サーバがいます。
  再起動したあとも自動でつながるようにしてください（nmcli で作った接続は、既定でそうなります）。

  判定では、nmcli で enp0s18 の状態（connected か）と接続の設定（ipv4.method / autoconnect）を聞き、
  ip で DHCP で借りたアドレス（dynamic）が付いているかを見ます。

【できたら】
