演習 04 — デフォルトルートを正しいルータに直す                        影響度 B / 目安 12分

  練習機（linuc）の中で作業します（外で ssh linuc）。システム全体を触ります。
  経路を壊しても ssh は切れません（管理用の NIC は 10.0.2.0/24 に直接つながっているため）。

【いまの状態を見てください】

    ping -c 3 172.16.20.10
    ip route

  社内のサーバ 172.16.20.10 に ping が届きません。
  返事をしているのは誰でしょうか（From の後ろを読んでください）。

  ネットワーク担当から聞いた社内のルータは 192.168.10.1 です。
  192.168.10.254 は撤去予定の古いルータで、もうどこにもつながっていません。

【やること】

  デフォルトルートを 192.168.10.1 に直してください。
  ifdown / ifup や再起動のあとも 192.168.10.1 のままになるようにしてください
  （いまのデフォルトルートを入れているのは ifupdown です。cat /etc/network/interfaces）。

  判定では、経路表・判定の中での ping 172.16.20.10・ifupdown が読む lab0 の設定（ifquery lab0）を見ます。
