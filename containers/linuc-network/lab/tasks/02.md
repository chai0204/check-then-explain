演習 02 — enp0s17 を ifupdown に持たせる                            影響度 B / 目安 12分

  練習機（linuc）の中で作業します（外で ssh linuc）。システム全体を触ります。
  先に演習 01 を終わらせてください。手で付けた 10.0.3.50/24 が残っている状態から始めます。

【いまの状態を見てください】

    cat /etc/network/interfaces
    ifquery --list
    ifquery --state
    ip -4 addr show enp0s17

  ifupdown（ifup / ifdown）は、lo と lab0 は知っていますが、enp0s17 のことは知りません。
  演習 01 で付けたアドレスは、どのファイルにも書かれていないので、再起動すると消えます。

【やること】

  enp0s17 の設定（10.0.3.50/24）を ifupdown の設定ファイルに書き、ifup で上げてください。
  起動のたびに自動で上がる（auto）ようにしてください。

  判定では次の3つを見ます。

      ifquery --state enp0s17   ifupdown が「自分で上げた」と記録しているか
      ifquery --list            起動時に上げる NIC の一覧に enp0s17 が入っているか
      ip -4 addr show enp0s17   10.0.3.50/24 が実際に付いているか

【詰まったら】

  ifup がエラーで止まることがあります。メッセージを1行ずつ読んでください。
  ifdown が「not configured」と言うのに、アドレスが残っていることもあります。
  どちらも ifupdown が「何を見て」動いているかが分かると解けます。
