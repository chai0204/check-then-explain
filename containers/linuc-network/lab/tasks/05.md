演習 05 — 掲示板を外から見えるようにする                              影響度 B / 目安 10分

  練習機（linuc）の中で作業します（外で ssh linuc）。システム全体を触ります。
  練習機では「社内掲示板」（lab-board.service）という小さな Web サーバが 8080/tcp で動いています。

【いまの状態を見てください】

    curl http://127.0.0.1:8080/
    curl http://192.168.10.2:8080/
    sudo ss -tlnp

  同じ練習機の中から同じ 8080 番に聞いているのに、片方だけ断られます。
  社内 LAN のほかの機械（ここでは router）からも試せます。

    sudo ip netns exec router curl http://192.168.10.2:8080/

  （ip netns exec router … は「router という別の機械の中で … を打つ」という意味です。第5章を参照）

【やること】

  router から http://192.168.10.2:8080/ で掲示板が見えるようにしてください。
  判定では、router から実際に取りに行きます。

【できたら】

    lab check 05
