演習 01 — enp0s17 にアドレスを手で付ける                          影響度 B / 目安 10分

  この演習は練習機（linuc）の中で作業します。外の端末で ssh linuc と打って入ってください。
  システム全体を触ります。最初からやり直すときは、外で vm reset --yes（練習機ごと工場出荷時に戻る）。

【いまの状態を見てください】

    ip link show enp0s17
    ifconfig | grep '^[a-z]'
    ifconfig -a | grep '^[a-z]'

  enp0s17 は ifconfig の一覧に出てきません。-a を付けると出てきます。何が違うのでしょうか。

【やること】

  enp0s17 を上げ（up）、10.0.3.50/24 を付けてください。
  このネットワーク（10.0.3.0/24）には 10.0.3.2 という相手がいます。そこへ ping が届けば完成です。

      ping -c 2 10.0.3.2

  設定ファイルには書かなくて構いません（手で付けるだけ。ファイルに書くのは演習 02）。
  ip でも ifconfig でも構いません。両方で付けてみて、ifconfig と ip addr の表示を比べてください。
