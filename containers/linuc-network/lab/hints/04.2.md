    sudo ip route del default
    sudo ip route add default via <ルータ>

    sudo route del default gw <古いルータ>
    sudo route add default gw <ルータ>

これで ping は通ります。ただし判定は通りません。試してください。

    sudo ifdown lab0
    sudo ifup lab0
    ip route show default

ifup は /etc/network/interfaces の gateway の行を読んで、デフォルトルートを入れ直します。
