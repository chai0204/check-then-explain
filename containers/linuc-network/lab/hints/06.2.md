/etc/resolv.conf に nameserver の行を足すと、一度は引けるようになります。
でも systemd-resolved を再起動すると消えます。試してください。

    echo 'nameserver 172.16.20.10' | sudo tee -a /etc/resolv.conf
    host server.lab.example
    sudo systemctl restart systemd-resolved
    cat /etc/resolv.conf

書き込んだ先は /etc/resolv.conf ではなく、リンクの先の
/run/systemd/resolve/stub-resolv.conf で、systemd-resolved が作り直すファイルだからです。

残す方法は2つあります。

    A. リンクをやめて、ふつうのファイルにする（古典的な方法。試験の書き方）
    B. systemd-resolved に「中継の先」を教える（resolvectl / resolved.conf）
