ほぼ答えです。設定ファイルの gateway を直し、ifupdown に読み直させます。

    sudo sed -i 's/gateway 192.168.10.254/gateway 192.168.10.1/' /etc/network/interfaces
    ifquery lab0                 … gateway: 192.168.10.1
    sudo ifdown lab0
    sudo ifup lab0
    ip route show default        … default via 192.168.10.1 dev lab0 onlink
    ping -c 2 172.16.20.10

ifdown で「RTNETLINK answers: No such process」と出ることがあります。
ifdown が消そうとしたデフォルトルート（ファイルに書かれていた方）が、もう無かったという意味です。
