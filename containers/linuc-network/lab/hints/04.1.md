経路表は「宛先ごとに、次に誰へ渡すか」の表です。

    ip route
    #=> default via 192.168.10.254 dev lab0 onlink
    #   192.168.10.0/24 dev lab0 …

宛先 172.16.20.10 に当てはまる行は default（0.0.0.0/0）だけです。
カーネルがどの行を選んだかは、これで聞けます。

    ip route get 172.16.20.10

ping の From が 192.168.10.254 なのは、パケットを渡された古いルータが「その先へは行けない」と
ICMP で言い返しているからです（Destination Net Unreachable）。
