ここで1つ足して、ifconfig と見比べてください。

    sudo ip addr add 10.0.3.51/24 dev enp0s17
    ip -4 addr show enp0s17       … 2つ出る
    ifconfig enp0s17              … 1つしか出ない

足した 10.0.3.51 は消しておいてください（判定には関係しません）。

    sudo ip addr del 10.0.3.51/24 dev enp0s17
