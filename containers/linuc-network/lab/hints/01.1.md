NIC には状態が2つあります。

    リンクが上がっているか   ip link show enp0s17 の <...UP...> と state UP / DOWN
    アドレスが付いているか   ip addr show enp0s17 の inet の行

いまの enp0s17 は、どちらも無い状態です。

ifconfig は、上がっていない NIC を一覧に出しません（-a を付けると出す）。
「ifconfig に出てこない＝NIC が無い」ではありません。

まず上げるコマンドを man で探してください。

    man ip-link | grep -n ' up'
