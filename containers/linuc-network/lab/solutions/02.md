設定を書いてから ifup します。途中で2つ断られます。どちらも理由は同じで、
ifupdown は NIC の実際の状態ではなく「設定ファイル」と「自分の記録」だけを見て動いているからです。

    printf 'auto enp0s17\niface enp0s17 inet static\n    address 10.0.3.50/24\n' | sudo tee /etc/network/interfaces.d/enp0s17
    ifquery --list
    #=> lo / enp0s17 / lab0        ← auto と書いたので、起動時に上げる一覧に入った
    ifquery enp0s17
    #=> address: 10.0.3.50 / broadcast: 10.0.3.255 / netmask: 255.255.255.0

【断られる1つ目 — ifup】

    sudo ifup enp0s17
    #=> Error: ipv4: Address already assigned.
    #   ifup: failed to bring up enp0s17

  ifup は設定ファイルに書かれたとおりに ip addr add … を実行します。
  演習 01 で手で付けたアドレスがもうあるので、そこで失敗しました。

【断られる2つ目 — ifdown】

    sudo ifdown enp0s17
    #=> ifdown: interface enp0s17 not configured
    ip -4 addr show enp0s17
    #=> inet 10.0.3.50/24 ...      ← 残っている

  ifdown は「ifupdown が上げた NIC」しか下げません。記録はここにあります。

    ifquery --state
    #=> lab0=lab0 / lo=lo          ← enp0s17 は無い（/run/network/ifstate）

【手で付けたものを手で外して、ifup し直す】

    sudo ip addr flush dev enp0s17
    sudo ifup enp0s17
    ifquery --state
    #=> enp0s17=enp0s17 / lab0=lab0 / lo=lo
    ip -4 addr show enp0s17
    #=> inet 10.0.3.50/24 brd 10.0.3.255 scope global enp0s17

  こんどは ifdown も効きます。下げるとリンクも落ち、アドレスも消えます。

    sudo ifdown enp0s17
    sudo ifup enp0s17

【起動時】

  networking.service が ifup -a を実行し、auto と書かれた NIC を上げます。
  だから再起動しても enp0s17 に 10.0.3.50/24 が付きます。

【書き方の要点（試験に出る形）】

    auto enp0s17                    起動時に上げる（ifup -a の対象）
    iface enp0s17 inet static       IPv4 を固定で
        address 10.0.3.50/24
        gateway 10.0.3.2            （デフォルトルートが要るときだけ。ここでは書かない）
    iface enp0s17 inet dhcp         DHCP にするならこう書く。ifupdown は DHCP を自分ではせず、
                                    外の DHCP クライアント（dhclient など。この練習機では dhcpcd）を起動する

【RHEL 系では ifcfg ファイル（試験には両方の形が出ます）】

  ifup / ifdown は RHEL 系にもあります。読む設定ファイルが違い、RHEL 8 までは
  /etc/sysconfig/network-scripts/ifcfg-<NIC の名前> に、1つの NIC を1つのファイルで書きます。
  （この練習機は Ubuntu なので、このファイルはありません。）

    Debian 系（/etc/network/interfaces）   RHEL 系（ifcfg-enp0s17）
    auto enp0s17                          ONBOOT=yes
    iface enp0s17 inet static             BOOTPROTO=none（static とも書く）
    iface enp0s17 inet dhcp               BOOTPROTO=dhcp
    address 10.0.3.50/24                  IPADDR=10.0.3.50 と PREFIX=24（または NETMASK=255.255.255.0）
    gateway 10.0.3.2                      GATEWAY=10.0.3.2（全体の既定は /etc/sysconfig/network にも書ける）
