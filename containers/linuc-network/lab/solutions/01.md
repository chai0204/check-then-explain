リンクを上げて、アドレスを足します。ip では2つのコマンドです。

    sudo ip link set enp0s17 up
    ip addr show enp0s17
    #=> state UP。IPv4 はまだ無いが、inet6 fe80::5054:ff:fe12:3457/64 がもう付いている

    sudo ip addr add 10.0.3.50/24 dev enp0s17
    ip -4 addr show enp0s17
    #=> inet 10.0.3.50/24 scope global enp0s17

    ping -c 2 10.0.3.2
    #=> 64 bytes from 10.0.3.2: icmp_seq=1 ttl=255 ...

  10.0.3.2 は同じネットワーク（10.0.3.0/24）にいるので、ルータを通らずに直接届きます。

【ifconfig で同じことをする】

    sudo ifconfig enp0s17 10.0.3.50 netmask 255.255.255.0

  ifconfig はアドレスを付けるとリンクも上げます。

【ip addr add は「足す」、ifconfig は「置き換える」】

    sudo ip addr add 10.0.3.51/24 dev enp0s17
    ip -4 addr show enp0s17
    #=> inet 10.0.3.50/24 scope global enp0s17
    #   inet 10.0.3.51/24 scope global secondary enp0s17

    ifconfig enp0s17
    #=> inet 10.0.3.50  netmask 255.255.255.0  broadcast 0.0.0.0   ← 1つしか出ない

  ifconfig は1つの名前（enp0s17）につき1つのアドレスしか表示しません（古い窓口 ioctl で聞くため）。
  ラベルの無い2つ目（secondary）は ifconfig からは見えません。
  ラベルを付けて足すと（ip addr add 10.0.3.52/24 dev enp0s17 label enp0s17:1）、enp0s17:1 という名前で見えます。

    sudo ifconfig enp0s17 10.0.3.60 netmask 255.255.255.0
    ip -4 addr show enp0s17
    #=> inet 10.0.3.60/24 brd 10.0.3.255 ...   ← 10.0.3.50 も 10.0.3.51 も消えた

  ifconfig でアドレスを付けると、元のアドレスと入れ替わります。
  元のアドレスが消えると、同じネットワークの secondary も一緒に消えます（この練習機＝Ubuntu の既定で、
  sysctl net.ipv4.conf.enp0s17.promote_secondaries が 0。RHEL 9 などの既定の 1 なら、secondary が繰り上がって残ります）。
  判定の前に 10.0.3.50 に戻してください。

    sudo ifconfig enp0s17 10.0.3.50 netmask 255.255.255.0

【broadcast 0.0.0.0】

  ip addr add で brd を指定しないと、ブロードキャストアドレスは付きません（ifconfig に 0.0.0.0 と出る）。
  ifconfig や ifupdown で付けると 10.0.3.255 が自動で付きます。付けたいなら:

    sudo ip addr add 10.0.3.50/24 brd + dev enp0s17

【この設定は再起動で消える】

  手で付けたものはどのファイルにも残っていません。残す方法が演習 02（ifupdown）と演習 03（nmcli）です。
