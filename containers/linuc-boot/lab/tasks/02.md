演習 02 — RSA の鍵で、パスワードなしで入れるようにする          影響度 B / 目安 12分

  外（lab@host）で打ちます。練習機が起動している必要があります（演習 01）。

【いまの状態を見てください】

    ls -la ~/.ssh
    ssh linuc            # 初回はホスト鍵の確認（yes）と、パスワード（student）を聞かれる

  外の lab には鍵が1つもありません。だから ssh はパスワードで入ります。
  入れたら exit で戻ってください。

【やること】

  試験の出題範囲が名指ししている名前の鍵ペアを、外の lab に作ってください。

      ~/.ssh/id_rsa        秘密鍵
      ~/.ssh/id_rsa.pub    公開鍵

  その公開鍵を練習機の student に登録して、パスワードを打たずに入れるようにしてください。

  判定では、パスワードでの認証を禁じた ssh を実際に1回打ち、
  id_rsa だけで入れるかを確かめます。

【できたら】

    lab check 02
