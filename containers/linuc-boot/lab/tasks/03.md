演習 03 — 次の1回だけ、CUI のターゲットで起動する                影響度 B / 目安 15分

  練習機を再起動して、GRUB のメニューでカーネル引数を足します。
  端末を2つ用意してください（docker exec -it lab-linuc-boot bash -l を2回）。

      端末1（外）: virsh console linuc     … 練習機の画面。抜けるのは Ctrl+]
      端末2（外）: ssh linuc sudo reboot   … 再起動の合図を送る

【いまの状態を見てください】

    ssh linuc systemctl get-default
    ssh linuc cat /proc/cmdline

  既定のターゲットは graphical.target（GUI 用）です。この練習機に GUI は入っていません。

【やること】

  設定ファイルは何も変えずに、次の1回の起動だけ multi-user.target で起動してください。
  GRUB のメニューが出ているのは 10 秒です。矢印キーを1回押すと、数え下げが止まります。

  判定では次の2つを確かめます。

      いま動いているカーネルが受け取った引数に、起動ターゲットの指定がある
      multi-user.target が active で、graphical.target が inactive

【できたら】

    lab check 03

  GRUB のメニューを見逃したら、もう一度 ssh linuc sudo reboot（または外で virsh reboot linuc）。
