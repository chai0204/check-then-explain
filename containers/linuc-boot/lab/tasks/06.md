演習 06 — TERM を無視するプロセスを止める                        影響度 B / 目安 12分

  練習機の中（student@linuc）で打ちます。

【いまの状態を見てください】

    ps -ef | grep lab-hog
    pstree -p | grep lab-hog

  student の権限で lab-hog というプロセスが動いています。
  起動のたびに systemd が立ち上げる「居座るプロセス」です。

【やること】

  lab-hog を、シグナルを送って止めてください。
  まず普通に kill を打ってみて、何が起きるか（起きないか）を ps で確かめてから進めてください。

  判定では、systemd が記録した lab-hog の終わり方（何で止まったか）を確かめます。

【できたら】

    lab check 06

  もう一度やりたいときは  sudo systemctl start lab-hog  で戻せます（再起動でも戻ります）。
