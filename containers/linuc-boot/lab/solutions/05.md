【予約はどこにあるか】

  予約を持っているのは systemd-logind です。

    busctl get-property org.freedesktop.login1 /org/freedesktop/login1 \
      org.freedesktop.login1.Manager ScheduledShutdown
    #=> (st) "poweroff" 17918…        ← 種類と、止める時刻（1970年からのマイクロ秒）

    cat /run/systemd/shutdown/scheduled
    #=> USEC=… / MODE=poweroff / WALL_MESSAGE=…   ← 文は \xe3\x83… の形で保存されている

  -h は Ubuntu（systemd）では「電源を切る」（poweroff）です。電源を切らずに止めるのは -H（halt）、再起動は -r。

【時刻の書き方】

    shutdown -h now        すぐ
    shutdown -h +30        30 分後
    shutdown -h 23:00      23 時に
    shutdown -h            時刻を書かないと 1 分後（すぐには止まらない）

【知らせはいつ届くか】

  時刻を書かない shutdown（1分後）では、他の端末にすぐ Broadcast message が届きました。
  +30 では、予約した瞬間には届きませんでした（logind は残り時間に応じて間を置いて知らせる）。
  取り消すと「System shutdown has been cancelled」がすぐ届きます。
  残り 5 分を切ると /run/nologin が作られ、一般ユーザは新しくログインできなくなります。
