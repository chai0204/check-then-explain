【set-default がしたこと】

  /etc/systemd/system/default.target というシンボリックリンクを作っただけです。
  既定は /usr/lib/systemd/system/default.target（→ graphical.target）にもありますが、/etc の方が優先されます。

    ls -l /etc/systemd/system/default.target /usr/lib/systemd/system/default.target

  リンクを書き換えても、いま動いている状態（graphical.target まで来ている）は変わりません。
  効くのは次の起動からです。いまの状態だけを変えるのは isolate で、こちらは再起動すると元に戻ります。

    sudo systemctl isolate multi-user.target     # いまだけ。再起動すると既定に戻る
    sudo systemctl set-default multi-user.target # 次の起動から。いまは変わらない

【元に戻す】

    sudo systemctl set-default graphical.target
