  端末1（外）:  virsh console linuc
  端末2（外）:  ssh linuc sudo reboot

  端末1 に GRUB が出たら:
    1. ↑ を1回押して数え下げを止める（Ubuntu が選ばれたまま）
    2. e を押す
    3. ↓ を 10 回押して linux から始まる行へ
    4. Ctrl+E で行末へ行き、空白を1つ空けて 3 と打つ
    5. Ctrl+X で起動

  起動したら確かめます。

    ssh linuc cat /proc/cmdline                          # 最後に 3 が付いている
    ssh linuc systemctl is-active graphical.target multi-user.target
    #=> inactive
    #   active
