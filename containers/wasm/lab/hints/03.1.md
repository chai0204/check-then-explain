`(data ...)` は「モジュールが読み込まれた時点でメモリのこの位置にこのバイト列を置く」
という宣言です。実行時にコピーする命令を書く必要はありません。

長さは自分で数えます。`"hello wasm"` は空白も1バイトなので10です。
**WASM 側はこの 10 という数を知りません。** あなたが `i32.const` で書いた定数です。

Node 側の3段は、それぞれ1行で書けます。

    const p = instance.exports.ptr();
    const bytes = new Uint8Array(instance.exports.mem.buffer, p, instance.exports.len());
    console.log(new TextDecoder().decode(bytes));

`new Uint8Array(buffer, 開始, 長さ)` は、**バッファをコピーせずに窓を開ける**書き方です。
第2・第3引数を省略すると全体（65536バイト）が見えます。試してみると、
文字列の後ろに何が入っているか分かります。

`instantiate` の第2引数は、import が無いモジュールでも `{}` を渡します。
