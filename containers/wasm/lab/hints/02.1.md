import は `(module` の直後、関数定義より**前**に書きます。順番を入れ替えると
wat2wasm が「import は先に書け」という趣旨のエラーを出します。

    (module
      (import "env" "log" (func $log (param i32)))
      (func (export "run")
        ...))

`$log` の `$` はローカルな名前（ラベル）で、バイナリには残りません。
`call $log` で呼びます。

`(param i32)` だけで `(result ...)` を書かなければ「何も返さない関数」になります。

Node 側の import は**2段の入れ物**です。外側のキーが import 文の第1引数（モジュール名）、
内側のキーが第2引数（関数名）に対応します。

    { env: { log: ... } }
      ^^^     ^^^
      "env"   "log"

例外を捕まえるには try / catch を使います。エラーの種類の名前は
`e.constructor.name` で取れます。

wasmtime 側の出力をファイルに残すときは標準エラー出力もリダイレクトしてください。
