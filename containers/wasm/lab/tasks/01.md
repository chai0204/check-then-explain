【やること】

  1. add.wat という名前で、次の仕様を満たすモジュールを書いてください。

       ・i32 を2つ受け取り、足した i32 を返す
       ・関数を "add" という名前で export する

     WAT（WebAssembly Text Format）は S式です。形はこうなります。

       (module
         (func (export "名前") (param 型 型) (result 型)
           ここに命令を並べる))

     使う命令は3つだけです。
       local.get 0    1つめの引数をスタックに載せる
       local.get 1    2つめの引数をスタックに載せる
       i32.add        スタックから2つ取り、足した結果を載せる

  2. これを .wasm にコンパイルしてください。

       wat2wasm add.wat -o add.wasm

  3. できたファイルのサイズを見てください。それから中身を全部表示してください。

       ls -l add.wasm
       xxd add.wasm

     右側の ASCII 列に、読める文字がいくつか見えます。何が見えますか。

  4. 実行してください。

       wasmtime run --invoke add add.wasm 3 4

     警告が2行出ますが、これは正常です（後述の理由があります）。

  5. **文字列を返す関数を書こうとしてください。** 次を str.wat として保存し、
     コンパイルを試してください。

       (module
         (func (export "greet") (result string)
           unreachable))

     何が起きましたか。メッセージは observed.txt に残します
     （wat2wasm のエラーは標準エラー出力に出るので 2>&1 が必要）。

       wat2wasm str.wat -o str.wasm > observed.txt 2>&1
       cat observed.txt
