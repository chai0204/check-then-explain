演習 03 — 数値2つで文字列を渡す                                     影響度 A / 目安 12分

  ~/work/03 で作業します。

【やること】

  1. mem.wat を書いてください。仕様は4つです。

       ・1ページの線形メモリを持ち、"mem" という名前で export する
       ・そのメモリのオフセット 0 に文字列 "hello wasm" を置く
       ・"ptr" という関数を export し、その文字列の開始位置を返す
       ・"len" という関数を export し、その文字列の長さ（バイト数）を返す

     書き方の部品:

       (memory (export "mem") 1)          1ページのメモリを export する
       (data (i32.const 0) "文字列")       メモリの指定位置に初期データを置く
       (func (export "名前") (result i32)  i32 を返す関数
         i32.const 数値)                   定数を返すだけの本体

  2. コンパイルして、2つの関数を呼んでください。

       wasmtime run --invoke ptr mem.wasm
       wasmtime run --invoke len mem.wasm

     何が返りましたか。それは文字列でしたか。

  3. read.mjs を作り、Node 側で文字列に組み立ててください。
     やることは3段です。

       ・ptr() と len() を呼んで2つの数値を得る
       ・instance.exports.mem.buffer から、その範囲のバイト列を取り出す
         （new Uint8Array(buffer, 開始, 長さ) が使えます）
       ・TextDecoder でデコードして表示する

     あわせて、**メモリの実体が何バイトあるか**も表示してください。
     mem.buffer.byteLength で分かります。

  4. wasm-objdump で、文字列がバイナリのどこに入っているか確認してください。

       wasm-objdump -x mem.wasm

     Data セクションの出力に注目してください。
