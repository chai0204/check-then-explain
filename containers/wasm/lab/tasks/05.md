演習 05 — 実行する前に調べる                                        影響度 A / 目安 12分

  ~/work/05 に mystery.wasm というファイルが置いてあります。
  どこかから配布されてきた .wasm だと思ってください。中身は教えません。

  **この演習では、最後まで実行しないでください。** 調べるだけです。

【やること】

  次の4つを調べて、~/work/05/answers.txt に書いてください。
  形式は自由ですが、後から自分で読み返せるようにしてください。

  1. このモジュールは **何を import しているか**。
     モジュール名と関数名の組をすべて挙げてください。

  2. このモジュールは **何を export しているか**。

  3. メモリに **初期データとして何が置かれているか**。
     読める文字列があれば、それも書いてください。

  4. 上の3つから、**このモジュールは何をしようとしているか** を推測してください。
     そして、**ホストが import を1つも渡さなかったら何ができるか** を書いてください。

  使う道具は1つだけです。

      wasm-objdump -x mystery.wasm

  Import / Export / Data の3つのセクションに注目してください。

【最後に】

  調べ終わったら、import を何も渡さずに実行してみてください。
  推測した「何をしようとしているか」は、実際に起きましたか。

      wasmtime run mystery.wasm

  この結果も answers.txt に追記してください。
