【やること】

  1. imp.wat という名前で、次の仕様のモジュールを書いてください。

       ・"env" の "log" という名前の関数を import する（i32 を1つ受け取り、何も返さない）
       ・"run" という名前で export する関数を1つ持つ
       ・run は 42 を log に渡して呼ぶ

     import の書き方はこうです。

       (import "モジュール名" "関数名" (func $ローカル名 (param 型)))

     呼び出しは call です。

       i32.const 42
       call $ローカル名

  2. wat2wasm でコンパイルしてください。

  3. **まず wasmtime で実行してみてください。**

       wasmtime run --invoke run imp.wasm

     何が起きましたか。メッセージは observed.txt に残します
     （wasmtime のエラーは標準エラー出力に出るので 2>&1 が必要）。

       wasmtime run --invoke run imp.wasm > observed.txt 2>&1
       cat observed.txt

  4. 次に Node から実行します。host.mjs を作り、import を渡して呼んでください。
     骨格はこうです。ホストが渡す関数の中身は自分で決めてください。

       import { readFile } from "node:fs/promises";
       const bytes = await readFile("imp.wasm");
       const { instance } = await WebAssembly.instantiate(bytes, {
         env: { log: (n) => /* ここでホスト側の処理をする */ },
       });
       instance.exports.run();

     実行は node host.mjs です。
     ホスト側で受け取った値（42）が、何らかの形で画面に出るようにしてください。

  5. **import を渡さない版も作ってください。** ファイル名は ng.mjs にします。
     env を空のオブジェクト {} にして instantiate し、例外を捕まえて
     エラーの名前とメッセージを表示してください。
     こちらは catch で捕まえて console.log するので標準出力に出ます。追記します。

       node ng.mjs >> observed.txt 2>&1
       cat observed.txt

     observed.txt には **2回分**（wasmtime の拒否と、Node の LinkError）が残ります。
