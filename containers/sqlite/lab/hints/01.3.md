形はこうなります。テーブル定義とデータは自分で埋めてください。

    cd ~/work/01
    sqlite3 notes.db 'CREATE TABLE ... ; INSERT INTO ... ;'

確認の3コマンドは、どれも sqlite3 を使いません。**普通のファイルとして調べます。**

    ls -l notes.db
    file notes.db
    xxd -l 16 notes.db

xxd の右側の列（ASCII 表示）に注目してください。読める文字が出ます。

サーバを探すほうは、ps -ef の結果を grep で絞ります。
「見つからない」が答えになる場合もあります。
