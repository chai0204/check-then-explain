2000行の SQL を手で書く必要はありません。標準入力から流し込めます。

    sqlite3 naive.db < ファイル
    何かで生成 | sqlite3 naive.db

シェルで連番を作るなら `seq` が使えます。
`seq 1 3` は 1 / 2 / 3 を1行ずつ出します。

これを INSERT 文に変えるのは `sed` が短く書けます。`&` はマッチした行全体を指します。

    seq 1 3 | sed 's/.*/INSERT INTO a VALUES(&);/'

トランザクションで囲む側は、流し込む SQL の**先頭に BEGIN; を、末尾に COMMIT; を足す**だけです。
`{ echo ...; seq ... | sed ...; echo ...; }` のように波括弧でまとめると1本のパイプに流せます。

時間の測り方は2通りあります。

    time （コマンド）                 ← シェル組み込み。`real` の行を読む
    /usr/bin/time -f %e （コマンド）  ← 秒数だけが出る（このコンテナには入っています）

記録するのは `real`（実際に経過した時間）です。`user` や `sys` ではありません。
**なぜ user ではなく real を見るのかは、この演習の答えそのもの**なので考えてみてください。
