SQL は1回の呼び出しで複数文を渡せます。セミコロンで区切ってください。

    sqlite3 t.db 'CREATE TABLE ...; INSERT INTO ...; SELECT ...;'

`typeof()` は SQLite の組み込み関数で、**宣言された型ではなく、実際に格納された値の型**を返します。
返る文字列は integer / text / real / blob / null のどれかです。

STRICT の書き方は、閉じ括弧の**後ろ**です。

    CREATE TABLE tight(n INTEGER) STRICT;

エラーメッセージをファイルに残すときは、標準エラー出力もリダイレクトしてください。

    sqlite3 t.db '...' 2> observed.txt
