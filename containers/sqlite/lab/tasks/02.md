演習 02 — 型に嘘をつかせる                                          影響度 A / 目安 10分

  ~/work/02 で作業します。DB 名は t.db にしてください。

【やること】

  1. 次のテーブルを作ってください。

       loose(n INTEGER)

  2. この列に、順番に3つ入れてください。

       42        （数値）
       'abc'     （文字列）
       '123'     （数字に見える文字列）

     3つとも通りますか。エラーが出るものはありますか。

  3. 何が格納されたかを typeof() で確かめてください。

       SELECT n, typeof(n) FROM loose;

     3行の typeof は全部同じでしょうか。違うなら、どれが違いますか。

  4. 次に、同じ定義に STRICT を付けたテーブルを作ってください。

       tight(n INTEGER) STRICT

  5. tight に 'abc' を入れてみてください。何が起きますか。
     出たメッセージを ~/work/02/observed.txt に貼り付けてください。

  ・入るとして、それは何型として保存されるか
  ・'123' と 'abc' で扱いが違うか
  ・STRICT を付けると何が変わるか
