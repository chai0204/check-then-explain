演習 05 — ログを切って3世代だけ残す                                影響度 B / 目安 12分

  この演習はシステム全体を触ります。作業場所は /etc/logrotate.d です。
  先に演習 03 を終わらせてください（/var/log/lab-app.log が要ります）。

【いまの状態を見てください】

    grep -vE '^\s*#|^\s*$' /etc/logrotate.conf
    ls /etc/logrotate.d/
    cat /etc/logrotate.d/rsyslog

【やること】

  /var/log/lab-app.log を切る設定を書いてください。条件は4つです。

      1k を超えたら切る
      3世代だけ残す
      切ったものは圧縮する
      切った後に rsyslog へ HUP を送る

  そのうえで、実際に切れた状態（**/var/log/lab-app.log.1.gz** が在る状態）に
  してください。

  ログを太らせるには、こうすれば足ります。

      for i in $(seq 1 60); do logger -p local3.info "かさ増し $i"; done

【詰まったら】

  logrotate は「何もせずに終わる」ことがあります。そのときは -d を付けて
  何を考えているかを読んでください。黙って失敗はしません。

      logrotate -d /etc/logrotate.d/lab-app

  エラーが出ているのに終了コードが 0 になることがあります。
  「成功したのに切れない」と思ったら、メッセージを1行ずつ読んでください。
  引っかかるところは2つあり、どちらも権限の話です
  （podman で入った場合は、シェルの umask が違うので1つ目には当たりません）。

【できたら】
