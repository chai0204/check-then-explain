演習 02 — chrony に基準を与えて同期させる                          影響度 B / 目安 12分

  この演習はシステム全体を触ります。作業場所は /etc/chrony です。

【いまの状態を見てください】

    chronyc sources
    chronyc tracking

  chronyd は動いています（systemctl is-active chrony）。
  それでも時刻は同期していません。Leap status を見てください。

【やること】

  この檻の中には、もう1台 chronyd が立っています。

    systemctl is-active lab-ntp-server
    ss -lun | grep :123

  このサーバを基準として使うようにクライアント側を設定し、
  chronyc tracking が次の2つを出す状態にしてください。

      Reference ID    : 7F000001 (localhost)
      Leap status     : Normal

【注意】

  この檻には時計を動かす権限（CAP_SYS_TIME）がありません。
  chronyd は「ずれを測る」ところまでやりますが、時計そのものは動かしません。
  それでも同期状態にはなります。なぜそうなるかを考えてください。

【できたら】

    lab check 02
