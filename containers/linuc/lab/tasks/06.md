演習 06 — メールを2回曲げて、ログで追う                            影響度 B / 目安 15分

  この演習はシステム全体を触ります。作業場所は /etc と /home です。
  alice と bob というユーザが用意してあります（id alice / id bob）。

【いまの状態を見てください】

    echo "本文です" | mail -s "最初の1通" alice
    ls -l /var/mail/
    cat /var/mail/alice

  alice に送ったものが alice に届きます。ここまでは当たり前です。

【やること】

  alice 宛に送ったメールが、最終的に **root のメールボックス**に入るように
  してください。ただし曲げ方は2段にします。

      1段目: alice 宛を bob 宛にする   → システム全体の設定で
      2段目: bob 宛を root 宛にする    → bob 本人の設定で

  2つの段で使うファイルは別の場所にあります。どちらも試験範囲です。

  仕上げに、2回曲がったことがログに残っているのを確かめてください。

      journalctl -t postfix/local -n 5

  `orig_to=` と `to=` の2つが別の名前になっている行が出ます。

【詰まったら】

  配送されない・曲がらないときは、postfix が理由をログに書いています。
  推測せずに読んでください。

      journalctl -t postfix/local -n 20

【できたら】
