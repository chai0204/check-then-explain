使うディレクティブは4つです。

    size 1k        … このサイズを超えたら切る（weekly / daily と排他）
    rotate 3       … 3世代残す
    compress       … 切ったものを gzip する
    postrotate … endscript  … 切った後に走らせるコマンド

通常の実行は「切る条件を満たしていなければ何もしない」ので、
`-v` を付けて何をしたかを出させてください。

    logrotate -v /etc/logrotate.d/lab-app

ここで **何も起きない／エラーが出るのに終了コードは 0** という状態になります。
logrotate は黙って失敗しません。出ているメッセージを1行ずつ読んでください。
原因は2つあり、どちらも「権限」の話です。
