ほぼ答えです。

    # 1段目
    echo 'alice: bob' >> /etc/aliases
    newaliases

    # 2段目
    echo 'root' > /home/bob/.forward
    chown bob:bob /home/bob/.forward
    chmod 644 /home/bob/.forward        # ← docker で入った場合はここが要点

docker exec で入ったシェルは umask が 0000 なので、`>` で作った .forward は 0666 になります。
その場合、最後の chmod を忘れると、postfix は .forward を**読みません**。
読まなかったことはログに書いてあります。

    journalctl -t postfix/local | grep forward
    #=> warning: file /home/bob/.forward is world writable

podman exec で入った場合は umask が 0022 なので、最初から 0644 で作られ、この警告は出ません。
どちらで入っても、chmod 644 を打っておけば同じ状態になります（自分の値は `umask` で確かめられます）。
