演習 09 — labapp を yum で入れ、挨拶を「こんにちは」に変える         影響度 B / 目安 10分

  この演習はシステム全体を触ります（パッケージを入れ、/etc の設定ファイルを書き換えます）。
  作業ディレクトリは使いません。

【いまの状態】

    $ labapp
    bash: labapp: command not found

  labapp はまだ入っていないので、これが始まりの正しい状態です。
  （第9章を同じ檻で打って入れて消したあとなら、
    bash: /usr/bin/labapp: No such file or directory
   と出ることもあります。どちらも「いまは入っていない」という意味です）

【やること】

  1. パッケージ labapp を yum で入れて、labapp コマンドを使えるようにする
  2. labapp が出す挨拶を hello から こんにちは に変える

      labapp   →   liblab: こんにちは from labapp 1.0   と出れば完成

  挨拶は labapp の設定ファイルに書いてあります。設定ファイルの場所は教えません。
  rpm の台帳に聞いて見つけてください。/usr/bin/labapp は書き換えないでください。
  設定ファイルは root しか書けないので、主題1.03 で使った vi か sed に sudo を付けて書き換えます
  （sudo vi ファイル、または sudo sed -i 's/前/後/' ファイル）。

【判定のしかた】

  labapp を動かして、上の1行が出るかを見ます。
  あわせて、labapp と、labapp が必要とする liblab が、yum でリポジトリ lab から入っていること
  （yum list installed の右端が @lab）と、rpm の台帳に記録された「入れたときの中身」と比べて、
  設定ファイル以外のファイルが入れたときのままであることを見ます。

【できたら】

    lab check 09
