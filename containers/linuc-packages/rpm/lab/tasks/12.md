演習 12 — labtool を yumdownloader で取り、rpm で入れる               影響度 B / 目安 12分

  作業ディレクトリは ~/work/12 です。

【いまの状態】

    $ cd ~/work/12
    $ ls
    $ labtool
    bash: labtool: command not found

  ~/work/12 は空で、labtool はまだ入っていません。これが始まりの正しい状態です。
  （第11章を同じ檻で打って入れて消したあとなら、
    bash: /usr/bin/labtool: No such file or directory
   と出ることもあります。どちらも「いまは入っていない」という意味です）

  インターネットにつながらないサーバに入れる、という想定です。
  つながっている側で .rpm ファイルを取ってきて、運び込んでから rpm で入れます。
  （ここでは同じ檻の中で、取る作業と入れる作業の両方をします）

【やること】

  1. labtool の .rpm を ~/work/12 に取ってくる（yum install は使わない）
  2. それを rpm コマンドで入れて、labtool コマンドが動く状態にする

【判定のしかた】

  次の3つを確かめます。

      ~/work/12 に labtool と、labtool が必要とするパッケージの .rpm がある
      （ファイルの中身を rpm -qp で確かめます）
      labtool と、labtool が必要とするパッケージが、rpm の台帳にある
      どちらも yum ではなく、rpm で入っている
      （rpm の台帳の「入れた時刻」を、yum の取引の記録と比べて見分けます）

【できたら】

    lab check 12
