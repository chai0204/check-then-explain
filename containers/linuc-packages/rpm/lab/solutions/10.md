リポジトリの登録 → ファイル名から探す → 署名を確かめて入れる、の3段です。

    sudo tee /etc/yum.repos.d/lab-tools.repo <<'END'
    [lab-tools]
    name=lab tools
    baseurl=file:///srv/lab-tools-rpm
    gpgcheck=1
    gpgkey=file:///srv/lab-tools-rpm/RPM-GPG-KEY-lab-tools
    END
    yum repolist                     # lab-tools が並べば読めている

    yum provides '*/labcalc'         # ファイル名からパッケージを探す（入っていなくてよい）
    #=> lab-mathtools-1.0-1.noarch : small number utilities for the lab
    #   Repo        : lab-tools

    sudo yum install lab-mathtools
    #=> Importing GPG key 0x…:
    #    Userid     : "lab tools <tools@example.invalid>"
    #    From       : /srv/lab-tools-rpm/RPM-GPG-KEY-lab-tools

    #   Key imported successfully

    labcalc 2 3
    #=> 5
    yum list installed lab-mathtools
    #=> lab-mathtools.noarch   1.0-1   @lab-tools    ← どのリポジトリから入ったか
    rpm -q gpg-pubkey --qf '%{SUMMARY}\n'
    #=> … lab tools <tools@example.invalid> public key

【目録を取り直すコマンドを打たなくてよかった理由】

  yum（dnf）は、目録を持っていないリポジトリや、目録の期限（metadata_expire）が
  切れたリポジトリがあると、コマンドを打った時点で自分で目録を取りに行きます。
  apt は apt update を打つまで取りに行きません。

  名前が似ていますが、yum update は apt update にあたりません。
  yum update は入っているパッケージを上げるもので、apt upgrade にあたります。

    yum makecache       目録を取り直す（apt update にあたる）
    yum check-update    更新できるものがあるかを確かめる（あれば終了コード 100）
    yum update          入っているパッケージを上げる（apt upgrade にあたる）

【gpgkey を書かずに gpgcheck=1 だと】

  Public key for lab-mathtools-1.0-1.noarch.rpm is not installed
  … Error: GPG check FAILED

  yum は署名を確かめるための鍵を持っていないので、入れるのを断ります。
  gpgcheck=0 にすれば入りますが、それは「誰が作ったか確かめずに入れる」ことです。
  演習の判定は、リポジトリの設定が gpgcheck=1 のままかと、lab tools の鍵が
  lab-mathtools より先に rpm の台帳に入ったかで、それを見分けています。

【gpgcheck=0 で入れてしまったら】

  あとから sudo rpm --import で鍵だけ取り込んでも、判定は通りません。
  入れたときに署名を確かめていないことは、変わらないからです。
  .repo を gpgcheck=1 と gpgkey= の形に直してから、入れ直します。

    sudo yum reinstall lab-mathtools      # 鍵がまだなら、取り込んでよいかを尋ねられる → y

【.repo の主な項目】

    [repo id]          リポジトリの名前（yum repolist に出る。@ 付きで yum list installed にも出る）
    name=              説明
    baseurl=           場所（http:// https:// file://）
    mirrorlist=        場所の一覧を返す URL（baseurl の代わり）
    enabled=1|0        使うかどうか
    gpgcheck=1|0       パッケージの署名を確かめるか
    gpgkey=            署名を確かめる公開鍵の場所
    metadata_expire=   目録をいつ取り直すか（秒。-1 なら取り直さない）

【別解: ファイルを1行で書く】

  第10章のヒアドキュメントの代わりに、printf で行を並べて tee に渡しても、同じファイルができます。

    printf '%s\n' '[lab-tools]' 'name=lab tools' 'baseurl=file:///srv/lab-tools-rpm' \
      'gpgcheck=1' 'gpgkey=file:///srv/lab-tools-rpm/RPM-GPG-KEY-lab-tools' \
      | sudo tee /etc/yum.repos.d/lab-tools.repo
