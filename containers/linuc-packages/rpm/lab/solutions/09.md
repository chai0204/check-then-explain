yum で入れ、rpm の台帳から設定ファイルの場所を引いて書き換えます。

    sudo yum install labapp
    #=> Installing:
    #    labapp     noarch   1.0-1   lab   7.3 k
    #   Installing dependencies:
    #    liblab     noarch   1.0-1   lab   6.7 k     ← 依存関係で一緒に入る
    #   Is this ok [y/N]: y
    labapp
    #=> liblab: hello from labapp 1.0

    rpm -qc labapp                  # 設定ファイルだけを出す（-ql なら全部）
    #=> /etc/labapp.conf
    cat /etc/labapp.conf
    #=> # labapp の設定ファイル（rpm が %config として管理する）
    #   greeting="hello"
    sudo sed -i 's/^greeting="hello"$/greeting="こんにちは"/' /etc/labapp.conf
    labapp
    #=> liblab: こんにちは from labapp 1.0

    yum list installed labapp liblab
    #=> labapp.noarch   1.0-1   @lab
    #   liblab.noarch   1.0-1   @lab   ← @lab は「リポジトリ lab から yum で入った」

【rpm に聞く向き】

    rpm -ql パッケージ名     パッケージ → それが置いたファイル（-qc は設定ファイルだけ、-qd は文書だけ）
    rpm -qf ファイルのパス   ファイル → それを置いたパッケージ

  Debian 系の dpkg -L と dpkg -S にあたります。どちらも rpm の台帳（/var/lib/rpm）を読んでいます。
