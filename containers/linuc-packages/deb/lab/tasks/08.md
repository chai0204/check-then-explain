演習 08 — 配られたスクリプトを、自分でパッケージにして入れる        影響度 B / 目安 15分

  作業ファイルは ~/work/08 にあります。

【いまの状態】

    $ cd ~/work/08
    $ ls
    labmine.sh
    $ cat labmine.sh
    #!/bin/sh
    # labmine - liblab の lab_greet を使って1行出す（演習08 で、あなたがパッケージにするスクリプト）
    . /usr/lib/liblab/liblab.sh
    lab_greet "自分で作ったパッケージから入りました"
    $ sh labmine.sh
    labmine.sh: 3: .: cannot open /usr/lib/liblab/liblab.sh: No such file

  sh labmine.sh は、ファイルを sh（シェル）に読ませて動かす打ち方です。
  1行目の #!/bin/sh は、第8章で見た「sh に読ませて動かす」という印です。
  labmine.sh は、パッケージ liblab が置くファイル /usr/lib/liblab/liblab.sh を読み込みます。
  liblab はまだ入っていないので、このエラーが出るのが始まりの正しい状態です。

【やること】

  labmine.sh を /usr/bin/labmine として置くパッケージを作り、入れてください。

      パッケージの名前   labmine
      版                 1.0
      依存関係           liblab（labmine は liblab が無いと動かないので、パッケージの情報に書く）

  liblab を apt install liblab で先に入れるのではなく、labmine を入れるときに
  依存関係から一緒に入るようにしてください。

      labmine   →   liblab: 自分で作ったパッケージから入りました   と出れば完成

【判定のしかた】

  dpkg の台帳で、labmine が版 1.0 で ii になっていること、依存関係に liblab が書かれていること、
  /usr/bin/labmine が labmine のファイルとして載っていて、持ち主が root であることを見ます。
  liblab には、依存関係から一緒に入ったときにだけ付く「自動で入った」印（第5章の
  apt-mark showauto）が付いているかを見ます。
  そして labmine を実際に動かし、上の1行が出るかを見ます。
