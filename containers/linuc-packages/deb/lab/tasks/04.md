演習 04 — 見つからなくなった labbackup を、パッケージから戻す        影響度 B / 目安 10分

  この演習はシステム全体を触ります（/usr/bin にファイルを戻します）。作業ディレクトリは使いません。

【いまの状態】

    $ labbackup
    bash: labbackup: command not found
    $ dpkg -l labbackup | tail -1
    ii  labbackup      1.0          all          practice backup command

  コマンドは見つからないのに、台帳は「入っていて、使える状態（ii）」と言っています。
  これが始まりの正しい状態です（誰かが、パッケージを通さずにファイルだけを消してしまった、
  という想定です）。

【やること】

  1. 台帳と照らし合わせて、labbackup のどのファイルが、どうなっているかを確かめる
  2. labbackup を、パッケージから入れたときの状態に戻す

  消して入れ直すのではなく、入ったまま元に戻すコマンドを使ってください。

【判定のしかた】

  labbackup を動かして、1行のメッセージが出るかを見ます。
  あわせて、台帳との照らし合わせ（dpkg -V labbackup）が何も出さないこと、
  つまり labbackup のファイルが全部、台帳の記録どおりであることを見ます。

【できたら】

    lab check 04
