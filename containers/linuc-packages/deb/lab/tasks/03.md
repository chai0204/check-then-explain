演習 03 — labsvc の設定ファイルを探して、ポートを 9090 に変える      影響度 B / 目安 10分

  この演習はシステム全体を触ります（/etc の設定ファイルを書き換えます）。作業ディレクトリは使いません。

【いまの状態】

    $ labsvc
    labsvc: 動いています
    port=8080

  labsvc は、設定ファイルに書かれたポート番号を読んで表示する練習用の道具です
  （ポート番号は、通信の相手のプログラムを見分けるための番号。
   labsvc は表示するだけで、本当には待ち受けません）。

【やること】

  labsvc が port=9090 と表示するように、labsvc の設定ファイルを書き換えてください。

  設定ファイルの場所は教えません。labsvc というコマンドがどのパッケージから来たのか、
  そのパッケージがどこにファイルを置いたのかを調べて、見つけてください。
  書き換えるのは設定ファイルだけです。/usr/bin/labsvc は書き換えないでください。

  設定ファイルは root しか書けません。主題1.03 で使った vi か sed に sudo を付けて
  書き換えてください（sudo vi ファイル、または sudo sed -i 's/前/後/' ファイル）。

【判定のしかた】

  labsvc を動かして、port=9090 と出るかを見ます。
  あわせて、パッケージの台帳に記録された「入れたときの中身」と比べて、
  設定ファイル以外のファイルが入れたときのままかを見ます。
