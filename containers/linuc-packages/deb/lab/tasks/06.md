演習 06 — labcalc コマンドを使えるようにする                          影響度 B / 目安 15分

  この演習はシステム全体を触ります（apt のソースと dpkg の台帳）。作業ディレクトリは使いません。

【いまの状態】

    $ labcalc 2 3
    bash: labcalc: command not found
    $ find /srv/lab-tools -maxdepth 3
    /srv/lab-tools
    /srv/lab-tools/dists
    /srv/lab-tools/dists/tools
    /srv/lab-tools/dists/tools/main
    /srv/lab-tools/dists/tools/Release
    /srv/lab-tools/pool
    /srv/lab-tools/pool/main
    /srv/lab-tools/pool/main/l

  labcalc はまだ入っていないので、command not found が出るのが始まりの正しい状態です。
  （find は、指定したディレクトリの下にあるものを並べるコマンドで、-maxdepth 3 は「3段下まで」という指定です）

  /srv/lab-tools に、apt のリポジトリが1つ置いてあります。
  まだ apt のソース（どこからパッケージを取るかの表）には入っていません。

  この中のどれかのパッケージに、labcalc というコマンドが入っています。
  パッケージの名前は教えません。説明文にも labcalc という語は出てきません
  （つまり apt search では見つかりません）。

【やること】

  labcalc コマンドを使えるようにしてください。

      labcalc 2 3     →   5 と出れば使えている

【判定のしかた】

  次の3つを確かめます。

      labcalc がコマンドとして見つかり、2 と 3 を渡すと 5 を返す
      labcalc が dpkg の台帳にあるパッケージから入っている（手で置いたファイルではない）
      そのパッケージを、apt が /srv/lab-tools から入れられる状態になっている

【できたら】

    lab check 06
