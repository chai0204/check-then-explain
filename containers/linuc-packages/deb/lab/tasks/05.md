演習 05 — labweb を、跡形なく消す                                   影響度 B / 目安 10分

  この演習はシステム全体を触ります（dpkg の台帳と /etc）。作業ディレクトリは使いません。

【いまの状態】

    $ apt list --installed 'labweb*'
    Listing... Done
    labweb-data/lab,now 1.0 all [installed,automatic]
    labweb/lab,now 1.0 all [installed]

  labweb と labweb-data の2つが入っています。
  自分で名指しして入れたのは labweb だけで、labweb-data は labweb を入れたときに
  「必要だから」と一緒に入ってきたもの（automatic の印）です。
  設定ファイル /etc/labweb.conf もあります。

【やること】

  labweb を、このシステムから跡形なく消してください。
  次の3つがそろえば完了です。

      labweb が dpkg の台帳に残っていない（rc の行も残っていない）
      /etc/labweb.conf が無い
      labweb のために入ってきた labweb-data も消えている

  labweb-data は名前を打たずに消してください。
  「もう誰にも必要とされていない」ことを apt に判断させるのが、この演習の半分です。

【判定のしかた】

  dpkg の台帳で labweb と labweb-data の行を見ます（rc で残っていても未達）。
  あわせて、/etc/labweb.conf があるかを見ます。

【できたら】

    lab check 05
