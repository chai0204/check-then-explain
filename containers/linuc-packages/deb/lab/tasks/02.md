演習 02 — 仕事に要らない遊びのパッケージを、見つけて消す            影響度 B / 目安 8分

  この演習はシステム全体を触ります（パッケージを消します）。作業ディレクトリは使いません。

【いまの状態】

  このサーバ（檻）には、lab で始まる名前の練習用パッケージがいくつか入っています。

    $ apt list --installed 'lab*'
    Listing... Done
    labbackup/lab,now 1.0 all [installed]
    labfortune/lab,now 1.0 all [installed]
    labsvc-common/lab,now 1.0 all [installed,automatic]
    labsvc/lab,now 1.0 all [installed]
    labweb-data/lab,now 1.0 all [installed,automatic]
    labweb/lab,now 1.0 all [installed]

【やること】

  このうち1つは、仕事のサーバには要らない遊び（ゲーム）のパッケージです。
  パッケージの分類（Section）が games になっています。
  それを見つけて消してください。ほかのパッケージは消さないでください。

  名前や説明文の印象で決めずに、分類を1つずつ確かめてください。

【判定のしかた】

  dpkg の台帳で、分類が games のパッケージがもう入っていないことと、
  ほかのパッケージが入ったままであることを見ます。
  未達のときも、どれが games かは判定の出力には出しません。

【できたら】
