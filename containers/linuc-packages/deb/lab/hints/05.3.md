ほぼ答えです（第5章と同じ2つのコマンドです）。

    sudo apt purge labweb
    sudo apt autoremove

すでに apt remove をしたあとでも、purge はできます（rc の行が消えます）。

【別解（理論編には出てこない書き方）】

    sudo apt purge --autoremove labweb    # purge と autoremove を1回で

sudo apt autoremove labweb のように autoremove に名前を渡すと、labweb-data は消えますが、
labweb は remove と同じ消し方なので rc が残ります。そのときは続けて purge してください。
