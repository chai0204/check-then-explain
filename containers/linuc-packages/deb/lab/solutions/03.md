コマンド → パッケージ → ファイルの一覧、の順にたどります。

    which labsvc
    #=> /usr/bin/labsvc
    dpkg -S /usr/bin/labsvc         # このファイルを置いたパッケージ
    #=> labsvc: /usr/bin/labsvc
    dpkg -L labsvc                  # labsvc が置いたファイルの一覧
    #=> /.
    #   /etc
    #   /etc/labsvc.conf            ← /etc の下にあるのが設定ファイル
    #   /usr
    #   /usr/bin
    #   /usr/bin/labsvc
    cat /etc/labsvc.conf
    #=> # labsvc の設定ファイル（dpkg が conffile として管理する）
    #   port=8080

    sudo sed -i 's/^port=8080$/port=9090/' /etc/labsvc.conf
    labsvc
    #=> labsvc: 動いています
    #   port=9090

【dpkg -S と dpkg -L は向きが逆】

    dpkg -S ファイルのパス   ファイル → それを置いたパッケージ
    dpkg -L パッケージ名     パッケージ → それが置いたファイルの一覧

  どちらも、パッケージを入れたときに dpkg が書いた記録（台帳）を読んでいます。

【dpkg -s の Conffiles 欄】

  dpkg -s labsvc の Conffiles: の欄にも /etc/labsvc.conf が出ます。
  パッケージを作った人が「利用者が書き換える設定ファイル」として印を付けたファイルで、
  書き換えてかまいません。判定はこの印を見て、設定ファイルの書き換えは違いに数えず、
  /usr/bin/labsvc のようなプログラムのほうが書き換わっていないかだけを見ています。
