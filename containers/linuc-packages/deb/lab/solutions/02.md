3つの帳簿を順に使います。apt のソース（どこから取るか）→ 目録（何があるか）→ 台帳（何が入ったか）。

    find /srv/lab-tools -maxdepth 3
    #=> /srv/lab-tools/dists/tools/main  … ディストリビューション tools、コンポーネント main

    echo 'deb [trusted=yes] file:/srv/lab-tools tools main' | sudo tee /etc/apt/sources.list.d/lab-tools.list
    sudo apt update            # 目録（Packages と Contents）を取りに行く
    #=> Get:… file:/srv/lab-tools tools/main amd64 Packages
    #   Get:… file:/srv/lab-tools tools/main amd64 Contents (deb)

    apt-file search labcalc    # Contents（どのファイルがどのパッケージにあるか）を引く
    #=> lab-mathtools: /usr/bin/labcalc

    sudo apt install lab-mathtools
    labcalc 2 3
    #=> 5

【なぜ apt search では見つからないのか】

  apt search（= apt-cache search）が読むのは目録の Packages で、
  そこにあるのはパッケージ名と説明文だけです。
  「どのファイルが入っているか」は Packages には無く、Contents という別の目録にあります。
  それを読むのが apt-file です。

    apt-file search labcalc    # ファイル名 → パッケージ（入っていなくてよい）
    apt-file list lab-mathtools # パッケージ → ファイル一覧（入っていなくてよい）
    dpkg -S /usr/bin/labcalc   # ファイル名 → パッケージ（入っているものだけ）
    dpkg -L lab-mathtools      # パッケージ → ファイル一覧（入っているものだけ）

【行を書いただけで入らない理由】

  sources.list は「どこから取るか」の表で、目録そのものではありません。
  apt が読むのは /var/lib/apt/lists/ に取ってきた目録の写しです。
  写しを作り直すのが apt update で、それまでは新しいリポジトリの中身を知りません。

    ls /var/lib/apt/lists/ | grep lab-tools
