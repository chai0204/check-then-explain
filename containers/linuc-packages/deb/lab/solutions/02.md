入っているものを並べ、1つずつ分類（Section）を確かめてから消します。

    apt list --installed 'lab*'        # 入っている lab* を並べる（dpkg -l 'lab*' でもよい）
    dpkg -s labbackup | grep Section   #=> Section: admin
    dpkg -s labfortune | grep Section  #=> Section: games    ← これ
    dpkg -s labsvc | grep Section      #=> Section: admin
    dpkg -s labsvc-common | grep Section  #=> Section: admin
    …（labweb・labweb-data も同じように確かめる）

    sudo apt remove labfortune
    apt list --installed 'lab*'
    #=> labbackup/lab,now 1.0 all [installed]
    #   labsvc-common/lab,now 1.0 all [installed,automatic]
    #   labsvc/lab,now 1.0 all [installed]

【調べるコマンドの使い分け】

    dpkg -l                 入っているものの一覧（ii の行が入っているもの）。80 桁の端末では less で開く
    dpkg -l 'lab*'          名前でしぼった一覧
    apt list --installed    入っているものの一覧（apt の書き方）
    dpkg -s 名前            1つのパッケージの詳しい情報（Status・Section・Version・Depends など）
    apt show 名前           同じく詳しい情報。どこから入ったか（APT-Sources）も出る

  どれも、パッケージを入れたときに書かれた記録（台帳）を読んでいるだけで、
  パッケージを動かしてみてはいません。

【説明文だけで決めない理由】

  labfortune の説明文は「prints a fortune for the day」（今日の運勢を出す）で、
  遊びかどうかは読み手しだいです。分類（Section）は、パッケージを作った人が
  決めて書いた欄なので、迷わず見分けられます。
