中身の木と DEBIAN/control を並べて .deb にし、apt にファイルとして渡します。

    cd ~/work/08
    mkdir -p labmine/usr/bin labmine/DEBIAN
    cp labmine.sh labmine/usr/bin/labmine
    chmod 755 labmine/usr/bin/labmine
    cat > labmine/DEBIAN/control <<'END'
    Package: labmine
    Version: 1.0
    Architecture: all
    Maintainer: lab <lab@example.invalid>
    Depends: liblab
    Description: my script packaged by hand
    END
    dpkg-deb --build --root-owner-group labmine .
    #=> dpkg-deb: building package 'labmine' in './labmine_1.0_all.deb'.
    dpkg -I labmine_1.0_all.deb          # 情報（Depends: liblab が入っているか）
    dpkg -c labmine_1.0_all.deb          # 中身（./usr/bin/labmine が root/root か）

    sudo apt install ./labmine_1.0_all.deb
    #=> The following additional packages will be installed:
    #     liblab                         ← 依存関係を読んで、目録から取ってくる
    labmine
    #=> liblab: 自分で作ったパッケージから入りました

【--root-owner-group を付ける理由】

  付けないと、パッケージの中のファイルは、作った人（lab）の持ち物として記録されます。
  それを入れると /usr/bin/labmine の持ち主が lab になり、一般ユーザが
  システムのコマンドを書き換えられる状態になります。dpkg -c で root/root と出ることを確かめてから入れます。

【dpkg -i で入れた場合】

    sudo dpkg -i labmine_1.0_all.deb     # liblab が無いので iU（展開済み・設定前）で止まる
    sudo apt --fix-broken install        # 足りない liblab を目録から取ってきて、続きを済ませる

  これでも通ります（第7章と同じ流れ）。

【名前・版・アーキテクチャ】

  dpkg-deb --build の2つ目にディレクトリ（ここでは .）を渡すと、control の
  Package・Version・Architecture から「名前_版_アーキテクチャ.deb」という名前で作ります。
