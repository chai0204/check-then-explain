sudo を付けて apt install します。

    sudo apt install labhello
    #=> The following NEW packages will be installed:
    #     labhello
    #   ...
    #   Unpacking labhello (1.0) ...
    #   Setting up labhello (1.0) ...
    labhello
    #=> labhello 1.0

【出力の読み方】

  The following NEW packages will be installed:   これから新しく入れるもの
  Get:1 file:/srv/lab-repo lab/main ...            リポジトリ（パッケージの配り場所）から取ってきた
  Unpacking labhello (1.0) ...                     中身（ファイル）を置いた
  Setting up labhello (1.0) ...                    使える状態に整えた

【sudo が要る理由】

  パッケージを入れると、/usr/bin/labhello のように、システム全体で使う場所に
  ファイルが置かれ、何を入れたかの記録も書き換わります。どちらも root しか書けません。
  sudo を付けないと「are you root?」と断られます。

【消すときは】

    sudo apt remove labhello

  消したあと、同じシェルで labhello と打つと
  「bash: /usr/bin/labhello: No such file or directory」と出ます。
  bash が一度見つけた場所を覚えているためで、hash -r で忘れさせると
  「command not found」に戻ります（第1章）。
