消すには3段あります。

    sudo apt remove labsvc        # 中身を消す。設定ファイルと、自動で入った依存は残る
    dpkg -l 'labsvc*'
    #=> rc  labsvc         1.0  ...   ← 設定ファイルだけ残っている
    #   ii  labsvc-common  1.0  ...   ← 一緒に入ってきたものは残る
    ls -l /etc/labsvc.conf
    #=> まだ在る

    sudo apt purge labsvc         # 設定ファイルも消す（rc の行が消える）
    sudo apt autoremove           # 自動で入って、もう誰にも必要とされていないものを消す

    dpkg -l 'labsvc*'
    #=> dpkg-query: no packages found matching labsvc*

【なぜ remove で設定ファイルが残るのか】

  /etc/labsvc.conf は、パッケージの中で「conffile」として印が付いています
  （dpkg -s labsvc の Conffiles: 欄）。利用者が書き換えるはずのファイルなので、
  dpkg は「中身を消す」ときに残します。入れ直したとき、書き換えた設定が戻ってくるように。
  台帳には rc（消したい／設定ファイルだけ残っている）と記録されます。

  rc が残るのは、labsvc のように conffile を持つパッケージだけです。
  conffile を持たないパッケージ（labsvc-common など）は、remove の時点で台帳から行ごと消えます。

【labsvc-common はなぜ残ったのか】

  apt は dpkg の台帳とは別に、自分の帳簿を持っています。
  「どれを利用者が名指しで入れ、どれを依存のために自分が入れたか」です。

    apt-mark showauto      # 自動で入った印
    apt-mark showmanual    # 名指しで入れた印

  labsvc を消すと、labsvc-common は「自動で入った・もう誰も依存していない」になります。
  それを片付けるのが autoremove です。remove の時点で apt がそう教えてくれています。

    The following package was automatically installed and is no longer required:
      labsvc-common
    Use 'sudo apt autoremove' to remove it.

【対応表】

    apt remove PKG          dpkg -r PKG     中身を消す（conffile があれば残って rc。無ければ台帳から消える）
    apt purge PKG           dpkg -P PKG     設定ファイルも消す
    apt remove --purge PKG                  purge と同じ
    apt autoremove                          自動で入って不要になったものを消す
    apt autoremove PKG                      PKG を remove し、不要になった自動の依存も消す
                                            （PKG の conffile は残って rc。この演習では purge が要る）
