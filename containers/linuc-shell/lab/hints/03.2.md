先頭行を #!/bin/bash に直したら、置き場所へコピーします。

    sudo cp greet /usr/local/bin/greet
    ls -l /usr/local/bin/greet

所有者と権限は ls -l の左側で読めます。直すコマンドは2つです。

    sudo chown root:root /usr/local/bin/greet
    sudo chmod 755 /usr/local/bin/greet

スクリプトには r（読み）と x（実行）の両方が要ります。
x だけ（711）にすると、alice は Permission denied になります。
実行するのは bash で、bash がファイルを読めないからです。

alice として試すには:

    sudo -iu alice greet
