ほぼ答えです。

    #!/bin/bash
    if [ $# -eq 0 ]; then
        echo "使い方: isuser.sh ユーザ名" >&2
        exit 2
    fi
    if grep -q "^$1:" /etc/passwd; then
        echo "居ます: $1"
        exit 0
    else
        echo "居ません: $1"
        exit 1
    fi

grep の検索語の末尾にある : を消すと、la で lab に当たって 0 になります。
/etc/passwd の1行は「ユーザ名:x:UID:…」なので、: までを含めて探すと名前の完全一致になります。
