残りは PATH です。スクリプトの中の date と id は、実行した人の PATH で探されます。
試しに、date という名前の偽物を先頭に置いた人として実行してみます。

    mkdir -p /tmp/fake
    printf '#!/bin/sh\necho 偽物\n' > /tmp/fake/date
    chmod 755 /tmp/fake/date
    sudo -u alice env PATH=/tmp/fake:/usr/local/bin:/usr/bin:/bin greet

スクリプトの先頭で PATH を決めてしまえば、使う人の PATH に左右されません。
2行目（#! の次）に足してください。

    PATH=/usr/bin:/bin
