bob には ~/.bash_profile があります。だから ~/.profile は読まれません。
~/.profile の先頭のコメントにも、そう書いてあります。

    sudo head -3 /home/bob/.profile
    #=> # ~/.profile: executed by the command interpreter for login shells.
    #   # This file is not read by bash(1), if ~/.bash_profile or ~/.bash_login
    #   # exists.

~/.bashrc は「対話シェルが起動するたび」に読まれるファイルです。
ここに書くと、bash と打って開いた子のシェルでも出てしまいます。
