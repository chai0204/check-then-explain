ほぼ答えです。bob の ~/.bash_profile の末尾に1行足します。

    echo 'echo "ようこそ bob さん"' | sudo tee -a /home/bob/.bash_profile
    sudo -iu bob          # 出るか確かめる
    bash                  # 子のシェル。ここでは出ないはず
    exit
    exit

tee -a は「ファイルの末尾に足す」です（-a が無いと上書きになります）。
sudo echo ... >> file と書くと失敗します。>> を処理するのは sudo ではなく、
いまのあなたのシェル（lab の権限）だからです。
