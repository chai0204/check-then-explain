read を while の条件に置き、読んだ値を case で分けます。

（下の塊は、画面から写して貼り付けられるように、行頭に空白を入れていません）
cat > menu.sh <<'EOF'
#!/bin/bash
echo "1) ユーザ名  2) ホスト名  q) 終了"
while read -r ans; do
    case "$ans" in
        1) id -un ;;
        2) hostname ;;
        q) echo "終了します"; exit 0 ;;
        *) echo "1・2・q のどれかを入力してください" ;;
    esac
done
EOF

    printf '1\n2\nx\nq\n' | bash menu.sh; echo "終了ステータス $?"
    #=> 1) ユーザ名  2) ホスト名  q) 終了
    #   lab
    #   linuc
    #   1・2・q のどれかを入力してください
    #   終了します
    #   終了ステータス 0

【while read の止まり方】

  read は1行読めたら 0、入力が終わったら 1 を返します。
  while は条件のコマンドが 0 の間だけ回るので、Ctrl-D で自然に止まります。
  while true; do read …; done と書くと、入力が終わっても read が失敗し続けるだけで、
  ループは止まりません。

【case の読み方】

    case 値 in
        パターン1) コマンド ;;
        パターン2|パターン3) コマンド ;;     ← | で「または」
        *) コマンド ;;                       ← どれにも当たらなかったもの
    esac

  パターンにはファイル名と同じワイルドカードが使えます（[yY]* は y か Y で始まるもの）。
  上から比べて、最初に当たった1つだけを実行します。

【Linux を知らない人に渡すなら】

  このスクリプトを /usr/local/bin に root 所有・755 で置き（演習03）、
  先頭で PATH を決めておけば、使う人は番号しか打たずに済みます。
  ログインシェルそのものをこのメニューにする運用もあります（chsh -s）。
