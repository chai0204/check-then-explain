演習 05 — 成功と失敗を、終了ステータスで返すスクリプト               影響度 A / 目安 12分

【いまの状態を見てください】

    cd ~/work/05
    cat isuser.sh
    bash isuser.sh lab;        echo "終了ステータス $?"
    bash isuser.sh nosuchuser; echo "終了ステータス $?"

  居ないユーザを調べても、終了ステータスが 0（成功）になっています。

【やること】

  isuser.sh が、結果を**終了ステータスで**返すように直してください。

      ユーザが /etc/passwd に居る      → 0
      居ない                            → 1
      引数が無い                        → 2

  こう使えるようになるのが目的です。

      bash isuser.sh alice && echo "alice は居る"

  画面に何を表示するかは自由です（表示しなくても構いません）。

【判定のしかた】

  isuser.sh を lab / nosuchuser / la / 引数なし の4通りで実際に実行し、
  それぞれの終了ステータス（$?）を見ます。

【できたら】

    lab check 05
