演習 03 — スクリプトを、全員が名前だけで使えるように置く            影響度 B / 目安 15分

  この演習はシステム全体を触ります（/usr/local/bin にファイルを置きます）。

【いまの状態を見てください】

  配られた greet は、そのままでは動きません。直して置くのがこの演習です。

    cd ~/work/03
    cat greet             ← 中身を見る
    bash greet            ← これは動く
    ./greet               ← エラーで止まる
    sh greet              ← エラーで止まる

  ./greet と sh greet は、どちらも次のように出して止まります
  （sh greet では、行の頭の ./greet: が greet: になります。日付はその日のもの）。

    ./greet: 3: function: not found
    こんにちは、 さん。今日は 10月13日 です
    ./greet: 5: Syntax error: "}" unexpected

  このエラーが出るのが、始まりの正しい状態です（教材の不具合ではありません）。
  なぜ bash greet だけが動くのかは、理論編の第4章とヒント（lab hint 03）にあります。

【やること】

  greet を /usr/local/bin/greet に置き、alice が

      greet

  と打つだけで、次の1行が出るようにしてください（日付はその日のもの）。

      こんにちは、alice さん。今日は 10月13日 です

  条件は2つあります。

    1. ファイルの所有者は root。root 以外のユーザは書き換えられないこと
    2. 使う人の PATH に何が並んでいても、同じ結果になること
       （PATH の先頭に date や id という名前の別物を置いている人がいても）

【判定のしかた】

  /usr/local/bin/greet の所有者と権限を読みます。
  次に alice として greet を2回実行します。1回目は alice のログインシェルから、
  2回目は date と id という名前の偽物を PATH の先頭に置いた状態から。

【できたら】

    lab check 03
