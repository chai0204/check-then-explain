演習 02 — 自作のコマンドを、名前だけで呼べるようにする               影響度 A / 目安 10分

【いまの状態を見てください】

    cat ~/work/02/today
    ~/work/02/today       ← パスを付ければ動く
    today                 ← 名前だけだと command not found
    echo $PATH

【やること】

  ~/work/02/today を **~/bin/today** に置き、どのディレクトリにいても

      today

  と打つだけで動くようにしてください。条件は2つです。

    1. いま開いている、このシェルで動くこと
    2. これから新しくログインしたシェルでも動くこと

【判定のしかた】

  lab check は、あなたのシェルから起動される子のプロセスです。
  あなたのシェルの PATH を受け継いでいるので、その PATH で today を探して実行します。
  さらに、環境をまっさらにしてログインシェルを1つ起動し、そこでも探して実行します。

【できたら】

    lab check 02
