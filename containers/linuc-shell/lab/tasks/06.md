演習 06 — 決まったコマンドだけを選ばせるメニュー                     影響度 A / 目安 15分

【いまの状態を見てください】

    cd ~/work/06
    cat menu.sh           ← 仕様のコメントと、1行の表示しか無い

【やること】

  Linux のコマンドを知らない人が、番号を入れるだけで決まったことを
  できるメニューを作ってください。menu.sh のコメントにある仕様のとおりです。

      1        → 自分のユーザ名を表示する（id -un）
      2        → ホスト名を表示する（hostname）
      q        → 「終了します」と表示して、終了ステータス 0 で終わる
      それ以外 → 「1・2・q のどれかを入力してください」と表示して、もう一度聞く
      入力が終わった（Ctrl-D）ときも終わる

  使ってみるとこうなります（入力は 1 → x → q）。

      $ bash menu.sh
      1) ユーザ名  2) ホスト名  q) 終了
      1
      lab
      x
      1・2・q のどれかを入力してください
      q
      終了します

【判定のしかた】

  menu.sh に 1 → 2 → x → q の順で入力を流し込んで実際に実行し、
  出力と終了ステータスを見ます。q を入れずに入力が終わる場合も試し、
  止まらずに終わるかを見ます（5 秒で打ち切ります）。
