レベル欄の位置を、行頭から決めます。

    grep -E '^[^ ]+ [^ ]+ (ERROR|WARN) ' server.log > hits.txt
    cat hits.txt
    #=> 2026-10-14 10:01:03 WARN  slow response 1200ms
    #   2026-10-14 10:02:11 ERROR database connection lost
    #   2026-10-14 10:04:02 ERROR disk full on /var
    #   2026-10-14 10:05:41 WARN  certificate expires in 7 days
    #   2026-10-14 10:06:55 ERROR job 8 failed
    lab check 07

【grep -E 'ERROR|WARN' だけでは】

  8行が出ます。本文に ERROR / WARN を含む INFO の2行と、WARNING の1行が混ざります。
  grep は「行のどこかに当たれば」出すので、どこに当たってほしいかを書く必要があります。

【部品の意味】

    ^          行頭
    [^ ]+      空白以外の1文字以上（[^ ] は「空白以外の1文字」、+ は直前の1回以上）
    (A|B)      A か B（拡張正規表現。基本正規表現では \(A\|B\) と書く）
    WARN の後ろの空白 … WARNING を外す

【基本正規表現で書くと】

    grep '^[^ ]\{1,\} [^ ]\{1,\} \(ERROR\|WARN\) ' server.log

  + も { } も ( ) も |、基本正規表現（grep の既定）ではただの文字です。
  特別な意味を持たせるには \ を付けます（\| と \+ は GNU の拡張）。
  -E を付ければ \ 無しで書けます。egrep は grep -E と同じものです。
