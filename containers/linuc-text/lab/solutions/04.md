置換と削除を1回の sed -i.bak にまとめます。

    sed -i.bak -e 's/^port=8080$/port=9090/' -e '/^#/d' app.conf
    cat app.conf
    #=> host=localhost
    #   port=9090
    #   port_admin=8081
    #   log_level=info
    #   url=http://localhost:8080/health
    lab check 04

【s/8080/9090/ ではだめな理由】

    sed 's/8080/9090/' app.conf | grep 9090
    #=> port=9090
    #   url=http://localhost:9090/health     ← url も変わってしまう

  sed は「その行のどこかに当たれば」置換します。^port= と行頭から書けば、
  port= で始まる行だけに当たります（port_admin= は port= の直後が _ なので当たりません）。

【-i を付けないと、ファイルは変わらない】

  sed は結果を標準出力に出すだけです。sed ... app.conf > app.conf と書くと、
  シェルが先に app.conf を空にしてから sed が読むので、ファイルは空になります（第7章）。
  -i は「結果を別のファイルに書いてから、元の名前に付け替える」ことで、これを避けています。

【-i.bak を2回打つと】

  2回目の .bak は、1回目に書き換えた後の中身で上書きされます。
  元の中身が欲しいなら、最初の1回で全部済ませるか、lab reset 04 で配り直します。
