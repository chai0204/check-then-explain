区切りを NUL 文字（\0）にして渡します。

    find . -name '*.tmp' -print0 | xargs -0 rm
    find . -type f | sort
    #=> ./data/keep.tmp.txt
    #   ./data/report final.txt
    #   ./data/sub dir/notes.txt
    #   ./logs/app.log
    lab check 06

【-print0 / -0 を付けないと】

    find . -name '*.tmp' | xargs rm
    #=> rm: cannot remove './data/sub': No such file or directory
    #   rm: cannot remove 'dir/x': No such file or directory
    #   rm: cannot remove 'y.tmp': No such file or directory
    #   rm: cannot remove './data/old': No such file or directory
    #   rm: cannot remove 'copy.tmp': No such file or directory
    #   （find が見つけた順に並ぶので、順番は環境で変わることがあります）

  xargs は受け取った文字列を空白と改行で区切って引数にします
  （既定では ' と " も特別な文字として読むので、名前にアポストロフィがあっても止まります）。
  ./data/old copy.tmp は ./data/old と copy.tmp の2つの引数になり、
  どちらもそんなファイルは無いので消せません。空白の無い cache.tmp だけが消えます。

  find -print0 は名前の区切りに NUL 文字を使い、xargs -0 は NUL だけで区切ります
  （引用符もただの文字として扱います）。
  ファイル名に NUL は入れられないので、どんな名前でも1つの引数のまま届きます。

【区切られ方を見る】

    find . -name '*.tmp' | xargs -n 1 echo

  -n 1 は「引数1つごとにコマンドを1回実行する」。1行に1つの引数が見えます。

【'*.tmp' の引用符】

  引用符を外すと、カレントディレクトリに .tmp で終わるファイルがあるとき、
  シェルが find に渡す前に *.tmp をその名前に置き換えます。
  find が受け取るパターンが変わってしまうので、パターンは引用符で囲みます。
