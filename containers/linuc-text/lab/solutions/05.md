1回目で2本に分け、2回目で1本にまとめます。

    ./check.sh > ok.log 2> ng.log
    ./check.sh > all.log 2>&1
    cat all.log
    #=> OK: disk
    #   NG: memory
    #   OK: network
    #   NG: cpu
    #   OK: clock
    lab check 05

【2>&1 を先に書くと】

    ./check.sh 2>&1 > all.log
    #=> NG: memory          ← 画面に出る
    #   NG: cpu

  リダイレクトは左から順に処理されます。
    1. 2>&1   … 2番を「いま1番が向いている先」＝画面へ（もともと画面なので何も変わらない）
    2. > all.log … 1番だけを all.log へ
  2>&1 は「1番と同じ先を、その時点で写す」だけで、後から1番を付け替えても2番はついていきません。

【&> でもよい】

    ./check.sh &> all.log

  bash では &> ファイル が「> ファイル 2>&1」と同じ意味です。

【>> と > の違い】

  > は開くときに中身を空にし、>> は末尾に足します。
  何回か試して ok.log に同じ行が2回ずつ入ったなら、>> を使ったか、
  別の回の出力が混ざっています。> で作り直してください。
