演習 05 — 出力を2本に分けて保存する                               影響度 B / 目安 10分

  ~/work/05/check.sh は、点検結果を5行出すスクリプトです。
  OK の行は標準出力に、NG の行は標準エラー出力に出します。

【いまの状態を見てください】

    cd ~/work/05
    ./check.sh

  画面では5行が混ざって見えます。どれがどちらに出たのかは、画面からは分かりません。

【やること】

  check.sh の出力から、次の3つのファイルを作ってください。

    ok.log   … 標準出力に出た行だけ（3行）
    ng.log   … 標準エラー出力に出た行だけ（2行）
    all.log  … 両方。画面に出たのと同じ順で（5行）

  check.sh は何回実行しても構いません。

【できたら】

    lab check 05
