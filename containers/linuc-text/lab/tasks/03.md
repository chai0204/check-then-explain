演習 03 — アクセスログのステータスを数える                        影響度 B / 目安 12分

  ~/work/03/access.log は、30行のアクセスログです。

【いまの状態を見てください】

    cd ~/work/03
    head -3 access.log
    wc -l access.log

  空白で区切ると、9番目の欄が HTTP のステータスコード（200 や 404）です。

【やること】

  ステータスコードごとの行数を数え、多い順に並べて ~/work/03/answer.txt に
  保存してください。1行に「件数 ステータス」の2つを書きます
  （間や行頭の空白の数は問いません）。

      例（数字は架空）:      7 200
                             3 404

  パイプでつないだフィルタで作ってください。手で数えると数え間違えます。

【できたら】

    lab check 03
