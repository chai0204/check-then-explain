演習 07 — レベルが ERROR か WARN の行だけを抜き出す               影響度 B / 目安 12分

  ~/work/07/server.log は14行のログです。1行は「日付 時刻 レベル 本文」の順です。

【いまの状態を見てください】

    cd ~/work/07
    cat server.log
    grep -c ERROR server.log

【やること】

  レベル（3番目の欄）がちょうど ERROR か WARN の行だけを、元の順のまま
  ~/work/07/hits.txt に保存してください。grep と正規表現を使います。

  次の行は含めません。

    - 本文の中に ERROR や WARN という語が出てくるだけの行
    - レベルが WARNING の行
    - レベルが小文字の error の行
