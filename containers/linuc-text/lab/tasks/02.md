演習 02 — 自作のコマンドを名前だけで動かす                        影響度 B / 目安 10分

  ~/work/02/bin/greet は、あいさつを1行出すだけのコマンドです。

【いまの状態を見てください】

    cd ~/work/02
    ls -l bin/
    ~/work/02/bin/greet
    greet

  フルパスなら動くのに、名前だけだと command not found になります。

【やること】

  どのディレクトリにいても、greet と打つだけで ~/work/02/bin/greet が
  動くようにしてください。

  判定では、lab check が /tmp に移動してから、名前だけで greet を探して
  実行します。~/work/02 の中でだけ動く状態では通りません。

  注意: PATH を丸ごと書き換えると、ls も lab も見つからなくなります。
  そうなったら exit して起動し直してください（進捗は消えません）。

【できたら】
