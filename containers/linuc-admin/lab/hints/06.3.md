ほぼ答えです。今ある at.deny に1行足し、cron.deny を新しく作ります。

    echo eve | sudo tee -a /etc/at.deny
    echo eve | sudo tee /etc/cron.deny

    sudo -u eve atq            #=> You do not have permission to use atq.
    sudo -u eve crontab -l     #=> You (eve) are not allowed to use this program (crontab)
    sudo -u bob atq            （何も出ない＝使える）
