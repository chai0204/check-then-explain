ほぼ答えです。有効期限を「1970-01-02」にします（エポックからの日数 1）。

    sudo usermod -e 1 dave
    sudo chage -l dave | grep 'Account expires'

外の端末で:

    ssh -l dave linuc id
    #=> Your account has expired; please contact your system administrator.

戻すときは sudo usermod -e '' dave です。
シェルを /usr/sbin/nologin にする方法でも通ります（sudo usermod -s /usr/sbin/nologin dave）。
