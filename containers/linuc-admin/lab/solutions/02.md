groupadd でグループを作り、usermod -aG で「足す」と指定します。

    sudo groupadd -g 2000 devs
    sudo usermod -aG devs bob
    id bob
    #=> uid=1001(bob) gid=1001(bob) groups=1001(bob),1101(proj-a),1102(proj-b),2000(devs)
    getent group devs
    #=> devs:x:2000:bob

【-a を付けないと】

    sudo usermod -G devs bob
    id bob
    #=> uid=1001(bob) gid=1001(bob) groups=1001(bob),2000(devs)

  -G は「副グループの一覧をこれにする」という意味で、/etc/group の各行の4列目（メンバー）を
  書き直します。渡さなかった proj-a・proj-b の行からは bob が消されます。足すときは必ず -aG と書きます。

【主グループは別の台帳にある】

  bob の主グループ（gid=1001(bob)）は /etc/passwd の4列目に書かれていて、/etc/group の4列目には載りません。
  usermod -G が触るのは副グループだけです。主グループを変えるのは usermod -g です。

【ログイン中のシェルには効かない】

  所属の変更は、次にログインしたときに読まれます。bob がすでにログインしているなら、
  その端末の id には出ません。入り直すと出ます（id bob のように名前を付けると、台帳を直接読むので出ます）。
