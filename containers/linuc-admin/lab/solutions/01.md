README.txt を /etc/skel に置いてから、-m と -s を付けて作り、パスワードを付けます。

    echo 'はじめに読んでください。' | sudo tee /etc/skel/README.txt
    sudo useradd -m -s /bin/bash frank
    sudo passwd frank
    #=> New password:
    #   Retype new password:
    #   passwd: password updated successfully

    getent passwd frank
    #=> frank:x:1004:1004::/home/frank:/bin/bash     （番号は作った順で変わります）
    sudo ls -A /home/frank
    #=> .bash_logout  .bashrc  .profile  README.txt
    sudo passwd -S frank
    #=> frank P 2026-10-13 0 99999 7 -1

【何も付けずに useradd すると】

    sudo useradd frank
    getent passwd frank
    #=> frank:x:1004:1004::/home/frank:/bin/sh
    ls -ld /home/frank
    #=> ls: cannot access '/home/frank': No such file or directory

  useradd が書いたのは台帳（/etc/passwd・/etc/shadow・/etc/group）の行だけです。
  6列目の /home/frank は「ここをホームとする」という記述で、ディレクトリを作る指示ではありません。
  作らせるのが -m です。シェルの /bin/sh は /etc/default/useradd の SHELL= から来ています。
  （-m なしで作るかどうかは /etc/login.defs の CREATE_HOME で決まります。この Ubuntu には行が無いので作らず、
   RHEL 系は CREATE_HOME yes なので -m なしでも作ります。どちらでも -m を付ければ確実です）

【順番が大事な理由】

  /etc/skel は「ひな形」で、useradd -m がホームを作るその瞬間にだけ写されます。
  frank を作ったあとで /etc/skel に README.txt を足しても、frank のホームには入りません
  （そのときは sudo cp /etc/skel/README.txt /home/frank/ と sudo chown frank: で手で配ります）。

【パスワードの欄】

  useradd 直後の /etc/shadow の2列目は ! です（passwd -S では L。RHEL 系では !! で、passwd -S は LK と出ます）。
  これは「パスワードが無い・ロック」の印で、
  パスワードではログインできません。passwd で設定すると $y$… で始まる文字列（yescrypt のハッシュ）に変わります。

【adduser との違い】

  Debian 系には adduser という対話型の道具もあり、こちらはホームの作成・skel の写し・パスワードの入力まで
  まとめてやります（設定は /etc/adduser.conf）。試験で問われるのは useradd のオプションです。
