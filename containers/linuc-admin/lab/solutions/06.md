今ある /etc/at.deny に eve を足し、/etc/cron.deny を作って eve を書きます。

    echo eve | sudo tee -a /etc/at.deny
    echo eve | sudo tee /etc/cron.deny

    sudo -u eve atq
    #=> You do not have permission to use atq.
    sudo -u eve crontab -l
    #=> You (eve) are not allowed to use this program (crontab)
    #   See crontab(1) for more information
    sudo -u bob crontab -l
    #=> no crontab for bob            ← 断られてはいない（表がまだ無いだけ）

【at.allow に書くと、逆になる】

    echo eve | sudo tee /etc/at.allow

  at.allow があると、at はそれだけを読み、書かれた人「だけ」が使えます。eve だけが使え、
  student と bob が使えなくなります。at.deny はもう読まれません。

【at.deny を消すと、一般ユーザは全員使えなくなる】

  at.allow も at.deny も無いとき、at を使えるのは root だけです。
  「拒否リストを消したのだから制限が無くなる」とは逆の動きです。

    ファイルの状態                 at                     cron（Debian 系）
    allow がある                   allow に書いた人だけ   allow に書いた人だけ
    allow が無く deny がある       deny に書いた人以外    deny に書いた人以外
    allow が無く deny が空         全員                   全員
    どちらも無い                   root だけ              全員

  root はどの場合でも使えます。
  RHEL 系の cron（cronie）は、どちらも無いときは root だけで、at と同じです。
  ただし RHEL は空の /etc/cron.deny を最初から置いているので、既定の状態では全員が使えます。
