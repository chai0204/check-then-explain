a は Shift_JIS、b は EUC-JP、c は ISO-2022-JP です。-f に正しい名前を渡せば元の文に戻ります。

    mkdir -p ~/lab08/utf8
    cd ~/lab08
    iconv -f SHIFT_JIS   -t UTF-8 a.txt > utf8/a.txt
    iconv -f EUC-JP      -t UTF-8 b.txt > utf8/b.txt
    iconv -f ISO-2022-JP -t UTF-8 c.txt > utf8/c.txt
    cat utf8/*.txt
    #=> 会議メモ: 来週の月曜に棚卸し。
    #   担当は佐藤さん。
    #   サーバ移行の手順書（第2版）。
    #   作業は夜間に行う。
    #   件名: 定期点検のお知らせ
    #   本文: 10月20日に停電があります。

【file の判定】

    file ~/lab08/*.txt
    #=> a.txt: Non-ISO extended-ASCII text
    #   b.txt: ISO-8859 text
    #   c.txt: ASCII text, with escape sequences

  EUC-JP の b.txt を「ISO-8859」と言っています。ISO-8859-1 は西欧の1バイトの文字コードで、
  0x80 以上のバイトにも文字が割り当ててあるので、どんな8bitのバイト列も「ISO-8859 として読める」からです。
  ファイルには「私は EUC-JP です」という印がありません。file はバイトの並びから推測しているだけです。
