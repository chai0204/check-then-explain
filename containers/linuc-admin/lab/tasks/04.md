演習 04 — 2種類の表に、毎分のジョブを置く                         影響度 B / 目安 15分

  この演習は練習機の中で、システム全体を触ります（外の端末で ssh linuc）。

【いまの状態を見てください】

    crontab -l
    grep -vE '^\s*#|^\s*$' /etc/crontab
    ls -l /etc/cron.d

【やること】

  毎分動くジョブを2つ置いてください。

      1. student の crontab に:
             毎分、date の出力を /home/student/tick.log に追記する
      2. /etc/cron.d/lab-whoami というファイルに:
             毎分、root として id -un の出力を /var/log/lab-whoami.log に追記する

  判定は cron が実際にジョブを動かした結果を見ます。2つのファイルが直近の1分以内に書かれていて、
  tick.log は student が、lab-whoami.log には root と書かれていれば達成です。
  まだ動いていなければ、判定は次の分まで待ちます（最大 75 秒。待っている間はそう表示します）。

【詰まったら】

  ジョブが動いたかどうかは cron のログに出ます。

      journalctl -u cron -n 20 --no-pager

  2つの表は、列の数が違います。

【できたら】

    lab check 04

  片づけ（演習の後で）: crontab -r と sudo rm /etc/cron.d/lab-whoami。
  毎分動き続けるので、終わったら消しておくと練習機のログが静かになります。
