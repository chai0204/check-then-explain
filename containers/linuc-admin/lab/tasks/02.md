演習 02 — 今の所属を残したまま、グループを1つ足す                   影響度 B / 目安 10分

  この演習は練習機の中で、システム全体を触ります（外の端末で ssh linuc）。

【いまの状態を見てください】

  練習機には、最初から bob というユーザがいます。

    id bob
    getent group proj-a proj-b

  bob は主グループ bob のほかに、proj-a と proj-b に入っています。

【やること】

  1. グループ devs を、GID 2000 で作ってください
  2. bob を devs にも入れてください。**今の所属（proj-a・proj-b）は残すこと**

  判定は練習機の中で getent と id を引き、bob が実際にどのグループに属しているかを見ます。

【できたら】

    lab check 02

  失敗しても、所属は usermod でもう一度書き直せます。練習機ごと最初に戻すなら外の端末で vm reset --yes。
