演習 01 — ユーザを1人、使える状態で作る                         影響度 B / 目安 12分

  この演習は練習機（仮想マシン）の中で、システム全体を触ります。
  外の端末で ssh linuc と打って練習機に入ってから始めてください（プロンプトが student@linuc になります）。

【いまの状態を見てください】

    getent passwd student
    useradd -D
    ls -A /etc/skel

【やること】

  ユーザ frank を作ってください。条件は4つです。

      1. ホームディレクトリ /home/frank が実際にあり、/etc/skel の中身（.bashrc など）が入っている
      2. ログインシェルは /bin/bash
      3. これから作るユーザ全員のホームに README.txt が配られるようにして（中身は自由）、
         frank のホームにも README.txt が入っている
      4. frank にパスワードが設定されている（sudo passwd -S frank の2列目が P）

  判定は練習機の中を実際に見ます。台帳（/etc/passwd）の行だけでなく、
  ホームの実物・中身・パスワードの状態を確かめます。

【詰まったら】

  useradd は、頼まれたことしかしません。
  台帳に「ホームは /home/frank」と書かれていることと、そのディレクトリが在ることは別です。

      getent passwd frank
      ls -ld /home/frank

【できたら】

    lab check 01        （練習機の中でも、外の端末でも打てます）

  作り直したいときは sudo userdel -r frank で消してから。
  練習機ごと最初に戻すなら、外の端末で vm reset --yes です（全部の演習が最初に戻ります）。
