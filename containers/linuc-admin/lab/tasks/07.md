演習 07 — 呼ぶ人のロケールに左右されないスクリプトにする            影響度 B / 目安 12分

  この演習は練習機の中で、システム全体を触ります（外の端末で ssh linuc）。

【いまの状態を見てください】

    cat /usr/local/bin/lab-report
    lab-report
    locale -a

  lab-report は、今月の英語3文字（Oct など）でアーカイブの置き場所を組み立て、当番の順を並べるスクリプトです。
  あなたの端末では正しく動きます。ところが、日本語の環境で使っている人が呼ぶと、置き場所の名前が変わります。

【やること】

  1. ja_JP.UTF-8 ロケールを生成してください（locale -a に ja_JP.utf8 が出る状態）
  2. lab-report を、**呼ぶ人のロケール設定に関係なく**、いつも C ロケールのときと同じ出力にしてください
     （今月の欄は Oct のような英語3文字になる）

  判定は lab-report を3通りに呼んで、出力を比べます。

      LANG=C.UTF-8        で呼ぶ
      LANG=ja_JP.UTF-8    で呼ぶ
      LC_ALL=ja_JP.UTF-8  で呼ぶ

  3つが同じで、今月の欄が C ロケールの月名なら達成です。
  1 をやらないと、日本語のロケールで呼んでも差が出ないので、確かめようがありません。

【できたら】

    lab check 07
