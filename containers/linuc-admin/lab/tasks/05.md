演習 05 — 置いてあるのに走らないスクリプトを、毎日の実行に入れる       影響度 B / 目安 12分

  この演習は練習機の中で、システム全体を触ります（外の端末で ssh linuc）。

【いまの状態を見てください】

    ls -l /etc/cron.daily
    cat /etc/cron.daily/lab-backup.sh

  lab-backup.sh は、毎日1回 /var/backups/lab-backup.log に1行書くつもりで置かれたスクリプトです。
  ところが、置いてから一度も走っていません。

    cat /var/backups/lab-backup.log

【やること】

  1. lab-backup.sh が、毎日の実行（cron.daily）に選ばれるようにしてください。スクリプトの中身は変えません
  2. 明日まで待たずに、今日の分を実際に走らせて、/var/backups/lab-backup.log に1行入った状態にしてください

  判定は、run-parts 自身に「cron.daily のうち、どれを走らせるか」を聞き（--test。走らせずに名前だけ出す）、
  そこに lab-backup が含まれるかと、ログの行があるかを見ます。

【詰まったら】

  cron.daily の中身を選んでいるのは run-parts です。選ばれるものは、こうして聞けます。

      run-parts --test /etc/cron.daily

【できたら】

    lab check 05
