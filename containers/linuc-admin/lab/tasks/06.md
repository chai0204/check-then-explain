演習 06 — 1人だけ、at と crontab を使えなくする                    影響度 B / 目安 10分

  この演習は練習機の中で、システム全体を触ります（外の端末で ssh linuc）。

【いまの状態を見てください】

    ls -l /etc/at.allow /etc/at.deny /etc/cron.allow /etc/cron.deny
    sudo cat /etc/at.deny

  練習機には eve と bob というユーザがいます。いまは2人とも、student も、at と crontab を使えます。

【やること】

  eve だけが at（atq・atrm も）と crontab を使えないようにしてください。
  student と bob は、どちらも使えるままにします。

  判定は、3人それぞれとして実際に atq と crontab -l を打ち、断られるかどうかを見ます。

【詰まったら】

  試すときは、そのユーザとして打ちます。

      sudo -u eve atq
      sudo -u eve crontab -l

【できたら】

    lab check 06
