演習 08 — 文字コードのそろわない3つのファイルを UTF-8 にする          影響度 B / 目安 12分

  この演習は練習機の中の、student のホームで作業します（外の端末で ssh linuc）。

【いまの状態を見てください】

    ls -l ~/lab08
    cat ~/lab08/a.txt
    file ~/lab08/*.txt

  3つとも日本語の文章ですが、別々の場所から集めたので文字コードがそろっていません。
  この端末（UTF-8）で cat すると、どれも読めません。

【やること】

  3つを UTF-8 に変換して、~/lab08/utf8/ に同じ名前で置いてください。

      ~/lab08/utf8/a.txt
      ~/lab08/utf8/b.txt
      ~/lab08/utf8/c.txt

  元のファイルは変えないでください。
  判定は、変換後のファイルを UTF-8 として読み、元のファイルを正しい文字コードで読んだ文と一致するかを見ます。

【詰まったら】

  file の言うことを、うのみにしないでください。候補は Shift_JIS・EUC-JP・ISO-2022-JP の3つです。
