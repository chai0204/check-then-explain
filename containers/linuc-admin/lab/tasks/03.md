演習 03 — アカウントを消さずに一時停止する                       影響度 B / 目安 12分

  この演習は練習機の中で、システム全体を触ります。外の端末と練習機の中の両方を使います。

【いまの状態を見てください】

  練習機には dave というユーザがいて、外の端末から鍵で入れます。外の端末（lab@host）で:

    ssh -l dave linuc id

  dave はしばらく休職します。アカウントを止めてください。ただし、戻ってきたらすぐ使えるように、
  消してはいけません。

【やること】

  dave を一時停止してください。条件は3つです。

      1. 外から ssh -l dave linuc しても入れない
      2. 練習機の中で sudo su - dave しても、dave としてコマンドが動かない
      3. dave の行（/etc/passwd）・ホーム・/home/dave/notes.txt・鍵（~/.ssh/authorized_keys）は残す

  判定は実際に入ってみます。外から dave の鍵で ssh し、練習機の中で root から su - dave して、
  dave としてコマンドが動くかを見ます。

【詰まったら】

  「ロックした」と表示されることと、入れなくなることは別のことです。止めたら、必ず入ってみてください。

【できたら】

    lab check 03
