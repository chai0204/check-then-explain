演習 05 — 外から ssh で練習機に入れるようにする                       影響度 B / 目安 15分

  ~/work/05 で打ちます。

【やること】

  1. ~/work/05/linuc.qcow2 を、土台 /var/lib/lab-vm/linuc-guest.qcow2 の上の差分ディスクとして作る
  2. それを自分の qemu-system-x86_64 で起動する（vm や virsh は使わない）
  3. 練習機を動かしたまま、この端末で  ssh linuc  と打てば入れるようにする
     （ssh linuc の行き先は ~/.ssh/config にある 127.0.0.1 の 2222 番です）

  練習機の中のネットワークの設定は、enp0s16 という名前の NIC にだけ DHCP でアドレスを付けます（第5章）。

  判定は、127.0.0.1:2222 で待っているプロセスと、それが開いているディスク（土台の上の差分か）、
  ssh で入った練習機の中の NIC のアドレスを見ます。

【できたら】

    lab check 05

  終わったら練習機を止めてください。動かしたままだと、演習 06 の QEMU が
  同じ 127.0.0.1:2222 を使えずに起動できません。
