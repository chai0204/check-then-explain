【戻すとき】

  同じディスクで起動し直し、モニタで  loadvm loggedin  と打つと、ログインした直後の画面の続きに戻ります
  （その後に作ったファイルは消え、時計も保存した時点に戻る）。

【qemu-img snapshot -c との違い】

    qemu-img snapshot -c disk-only linuc.qcow2
    qemu-img snapshot -l linuc.qcow2
    #=> … disk-only   0 B …                   ← VM SIZE が 0。ディスクの中身だけで、動いている状態は無い

  こちらは練習機が止まっているときに外から取るもので、戻すと「電源を入れる前」の状態に戻ります。

【UEFI の NVRAM を qcow2 で渡していると】

  savevm は、動いている状態を書き込める qcow2 のうち1つにだけ入れます。NVRAM を qcow2 にして渡していると
  状態はそちらに入り、linuc.qcow2 の loggedin は VM SIZE 0 B に見えます（第6章）。判定は ~/work/03 の
  ほかの qcow2 に同じ名前で状態が入っていれば、それを見つけて ✔ にします。
