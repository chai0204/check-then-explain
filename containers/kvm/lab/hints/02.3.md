ほぼ答えです。あなたの PC の端末で、いまの檻を exit で抜けてから:

    docker run --rm -it --name lab-kvm --hostname host \
      --device /dev/kvm --group-add "$(stat -c %g /dev/kvm)" \
      -v lab-kvm-vm:/home/lab/vm -v lab-kvm-state:/home/lab/.lab \
      （実践編に書いてあるイメージ名）

入ったら:

    ls -l /dev/kvm
    id
    lab check 02

/dev/kvm が crw-rw-rw-（0666）の PC では --group-add が無くても開けますが、付けておけば
0660 の PC と同じコマンドで済みます。
