【何が起きているか】

  練習機の CPU は、QEMU がソフトで作ったものです。CPU が何者かは、OS が主に CPUID という命令で
  CPU に尋ねて知ります。TCG の練習機では、その命令に答えているのは QEMU で、既定の CPU のモデル
  （qemu64）は「AMD の CPU で、仮想化支援（AMD-V。印は svm）を持っている」と答えます。
  練習機のカーネルはその答えを信じて kvm_amd を読み込み、/dev/kvm まで作りました（第1章）。
  この AMD-V は名乗りだけではなく、QEMU がソフトで真似していて、練習機の中の KVM で小さな仮想マシンを
  動かすこともできます（第1章で確かめます）。

  KVM を使うかどうかを判定は QEMU のプロセスで見ています。KVM を使う QEMU は、カーネルの中に作った
  仮想マシンを anon_inode:kvm-vm というファイルとして開いています。

    readlink /proc/$(pgrep qemu)/fd/* | grep kvm
    #=> （何も出ない。TCG の QEMU は /dev/kvm を開いていない）
