演習 04 — 練習機に、あなたの PC の CPU をそのまま見せる            影響度 B / 目安 10分

  外（lab@host）で打ちます。演習02 ができている（この檻の lab が /dev/kvm を開ける）ことが前提です。

【いまの状態を見てください】

    grep -m1 'model name' /proc/cpuinfo                 # あなたの PC の CPU
    ssh linuc grep -m1 'model name' /proc/cpuinfo       # 練習機の CPU（動いていれば）

【やること】

  練習機を KVM で起動し直し、練習機の中から見える CPU のメーカーとモデル名が、
  あなたの PC の CPU と同じになるようにしてください。
  QEMU のオプション -cpu で、練習機に見せる CPU を選べます。

  そのうえで、練習機の中に仮想化支援の印（vmx か svm）と /dev/kvm があるかを確かめてください。

  判定では次を確かめます。

      いま動いている QEMU が KVM を使っている
      練習機の中の CPU のメーカー・モデル名・型番（family・model・stepping）が、あなたの PC の CPU と同じ

【できたら】
