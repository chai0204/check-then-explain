演習 01 — 練習機を TCG で起動し、中から見える CPU を確かめる       影響度 B / 目安 10分

  外（lab@host）で打ちます。KVM が使えない PC（/dev/kvm の無い檻）でもできます。

【いまの状態を見てください】

    qemu-linuc status
    lscpu | grep -E '^(Vendor ID|Model name|Virtualization):'

  練習機はまだ止まっています。2行目は、あなたの PC の CPU です（この檻はコンテナなので、
  あなたの PC のカーネルが見ている CPU がそのまま見えます）。

【やること】

  1. 練習機を、アクセラレータに TCG（練習機の命令を、ひとまとまりずつ翻訳して実行する方式）を指定して起動してください。
     qemu-linuc の後ろに書いたものは、そのまま qemu-system-x86_64 のオプションになります。
  2. ssh linuc で中に入り、練習機の CPU が何を名乗っているか（メーカー・モデル名・仮想化支援の印）を
     確かめてください。あなたの PC の CPU と比べてください。

  判定では次の2つを、別々に確かめます。

      QEMU が KVM を使わずに（命令を翻訳して）動いている
      練習機の中の OS が ssh に応答する

【できたら】

    lab check 01

  練習機を止めるのは  qemu-linuc stop  。ディスクを最初の状態に戻すのは  qemu-linuc reset --yes
