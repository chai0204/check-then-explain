演習 03 — devs の共有ディレクトリを作る                             影響度 B / 目安 12分

  この演習はシステム全体を触ります。作業場所は /srv/share です（まだありません）。

【いまの状態を見てください】

    getent group devs
    id alice; id bob; id carol
    ls -ld /srv /srv/share

  alice と bob はグループ devs の仲間です。carol は入っていません。
  あなた（lab）も入っていないので、作業には sudo を使います。

【やること】

  /srv/share を、devs の共有ディレクトリとして作ってください。条件は4つです。

      1. alice が作ったファイルのグループが、自動で devs になる
      2. bob も、このディレクトリにファイルを作れる
      3. bob は alice のファイルを消せない（自分のファイルは消せる）
      4. carol は中を一覧できない

  判定では、alice・bob・carol として実際にファイルを作り、消し、一覧しようとします
  （判定で作ったファイルは、判定の最後に消します）。

【やり直すとき】

  檻を抜けて入り直してください。--rm で起動しているので /srv/share は消えます
  （進捗は残ります）。

【できたら】

    lab check 03
