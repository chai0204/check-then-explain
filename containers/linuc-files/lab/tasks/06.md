演習 06 — project を tar.xz にまとめる                               影響度 B / 目安 10分

  作業場所は ~/work/06 です（lab start 06 で project/ が配られています）。

【いまの状態を見てください】

    cd ~/work/06
    ls -lR project

【やること】

  project/ をまるごと、xz で圧縮した tar アーカイブ ~/work/06/project.tar.xz に
  してください。

      - アーカイブの中のパスは project/ から始まること
        （home/lab/... から始まらない）
      - 形式が本当に xz であること（名前だけ .xz にしても通りません）
      - project/ は消さずに残すこと

  判定では、アーカイブを実際に検査・展開して、元の project/ と比べます。

【やり直すとき】

    cd ~
    lab reset 06
    cd ~/work/06

  lab reset は ~/work/06 を消して配り直します。中にいたシェルは消えた場所に
  取り残されるので、先に cd ~ で出て、最後に入り直してください。

【できたら】

    lab check 06
