演習 05 — 大きな .tmp だけを、深いところまで消す                    影響度 B / 目安 12分

  作業場所は ~/work/05 です（lab start 05 でファイルが配られています）。

【いまの状態を見てください】

    cd ~/work/05
    ls -laR

【やること】

  ~/work/05 の下（深い階層も含む）から、次の2つを両方満たす **ファイル** を
  すべて消してください。

      - 名前が .tmp で終わる（隠しファイルも含む。大文字の .TMP は含まない）
      - 大きさが 1KB（1024 バイト）より大きい

  それ以外は1つも消しません。ちょうど 1024 バイトのものは残します。

  判定では、消えているべきものと残っているべきものを1つずつ確かめます。
  消す前に、同じ条件で一覧だけ出して確かめるのが安全です。

【やり直すとき】

    cd ~
    lab reset 05
    cd ~/work/05

  lab reset は ~/work/05 を消して配り直します。中にいたシェルは消えた場所に
  取り残されるので、先に cd ~ で出て、最後に入り直してください。

【できたら】

    lab check 05
