演習 07 — current を v2 に切り替える                                  影響度 B / 目安 10分

  作業場所は ~/work/07 です（lab start 07 で releases/ と current が配られています）。

【いまの状態を見てください】

    cd ~/work/07
    ls -l
    ls -l releases
    cat current/VERSION

  current は releases/v1 を指すシンボリックリンクです。
  「いま使う版」をリンクで指しておき、切り替えはリンクの向きを変えるだけで済ませる。
  版を入れ替えるときによく使う形です。

【やること】

  current が releases/v2 を指すように切り替えてください。

      - current はシンボリックリンクのまま（コピーやディレクトリにしない）
      - releases/ の中には何も足さない・消さない

  判定では、current の正体・辿り着く先・読める VERSION と、
  releases/ の中に余計なリンクができていないかを見ます。

【やり直すとき】

    cd ~
    lab reset 07
    cd ~/work/07

  lab reset は ~/work/07 を消して配り直します。中にいたシェルは消えた場所に
  取り残されるので、先に cd ~ で出て、最後に入り直してください。

【できたら】

    lab check 07
