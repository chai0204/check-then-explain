演習 01 — 一覧は見せずに、1つのファイルだけ読ませる                  影響度 B / 目安 10分

  作業場所は ~/work/01 です。他人（alice）の立場は sudo -u alice で借ります。

【いまの状態を見てください】

    echo "alice へ: 鍵は2番の棚" > ~/work/01/memo.txt
    ls -l ~/work/01/memo.txt
    sudo -u alice cat /home/lab/work/01/memo.txt

  memo.txt は -rw-r--r--（誰でも読める）なのに、alice は読めません。

【やること】

  alice から見て、次の3つが同時に成り立つようにしてください。

      cat /home/lab/work/01/memo.txt   … 読める
      ls  /home/lab                    … 一覧できない（Permission denied のまま）
      ls  /home/lab/work/01            … 一覧できない

  memo.txt の中身と場所は変えません。変えてよいのは権限だけです。
  判定では、alice として実際に読み、一覧しようとします。

【やり直すとき】

    cd ~
    chmod 750 ~            # ホームの権限は lab reset では戻りません
    lab reset 01
    lab start 01
    cd ~/work/01

【できたら】

    lab check 01
