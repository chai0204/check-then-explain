演習 02 — 次に開くシェルでも、640 と 750 で作られるようにする        影響度 B / 目安 10分

  作業場所は ~/work/02 です。

【いまの状態を見てください】

    cd ~/work/02
    umask
    touch before.txt; mkdir before.d
    ls -ld before.txt before.d

【やること】

  これから作るファイルが -rw-r-----（640）、ディレクトリが drwxr-x---（750）で
  作られるようにしてください。**次に開くシェルでも** そうなるようにします。

  判定では、umask を檻の起動時と同じ 0022 に戻したうえで新しいログインシェル
  （bash -l）を1つ起動し、その中でファイルとディレクトリを1つずつ作って、
  作られた瞬間の権限を確かめます。

      - いま開いているシェルでだけ umask を変えても通りません
      - 作った後に chmod で直すのは判定の対象外です

【注意】

  この檻は docker run --rm で起動しています。抜けると ~/.bashrc の変更も消えます。
  判定は、いまのコンテナの中で行ってください。

【やり直すとき】

    cd ~
    sed -i '/^umask 027$/d' ~/.bashrc     # ~/.bashrc に足した行は lab reset では消えません
    lab reset 02
    lab start 02
    cd ~/work/02

【できたら】

    lab check 02
