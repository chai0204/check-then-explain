current を、ディレクトリとして辿らずにリンクそのものとして置き換えます。

    cd ~/work/07
    ln -sfn releases/v2 current
    ls -l current
    #=> lrwxrwxrwx 1 lab lab 11 … current -> releases/v2
    cat current/VERSION
    #=> 2.0

【ln -sf では置き換わらない】

    ln -sf releases/v2 current
    ls -l current
    #=> current -> releases/v1          ← 変わっていない
    ls -l releases/v1
    #=> v2 -> releases/v2               ← v1 の中にリンクが増えた（しかも壊れている）

  ln の最後の引数がディレクトリなら、ln は「その中に作れ」と解釈します。
  current はディレクトリを指すリンクなので、ディレクトリとして辿られ、
  releases/v1 の中に v2 ができます。エラーは出ません。

    -f  同じ名前があれば消してから作る
    -n  最後の引数がディレクトリを指すリンクなら、辿らずにリンクそのものとして扱う

  -n が無いと -f が効く前に辿られてしまうので、両方要ります。
  できてしまった releases/v1/v2 は rm releases/v1/v2 で消します（リンクだけが消えます）。

【リンクの中身は「道順」】

  シンボリックリンクは、行き先のパスを中身として持つ別のファイルです。
  releases/v2 は「リンクの置き場所から見た」相対パスなので、current と releases が
  同じディレクトリにある限り、ディレクトリごと移動しても壊れません。

【版の切り替えに使う理由】

  切り替えはリンク1本の書き換えなので一瞬で終わり、戻すのも同じ1行です。
  releases/v1 と v2 の中身には一切触れません。
