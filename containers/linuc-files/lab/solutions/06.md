~/work/06 に移動してから、project を相対パスで渡し、J で xz を呼びます。

    cd ~/work/06
    tar -cJvf project.tar.xz project
    file project.tar.xz
    #=> project.tar.xz: XZ compressed data, checksum CRC64
    tar -tJf project.tar.xz
    #=> project/
    #=> project/…

【オプションの読み方】

    c  作る（create）       t  一覧する（list）    x  展開する（extract）
    z  gzip を通す          j  bzip2 を通す        J  xz を通す
    v  処理した名前を出す   f  次の引数がアーカイブのファイル名
    C  展開先のディレクトリ（tar -xJf project.tar.xz -C /tmp/out）

  f の直後には必ずアーカイブ名が来ます。-cJvf project.tar.xz の順に並べるのはこのためです。

【tar は束ねるだけ】

  tar が作るのは、ファイルの名前・権限・所有者・時刻と中身を1本に並べたものです。
  縮めているのは、z / j / J で呼ばれる gzip / bzip2 / xz のほうです。
  名前を .xz にしても中身は変わりません（判定は xz -t で実際に展開して確かめています）。
  一般ユーザが展開すると、権限には umask がかかります。記録どおりに戻すには p を足します
  （tar -xJpf project.tar.xz）。所有者まで戻るのは root で展開したときだけです（第6章）。

【中のパスは、渡したパスのまま】

    tar -cJf project.tar.xz ~/work/06/project
    #=> 中は home/lab/work/06/project/...（先頭の / だけが外される）

  これを展開すると、展開した場所に home/lab/work/06/... が掘られます。
  渡す前に移動しておくか、-C で「ここから見たパスで入れる」と指定します。

    tar -cJf project.tar.xz -C ~/work/06 project
