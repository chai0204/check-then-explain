隠しファイル用のパターンを足し、-p で時刻と権限を写します。

    cd ~/work/04
    mkdir backup
    cp -p *.conf .*.conf backup/
    ls -la --time-style=full-iso backup/

【* は隠しファイルに一致しない】

    echo *.conf
    #=> app.conf db.conf
    echo .*.conf
    #=> .secret.conf

  * や ? は、先頭の . に一致しません。. で始まる名前は、. から書き始めたパターンだけが拾います。
  そして広げているのは cp ではなくシェルです。cp が受け取るのは、広げた後の名前の並びです。
  だから echo で先に確かめられます。

【cp は新しいファイルを作る】

  cp は、元と同じ中身の「新しいファイル」を作ります。所有者はコピーした人、
  更新時刻はコピーした時刻、権限は「元の権限から umask のビットを落としたもの」になります。

    cp app.conf x.conf          → 時刻はいま（元とずれる）
    cp -p app.conf x.conf       → 時刻と権限を元から写す（-p = --preserve=mode,ownership,timestamps）
    cp -a app.conf x.conf       → -p に加えてリンクなども保ち、ディレクトリは再帰する（-dR --preserve=all）

  一般ユーザが -p を付けても、所有者だけは写せません（他人のファイルを写すと自分のものになります）。
  所有者を変えられるのは root だけだからです。

【よくある誤答】

  cp *.conf backup/ だと、.secret.conf が漏れ、残りの2つも時刻がずれます。
  判定はその両方を観測して ✗ を出します。
