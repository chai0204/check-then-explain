経路上のディレクトリの「その他」に、通り抜け（x）だけを渡します。

    chmod o+x ~              # /home/lab : drwxr-x---  → drwxr-x--x
    chmod o-r ~/work/01      # ~/work/01 : drwxr-xr-x  → drwxr-x--x

    sudo -u alice cat /home/lab/work/01/memo.txt
    #=> alice へ: 鍵は2番の棚
    sudo -u alice ls /home/lab
    #=> ls: cannot open directory '/home/lab': Permission denied
    sudo -u alice ls /home/lab/work/01
    #=> ls: cannot open directory '/home/lab/work/01': Permission denied

【なぜ memo.txt の権限ではなかったか】

  /home/lab/work/01/memo.txt を開くには、途中のディレクトリすべてで
  「次の名前を引いて、その先へ進む」必要があります。それがディレクトリの x です。

    /home/lab          drwxr-x---   ← その他に x が無い。alice はここで止まっていた
    /home/lab/work     drwxr-xr-x
    /home/lab/work/01  drwxr-xr-x
    memo.txt           -rw-r--r--   ← ここは最初から誰でも読めた

【ディレクトリの r・w・x】

  ディレクトリの中身は「名前 → 実体（inode）」の対応表です。

    r  表を読める            … ls で名前の一覧が出る
    x  表を引いて先へ進める  … 名前を知っていれば、その先を開ける・cd できる
    w  表を書き換えられる    … 名前を作る・消す・変える（x も一緒に要る）

  x だけを渡すと「名前を知っている人だけが入れる」状態になります。
  ホームを 711（drwx--x--x）にして中の一部だけを他人に読ませるのは、この性質を使っています。

【よくある誤答】

  chmod 755 ~ でも alice は memo.txt を読めますが、ホームの一覧まで見えてしまいます。
  「読める」と「一覧できる」は別の権限なので、片方だけ渡すことができます。

【注意】

  ホームを o+x にすると、名前さえ知っていれば alice は ~/work の下にも届きます。
  ~/work 自体（drwxr-xr-x）は一覧も見えます。見せたくない段には r を渡さないでください。
