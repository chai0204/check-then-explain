  第5章のとおりに打ってきた人は、もうできています（lab check 04 で確かめられます）。
  演習を先にやっている人の vdb は、演習03 の6つの区画だけがあり、
  FSTYPE と LABEL が空です。

    $ lsblk -o NAME,SIZE,FSTYPE,LABEL /dev/vdb
    NAME    SIZE FSTYPE LABEL
    vdb       2G
    ├─vdb1  100M
    ├─vdb2  300M
    ├─vdb3  256M
    ├─vdb4  600M
    ├─vdb5  400M
    └─vdb6  391M

【やること】

  vdb の区画に、次のファイルシステムを作ってください。

      vdb1   VFAT（FAT32）
      vdb2   ext3
      vdb4   XFS     ラベル ROOT
      vdb5   Btrfs   ラベル VAR
      vdb6   ext4    ラベル HOME

  さらに vdb6 の ext4 で、root のために取ってある予約を 5%（既定）から 1% に
  減らしてください。vdb3 はスワップにします（演習07）。
  vdb2 に BOOT というラベルを付けないこと（練習機自身の /boot が BOOT という
  ラベルで探されているので、重なると再起動したときに取り違えます）。

【判定のしかた】

  各区画の先頭にあるファイルシステムの印を直接読みます。
  vdb6 は ext4 の管理情報から予約の割合を計算します。
  マウントしているかどうかは見ません。
