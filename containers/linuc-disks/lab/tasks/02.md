演習 02 — 消してしまったパーティションを取り戻す              影響度 B / 目安 12分

  どこで打つか: 練習機の中（student@linuc）。/dev/vdd を使います。

【いまの状態】（練習機の中で）

    $ sudo fdisk -l /dev/vdd
    Disk /dev/vdd: 256 MiB, 268435456 bytes, 524288 sectors
    Units: sectors of 1 * 512 = 512 bytes
    Sector size (logical/physical): 512 bytes / 512 bytes
    I/O size (minimum/optimal): 512 bytes / 512 bytes
    Disklabel type: dos
    Disk identifier: 0x4c696e75

    Device     Boot  Start    End Sectors  Size Id Type
    /dev/vdd2       206848 411647  204800  100M 83 Linux

  vdd2 しかありません。先頭の 100MiB には、以前 vdd1 がありました。
  誰かが表から vdd1 を消してしまいました。中には、合言葉を書いたファイル
  /aikotoba.txt がありました。消す前の表は、その人が sfdisk -d
  （表を文字にして書き出すコマンド）でホームに保存していました。

    $ cat ~/vdd-before.txt
    label: dos
    label-id: 0x4c696e75
    device: /dev/vdd
    unit: sectors
    sector-size: 512

    /dev/vdd1 : start=        2048, size=      204800, type=83
    /dev/vdd2 : start=      206848, size=      204800, type=83

【やること】

  vdd1 を取り戻し、/aikotoba.txt の合言葉を読める状態にしてください。
  ファイルシステムを作り直してはいけません（mkfs すると中身が消えます）。
  区画を作り直すときに「中の印（signature）を消すか」と聞かれたら、N と答えます（理由は第3章）。

【判定のしかた】

  /dev/vdd の表と、vdd1 の中身を直接読みます。
  マウントしているかどうかは見ません。
