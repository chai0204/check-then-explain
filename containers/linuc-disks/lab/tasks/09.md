【いまの状態】（練習機の中で）

  第10章のとおりに打ってきた人は、もうできています（lab check 09 で確かめられます）。
  演習を先にやっている人の練習機では、vdb の ROTA が 1 です。

    $ lsblk -d -o NAME,TRAN,ROTA,SIZE,MODEL
    NAME
        TRAN   ROTA  SIZE MODEL
    sda sata      0    1G QEMU HARDDISK
    sr0 sata      1  368K QEMU DVD-ROM
    vda virtio    1   20G
    vdb virtio    1    2G
    vdc virtio    1    1G
    vdd virtio    1  256M
    vde virtio    1  512M

  ROTA が 1 の装置を、カーネルは「回転する装置（HDD）」として扱います。
  vdb も sda も、外から見れば同じ種類のファイル（外の ~/vm/extra/*.qcow2）です。

【やること】

  vdb を、回転しない装置（SSD）としてカーネルに扱わせてください。
  ただし、再起動しても SSD のままであること。起動のたびに書き換える仕組みは、
  第10章の udev の規則（/etc/udev/rules.d/）で作ります。

【判定のしかた】

  いまの値が 0 か（lsblk の ROTA と同じもの）を見ます。次に、再起動の代わりに、
  起動したときに起きるのと同じことを1回だけ起こします。rotational をいったん 1 に戻し、
  udev に起動したときと同じ add の知らせを送って、値を読みます。手で書いただけの 0 は、
  ここで 1 に戻ります。判定のあと、値は判定の前に戻します。
