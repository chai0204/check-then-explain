ほぼ答えです。gdisk で打つキーを並べます（空行は Enter だけ）。

    sudo gdisk /dev/vdb
      o  Y
      n  (Enter) (Enter) +100M  ef00
      n  (Enter) (Enter) +300M  8300
      n  (Enter) (Enter) +256M  8200
      n  (Enter) (Enter) +600M  8300
      n  (Enter) (Enter) +400M  8300
      n  (Enter) (Enter) (Enter) (Enter)
      p
      w  Y

同じことを sgdisk（gdisk の一括版）なら1行で書けます。

    sudo sgdisk -o -n 1:0:+100M -t 1:ef00 -n 2:0:+300M -t 2:8300 -n 3:0:+256M -t 3:8200 \
                -n 4:0:+600M -t 4:8300 -n 5:0:+400M -t 5:8300 -n 6:0:0 -t 6:8300 /dev/vdb
