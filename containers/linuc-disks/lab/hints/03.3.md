ほぼ答えです。fdisk で打つキーは次のとおりです。

    sudo fdisk /dev/vdd
      n          新しいパーティション
      p          基本パーティション
      1          番号
      2048       最初のセクタ（Enter だけでも 2048 になる）
      206847     最後のセクタ（+100M でも同じ位置になる）
      N          ext4 の印を消さない（← ここが大事）
      w          書き込んで終わる

    sudo mount -o ro /dev/vdd1 /mnt
    cat /mnt/aikotoba.txt
    sudo umount /mnt

sfdisk に保存した表をそのまま流し込んでも戻ります（sudo sfdisk /dev/vdd < ~/vdd-before.txt）。
