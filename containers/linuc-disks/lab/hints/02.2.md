外すだけなら、こうです（usb_storage は uas に使われているので、uas ごと外す）。

    sudo modprobe -r uas
    lsmod | grep -E "usb_storage|uas"     # 何も出ない

でも挿し直すと、また読み込まれます。udev は挿されるたびに modprobe を呼ぶからです。
読み込ませないための設定は /etc/modprobe.d/ に置きます。書き方は2通りあります。

    blacklist 名前            … 「別名で探されたときは」この名前を候補から外す
    install 名前 /bin/false   … この名前を読み込もうとしたら、代わりに /bin/false を実行する

どちらで足りるかは、試して lab check 02 で確かめてください。
