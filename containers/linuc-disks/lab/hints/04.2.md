gdisk の n は4つ聞いてきます。

    Partition number         … Enter で次の番号
    First sector             … Enter で空きの先頭
    Last sector              … +100M のように大きさで答えられる。最後の1つは Enter で残り全部
    Hex code or GUID         … 種類。EF00 = ESP / 8200 = Linux swap / 8300 = Linux filesystem

種類の一覧は L で出ます。p で確かめてから w で書き込みます。
