5つ作るとこうなります。

    sudo mkfs.vfat -F 32 /dev/vdb1
    sudo mkfs -t ext3 /dev/vdb2
    sudo mkfs.xfs -L ROOT /dev/vdb4
    sudo mkfs.btrfs -L VAR /dev/vdb5
    sudo mkfs.ext4 -L HOME /dev/vdb6

できたら一覧で確かめます。

    lsblk -o NAME,FSTYPE,LABEL,UUID /dev/vdb

やり直すときのように、もうファイルシステムがある区画に作ると、mkfs.xfs と mkfs.btrfs は
「-f を付けよ」と断ります（-f を付けると上書きする）。mkfs.ext4 と mkfs -t ext3 は
「Proceed anyway? (y,N)」と聞くので、上書きしてよければ y と答えます（第5章）。

残りは予約です。ext4 の管理情報は tune2fs -l で読めます。
