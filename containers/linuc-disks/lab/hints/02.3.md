ほぼ答えです。fdisk で打つキーは次のとおりです。

    sudo fdisk /dev/vdd
      n          新しいパーティション
      p          基本パーティション（プライマリパーティション）
      1          番号
      2048       最初のセクタ（Enter だけでも 2048 になる）
      206847     最後のセクタ（+100M でも同じ位置になる）
      N          ext4 の印を消さない（← ここが大事）
      w          書き込んで終わる

    sudo mount /dev/vdd1 /mnt
    cat /mnt/aikotoba.txt
    sudo umount /mnt

別のやり方: 保存した表を sfdisk にそのまま流し込んでも戻ります。< は、ファイルの中身をコマンドに読ませる書き方です
（> の逆向きのリダイレクト。主題1.03 第7章）。

    sudo sfdisk /dev/vdd < ~/vdd-before.txt
