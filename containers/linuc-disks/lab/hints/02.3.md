詰まるところが2つあります。

【1つ目】設定を書いても、udev は起動したときに読んだ設定を使い続けます。
         書いたあとは udev を再起動してください（練習機ごと再起動しても同じ）。

    sudo systemctl restart systemd-udevd

【2つ目】blacklist usb_storage だけでは止まりません。
         挿した USB メモリは uas という別のドライバの候補にもなっていて、uas は usb_storage に
         依存しています。依存として読み込まれるものには blacklist は効きません。

    modprobe --show-depends uas

止めるなら、読み込みそのものを失敗させる install を使います。

    echo 'install usb_storage /bin/false' | sudo tee /etc/modprobe.d/lab-usb.conf
    sudo systemctl restart systemd-udevd
    sudo modprobe -r uas
