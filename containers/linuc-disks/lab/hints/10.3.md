詰まるところが2つあります。

【1つ目】blacklist usb_storage だけでは止まりません。
         挿した USB メモリは uas という別のドライバの候補にもなっていて、uas は usb_storage に
         依存しています。依存として読み込まれるものには blacklist は効きません。

    modprobe --show-depends uas

  止めるなら uas も blacklist に書くか、読み込みそのものを失敗させる install を使います。

    install usb_storage /bin/false      … modprobe で読み込もうとすると、代わりに /bin/false が走って失敗する

【2つ目】udev は、/etc/modprobe.d に「ファイルが増えた・消えた」ことには自分で気づきますが、
         tee や > で「すでにあるファイルの中身だけを書き換えた」ことには気づきません（前の中身のまま動く）。
         書き換えたときは udev を再起動してください（練習機ごと再起動しても同じ）。

    sudo systemctl restart systemd-udevd

最後に、いま読み込まれている分を外すのを忘れずに。

    sudo modprobe -r uas
