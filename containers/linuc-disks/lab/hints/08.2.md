作って、ext4 を作って、マウントするまで:

    sudo pvcreate /dev/vdc /dev/sda
    sudo vgcreate vg0 /dev/vdc /dev/sda
    sudo lvcreate -L 600M -n data vg0
    sudo mkfs.ext4 /dev/vg0/data
    sudo mkdir /srv/data
    sudo mount /dev/vg0/data /srv/data

ここから lvextend で広げます。広げたあと df -h /srv/data を見てください。
lvs の大きさと df の大きさは、同じものを測っていません。
