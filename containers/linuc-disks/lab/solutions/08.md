一般ユーザにマウントを許すのは、sudo ではなく /etc/fstab の行のオプションです。

    sudo mkdir -p /media/cdrom
    echo "/dev/sr0  /media/cdrom  iso9660  ro,user,noauto  0  0" | sudo tee -a /etc/fstab
    sudo systemctl daemon-reload

    mount /media/cdrom                    # student のまま
    mount | grep /media/cdrom
    #=> /dev/sr0 on /media/cdrom type iso9660 (ro,nosuid,nodev,noexec,relatime,…,user=student)
    cat /media/cdrom/README.TXT
    umount /media/cdrom

【オプション】

    user     一般ユーザがマウントできる。外せるのはマウントした本人と root だけ
             （誰でも外せるようにするなら users）。nosuid,nodev,noexec も暗に付く
    noauto   起動時と mount -a ではマウントしない（メディアが入っていないこともある装置向け）
    ro       読み取り専用

【6列の意味】

    /dev/sr0   /media/cdrom   iso9660   ro,user,noauto   0      0
    何を       どこに          種類      オプション        dump   fsck の順番（0 は調べない）

【systemctl daemon-reload について】

  起動時のマウントは systemd が /etc/fstab から作ったユニットで行います。
  書き換えたら daemon-reload で読み直させます（mount コマンド自体は毎回 /etc/fstab を読みます）。
