材料（PV）→ 池（VG）→ 箱（LV）→ 中身（ext4）の順に作り、箱と中身を両方広げます。

    sudo pvcreate /dev/vdc /dev/sda
    sudo vgcreate vg0 /dev/vdc /dev/sda
    sudo lvcreate -L 600M -n data vg0
    sudo mkfs.ext4 /dev/vg0/data
    sudo mkdir /srv/data
    sudo mount /dev/vg0/data /srv/data
    df -h /srv/data
    #=> /dev/mapper/vg0-data  574M   24K  532M   1% /srv/data

【箱だけを広げると】

    sudo lvextend -L +600M vg0/data       # いまより 600MiB 大きく（1200MiB = 1.17GiB）
    sudo lvs vg0/data                     # 1.17g になっている
    df -h /srv/data                       # 574M のまま ← 中身は広がっていない

【中身も広げる】

    sudo resize2fs /dev/vg0/data          # マウントしたままでよい
    df -h /srv/data                       # 箱と同じくらいに広がる

  lvextend に -r を付けると、2つを続けてやります（sudo lvextend -r -L +600M vg0/data）。

【2台にまたがっていることを見る】

    sudo lvs -o lv_name,lv_size,devices vg0
    #=> data  1.17g /dev/vdc(0)
    #   data  1.17g /dev/sda(0)

【縮めるとき】

  ext4 は縮められますが、マウントを外してからです（第9章のとおり、先に umount してから lvreduce -r を打つ）。
  XFS は縮められません（fsadm: Xfs filesystem shrinking is unsupported.）。
