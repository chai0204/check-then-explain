第2章の流れ（区切る → 作る → つなぐ → 書く → 外す）を、vde でなぞります。

    sudo fdisk /dev/vde
      Command (m for help): n
      Select (default p): p
      Partition number (1-4, default 1): 1
      First sector (2048-1048575, default 2048):                        ← Enter
      Last sector, +/-sectors or +/-size{K,M,G,T,P} (2048-1048575, default 1048575):   ← Enter（全部）
      Command (m for help): w
    lsblk /dev/vde                        # vde1 ができている
    sudo mkfs.ext4 /dev/vde1
    sudo mount /dev/vde1 /mnt
    echo "こんにちは" | sudo tee /mnt/hello.txt
    sudo umount /mnt

【student のまま書きたいとき】

  作ったばかりの ext4 のいちばん上のディレクトリは、root のもの（rwxr-xr-x）です。
  持ち主を変えると、student のまま書けます。この変更は vde1 の ext4 の中に残ります。

    sudo mount /dev/vde1 /mnt
    sudo chown student:student /mnt
    echo "こんにちは" > /mnt/hello.txt
    sudo umount /mnt

【判定が見ているもの】

  外したあとでも、hello.txt は vde1 の ext4 の中に残っています。判定は debugfs
  （ext4 をマウントせずに読む道具）で、vde1 の中に /hello.txt があるかを確かめます。
  マウントする前の /mnt に書いてしまった場合（hello.txt は vda1 の /mnt に入る）は、
  vde1 の中に無いので、判定で分かります。
