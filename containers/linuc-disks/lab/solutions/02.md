外したドライバは、次に挿したとき udev が読み込み直します。
止めるには「読み込む側」が読む表（/etc/modprobe.d/）に書き、udev にその表を読み直させます。

    echo 'install usb_storage /bin/false' | sudo tee /etc/modprobe.d/lab-usb.conf
    sudo systemctl restart systemd-udevd
    sudo modprobe -r uas                  # いま読み込まれている分を外す（usb_storage も一緒に外れる）

  外で挿し直して確かめます。

    virsh detach-device linuc ~/vm/extra/usb-a.xml
    virsh attach-device linuc ~/vm/extra/usb-a.xml

    lsusb -t
    #=>     |__ Port 001: Dev 00N, If 0, Class=Mass Storage, Driver=[none], 5000M
    lsmod | grep -E "usb_storage|uas"      # 何も出ない

  USB 機器としては見えたまま、ドライバが付かないのでディスク（/dev/sdb）になりません。

【なぜ blacklist usb_storage では足りないのか】

  挿した USB メモリの「別名」（modalias）は、2つのドライバに当てはまります。

    modprobe --resolve-alias $(cat /sys/bus/usb/devices/2-1:1.0/modalias)
    #=> uas
    #   usb_storage

  blacklist usb_storage は「別名で探したときに usb_storage を候補から外す」だけです。
  uas はそのまま読み込まれ、uas は usb_storage に依存しているので、依存として読み込まれます。

    modprobe --show-depends uas
    #=> insmod …/usb-storage.ko.zst
    #   insmod …/uas.ko.zst

  blacklist で止めるなら、uas と usb_storage の両方を書きます。
  install 名前 /bin/false は、その名前を読み込もうとした時点で失敗させるので、依存でも止まります。

【なぜ書いただけでは効かないのか】

  udev は起動したときに /etc/modprobe.d/ を読み、そのあとは読み直しません。
  udevadm control --reload でも読み直しません（規則は読み直すが、modprobe の設定は別）。
  systemctl restart systemd-udevd か、練習機の再起動が要ります。

【戻すとき（第8章で USB メモリを使う前に）】

    sudo rm /etc/modprobe.d/lab-usb.conf
    sudo systemctl restart systemd-udevd
