パーティションテーブルは目次です。行を消しても中身は残っているので、
同じ位置・同じ大きさで行を書き戻せば、中身はそのまま読めます。

    cat ~/vdd-before.txt
    #=> /dev/vdd1 : start=        2048, size=      204800, type=83
    #   /dev/vdd2 : start=      206848, size=      204800, type=83

    sudo fdisk /dev/vdd
      Command (m for help): n
      Select (default p): p
      Partition number (1,3,4, default 1): 1
      First sector (2048-524287, default 2048):                    ← Enter
      Last sector, +/-sectors or +/-size{K,M,G,T,P} (2048-206847, default 206847):   ← Enter
      Partition #1 contains a ext4 signature.
      Do you want to remove the signature? [Y]es/[N]o: N           ← ここで N
      Command (m for help): w

    sudo mount /dev/vdd1 /mnt
    cat /mnt/aikotoba.txt
    #=> 合言葉: やまびこ
    sudo umount /mnt

  最後のセクタは、空きの終わり（vdd2 の手前）がちょうど 206847 なので Enter で揃います。

【sfdisk で書き戻す（別のやり方）】

  保存した表を、そのまま sfdisk に流し込んでも同じです。< は、ファイルの中身をコマンドに読ませる
  書き方です（> の逆向きのリダイレクト。主題1.03 第7章）。

    sudo sfdisk /dev/vdd < ~/vdd-before.txt

【Y と答えてしまったら】

  Y と答えると、fdisk は中の ext4 の「印」を消します。ファイルは残っていても、印が無いので
  mount は ext4 と認めず、読めなくなります。外（lab@host）で練習機を最初の状態に戻して、
  演習02 を始めからやり直してください。

    vm reset --yes
    vm start

  vm reset --yes は、vdd だけでなく練習機のディスクを全部、最初の状態に戻します。演習の進捗（lab ls の ✔）は
  残りますが、ディスクの上のものは全部消えます。
    ・理論編の途中なら、章で作ったもの（vdb・vdc・sda の区画とファイルシステム、/etc/fstab に足した行、
      スワップ、rotational を書く udev の規則など）も消えます。章は前の章の状態の上に積み上がっているので、
      本文と同じ画面に戻すには、第1章から打ち直します。
    ・演習だけを進めている人は、前の演習の状態を使う演習（演習03 の区画を使う 04・07 など）をやり直します。

【参考（このコースの範囲の外）: 印を書き戻して読む】

  消える印は、ext4 の管理情報の中心（スーパーブロック）の中の2バイト（区画の先頭から 1080 バイト目の
  53 ef）だけです。著者は、この2バイトを dd で書き戻して元の ext4 として読めることを確かめました
  （e2fsck -fn で異常なし）。ただし使う道具（dd の書き込み・printf のバイトの書き方）はこのコースの
  範囲の外で、書く場所を1バイト間違えると壊すので、ここでは手順を載せません。最初から N と答えるのが確実です。
