形を作り（mkswap）、使い始め（swapon）、起動時の一覧（/etc/fstab）に書きます。

    sudo mkswap -L SWAP /dev/vdb3
    #=> Setting up swapspace version 1, size = 256 MiB (268431360 bytes)
    #   LABEL=SWAP, UUID=…（作るたびに変わる）
    free -h                               # まだ Swap: 0B
    sudo swapon /dev/vdb3
    swapon --show
    #=> /dev/vdb3 partition 256M   0B   -2

    echo "UUID=$(sudo blkid -s UUID -o value /dev/vdb3)  none  swap  sw  0  0" | sudo tee -a /etc/fstab

【書いた行が効くかを、再起動せずに確かめる】

    sudo swapoff /dev/vdb3
    sudo swapon -a                        # /etc/fstab のスワップを全部有効にする（起動時と同じ）
    swapon --show

【デバイス名で書かない理由】

  /dev/vdb3 という名前は、カーネルが見つけた順に付けた呼び名です。ディスクを足したり
  差し替えたりすると、別の領域が /dev/vdb3 になりえます。スワップは中身を消して上書きするので、
  間違った領域を指すと、そこにあったデータが壊れます。UUID は mkswap がその領域に書いた印です。
