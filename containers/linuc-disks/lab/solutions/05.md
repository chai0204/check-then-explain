ファイルのままのディスクのイメージは、ループデバイスを通してマウントします。

    sudo mount -o loop ~/old-usb.img /mnt
    losetup -l                            # loop0 の後ろに /home/student/old-usb.img
    ls -l /mnt                            # message.txt がある
    cp /mnt/message.txt ~/
    sudo umount /mnt                      # ループデバイスも一緒に片づく（AUTOCLEAR）
    cat ~/message.txt

【中の種類を確かめる】

  中は FAT（vfat）です。mount は中の印を読んで種類を自分で見分けるので、種類を書かずにマウントできました
  （第6章で USB メモリをマウントしたときと同じ）。中の種類は blkid でも読めます（ファイルにも使えます）。

    sudo blkid ~/old-usb.img

【-o loop を付けずに mount したら】

  いまの mount は、ファイルを渡されると自分でループデバイスを用意するので、-o loop を省いても
  マウントできます（losetup -l に、同じように loop0 が出る）。-o loop は、それをはっきり頼む書き方です。
