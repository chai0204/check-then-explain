ファイルのままのディスクのイメージは、ループデバイスを通してマウントします。

    sudo mount -o loop ~/old-usb.img /mnt
    losetup -l                            # loop0 の後ろに /home/student/old-usb.img
    ls -l /mnt                            # message.txt がある
    cp /mnt/message.txt ~/
    sudo umount /mnt                      # ループデバイスも一緒に片づく（AUTOCLEAR）
    cat ~/message.txt

【mount の種類の指定は要らない】

  中は FAT（vfat）ですが、-t vfat を付けなくても、mount が中の印を読んで種類を見分けます。
  確かめるなら blkid で読めます（ファイルにも blkid は使えます）。

    sudo blkid ~/old-usb.img

【-o loop を付けずに mount したら】

  いまの mount は、ファイルを渡されると自分でループデバイスを用意することが多いので、
  -o loop を省いてもマウントできることがあります。試験では -o loop と答えます。
