【sgdisk で1行にする】

    sudo sgdisk -o -n 1:0:+100M -t 1:ef00 -n 2:0:+300M -t 2:8300 -n 3:0:+256M -t 3:8200 \
                -n 4:0:+600M -t 4:8300 -n 5:0:+400M -t 5:8300 -n 6:0:0 -t 6:8300 /dev/vdb

【確かめる】

    lsblk -o NAME,SIZE,PARTTYPENAME /dev/vdb
    sudo parted /dev/vdb print            # ESP には boot, esp、スワップには swap の旗が出る

【ESP の「種類」は何のためか】

  EF00（EFI System、C12A7328-…）は、UEFI の仕様が決めた「この区画が ESP だ」という印です。
  インストーラや OS の道具（lsblk・parted の boot, esp の旗など）は、これで ESP を見分けます。

  一方、起動のときのファームウェアは /etc/fstab もマウントも知りません。ふだんは NVRAM に登録した
  候補（efibootmgr の HD(15,GPT,<PARTUUID>,…)/File(\EFI\ubuntu\shimx64.efi)）で、区画の番号・固有の
  番号（PARTUUID）とファイルのパスを指して読みます（第4章）。
  中身を FAT にするのは第5章（演習04）、マウントは第6・7章で、どちらも別の段の話です。
