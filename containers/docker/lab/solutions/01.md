練習機の中（student@linuc）で打ちます。

    docker run -d --name ex01 --memory 96m alpine:3.24.2 sleep 3600
    docker exec ex01 cat /sys/fs/cgroup/memory.max
    #=> 100663296                       ← コンテナの中からは、かごのいちばん上に見える
    cat /sys/fs/cgroup/system.slice/docker-$(docker inspect -f '{{.Id}}' ex01).scope/memory.max
    #=> 100663296                       ← 練習機からは system.slice の下の docker-ID.scope
    systemctl show -p MemoryMax docker-$(docker inspect -f '{{.Id}}' ex01).scope
    #=> MemoryMax=100663296

    lab check 01

  96m は 96 × 1024 × 1024 = 100663296 バイトです（m は 1000 倍ではなく 1024 倍）。
  コンテナ1つが1つのかご（cgroup）になり、上限はそのかごの memory.max というファイルに書かれます。
  このかごを作ったのは systemd です（この docker は cgroup ドライバが systemd）。
