  名前（ex03:base）は中身を指す札にすぎず、docker tag でいつでも付け替えられます。
  中身を1つに決めているのはダイジェストで、この docker では ID はダイジェストそのもの（一覧には先頭12文字だけを出す）です。
  alpine:3.24.2 という名前もまた札なので、名前で付け替えるより ID で付け替えるほうが確実です
  （第3章でやったように、alpine:3.24.2 自体が別の中身に付け替えられていることもありうるため）。
