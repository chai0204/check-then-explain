    docker run -d --name ex02 --init alpine:3.24.2 sleep 3600
    docker exec ex02 ps
    #=> PID 1 は /sbin/docker-init -- sleep 3600、sleep はその子

    lab check 02

  --init を付けると、docker は小さな init（docker-init。tini というプログラム）を PID 1 に置きます。
  docker-init は合図をブロックして待つ作り（ハンドラは登録しない）で、docker stop の TERM を受け取って子の sleep に中継し、
  sleep は TERM で終わります。docker-init はそれを終了コード 143（128 + 15）で報告します。docker stop は1秒ほどで終わります。

  --stop-timeout 1 のように待ち時間を短くしても速くはなりますが、TERM は届かず KILL で終わる（137）ので、
  この演習の判定は通りません。待ち時間を変えることと、合図を届けることは別です。
