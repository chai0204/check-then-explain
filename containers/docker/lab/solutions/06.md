  RUN の段は greet.sh を使わないので、COPY より前に置けます。前に置けば、それより前にあるのは FROM の層だけで、
  greet.sh が変わっても RUN の段の材料（命令と、それより前の段の層）は変わらず、前回の層が使われます。
