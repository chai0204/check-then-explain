練習機の中（student@linuc）で打ちます。

    docker run --rm -v ex04-data:/data alpine:3.24.2 sh -c 'echo "keep me" > /data/memo.txt'
    docker ps -a --filter volume=ex04-data       # 使っているコンテナは無い（--rm で消えた）
    docker volume inspect --format '{{.Mountpoint}}' ex04-data
    #=> /var/lib/docker/volumes/ex04-data/_data
    sudo cat /var/lib/docker/volumes/ex04-data/_data/memo.txt
    #=> keep me

    lab check 04

  コンテナの中で書いたものは、普通はコンテナの書き込み用の層（upperdir）に入り、コンテナと一緒に消えます。
  ボリュームをマウントした場所（/data）に書いたものだけは、練習機の /var/lib/docker/volumes/ex04-data/_data に入り、
  コンテナを消しても残ります。
