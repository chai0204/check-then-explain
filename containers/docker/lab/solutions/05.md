    #=> 80/tcp -> 10.0.2.15:8080
    sudo iptables -t nat -L DOCKER -n
    #=> DNAT … 10.0.2.15  tcp dpt:8080 to:172.17.0.x:80   （x は、そのとき動いているコンテナの数で変わる）

    lab check 05

  外（lab@host）からの curl は、QEMU の転送で練習機の enp0s16（10.0.2.15）の 8080 番に届き、
  nat 表の DNAT の規則で宛先がコンテナ（172.17.0.x:80）に書き換えられて、コンテナの httpd に届きます。
  -p 8080:80 と書くと 0.0.0.0（全部のアドレス）で待ち受けることになり、あなたの PC なら LAN からも届きます。

  exec は、sh を httpd に置き換えて httpd を PID 1 にする書き方です（BusyBox の sh は、最後のコマンドなら exec が無くても置き換えます）。
  ただし BusyBox の httpd は TERM のハンドラを登録しないので、PID 1 のままだと docker stop は10秒待って KILL（137）になります。
  速く止めたいなら --init を付けます（第2章）。
