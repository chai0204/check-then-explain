    docker run -d --name ex07 --cap-add NET_ADMIN alpine:3.24.2 sleep 3600
    docker exec ex07 grep CapEff /proc/self/status
    #=> CapEff:	00000000a80435fb          ← 既定の a80425fb から CAP_NET_ADMIN の1ビットだけ増えた
    docker exec ex07 ip link add test0 type dummy
    docker exec ex07 ip link show test0

    lab check 07

  --privileged なら同じ操作も通りますが、全部のケーパビリティ・ほぼ全部の装置・seccomp と AppArmor の解除を
  まとめて渡すことになります。必要な1つ（CAP_NET_ADMIN）だけを足せば、渡したものを CapEff の差で説明できます。
  作った test0 は、ex07 の net の名前空間の中だけにあり、練習機の NIC は増えていません（ip link で確かめられます）。
