演習 05 — 練習機の外から届くように、ポートを公開する                影響度 B / 目安 12分

  練習機の中（student@linuc）で打ちます。判定は外（lab@host）から接続して確かめます。

【やること】

  busybox:1.38.0 の httpd で、1行の HTML

    hello from ex05

  を配るコンテナを、名前 ex05 で動かしてください。そして、外（lab@host）で

    curl http://127.0.0.1:8080/

  を打つとこの1行が返るように、ポートを公開します（この檻は、外の 127.0.0.1:8080 を練習機の 8080 番へ転送しています）。
  ただし、練習機のすべてのアドレス（0.0.0.0）では待ち受けず、外向きの NIC のアドレス 10.0.2.15 だけにしてください。

【できたら】

    lab check 05      （練習機の中でも外でも打てます）
