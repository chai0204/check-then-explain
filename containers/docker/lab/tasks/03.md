演習 03 — 付け替えられた名前を、中身に戻す                          影響度 B / 目安 8分

  練習機の中（student@linuc）で打ちます。

【準備】

  まず、次の1行で ex03:base という名前を作ります（いまは BusyBox の中身を指しています）。

    docker tag busybox:1.38.0 ex03:base

【やること】

  ex03:base という名前を、Alpine 3.24.2 の中身に付け替えてください。
  Alpine 3.24.2 の中身のダイジェストは次のとおりです。

    sha256:294b683cb724975bec92580e1e685676bd4b50bda910ddb8c51d4cabeaec77e6

  判定では、ex03:base が指している中身のダイジェストと、
  docker run --rm ex03:base cat /etc/alpine-release の結果を見ます。

【できたら】

    lab check 03
