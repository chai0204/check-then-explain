演習 02 — docker stop が TERM で終わるコンテナを動かす               影響度 B / 目安 10分

  練習機の中（student@linuc）で打ちます。

【やること】

  alpine:3.24.2 で sleep 3600 を動かすコンテナを、名前 ex02 で起動してください。
  ただし docker stop したときに、10秒待って KILL されるのではなく、
  TERM の合図で終わる（終了コードが 137 にならない）ようにします。

  先に、何も付けずに起動したコンテナで docker stop がどう終わるかを確かめてから進めると、違いが分かります。

【判定のしかた】

  判定は、動いている ex02 に実際に docker stop を打ち、かかった時間と終了コードを見ます。
  見終わったら docker start ex02 で起動し直しておきます（判定の後も ex02 は動いています）。

    lab check 02

  やり直すときは  docker rm -f ex02  で消してから、もう一度起動してください。
