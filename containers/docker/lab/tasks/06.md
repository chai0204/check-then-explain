演習 06 — キャッシュが効く順に Dockerfile を並べ替える              影響度 B / 目安 15分

  練習機の中（student@linuc）で打ちます。

【準備】

  次をそのまま打ちます（~/ex06 に greet.sh と Dockerfile ができ、1回ビルドします）。

    mkdir -p ~/ex06 && cd ~/ex06
    echo 'echo "hello, $(cat /opt/ready.txt)"' > greet.sh
    printf '%s\n' 'FROM alpine:3.24.2' 'COPY greet.sh /opt/greet.sh' 'RUN sleep 8 && echo "ready" > /opt/ready.txt' 'CMD ["sh", "/opt/greet.sh"]' > Dockerfile
    cat Dockerfile
    docker build -t ex06:1 .
    docker run --rm ex06:1

  （Dockerfile は1行ずつの printf で書いています。行頭に空白が入っても崩れないように。エディタ（nano・vim）で書いても構いません）

【やること】

  いまは greet.sh を少し直すたびに、8秒かかる RUN の段まで作り直されます（確かめてください）。
  Dockerfile を並べ替えて、greet.sh を直しても RUN の段が作り直されない（CACHED になる）ようにしてください。
  出来上がったイメージは、いまと同じく hello, ready と出すこと。

  判定では、~/ex06 を別の場所に写して greet.sh を書き換え、実際にビルドして、8秒かかる RUN の段（sleep 8）が CACHED になるかを見ます。
