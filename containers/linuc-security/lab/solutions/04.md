deploy に journalctl だけを sudo で許します。/etc/sudoers 本体は触りません。

    echo 'deploy ALL=(root) NOPASSWD: /usr/bin/journalctl' | sudo tee /etc/sudoers.d/deploy
    sudo chmod 440 /etc/sudoers.d/deploy        # ← これを忘れると丸ごと無視される
    sudo visudo -c                               #=> すべて parsed OK

確かめます（deploy になって打つ）。

    sudo -u deploy -i
    sudo -n -l                     #=> (root) NOPASSWD: /usr/bin/journalctl
    sudo -n journalctl -n 1        #=> ログが1行出る（許可）
    sudo -n id                     #=> sudo: a password is required（拒否）
    exit

【罠 — 権限が緩いと黙って無視される】
  このドロップインを 644 や 666 で作ると、sudo はこう言って無視します。

    sudo: /etc/sudoers.d/deploy is world writable

  そして「許したはずの journalctl も通らない」状態になります。440 にします。
  （logrotate が group 書き込み可の設定を無視するのと同じ考え方です。）

【要点】sudoers は visudo -c で構文を、ls -l で権限（440）を必ず確かめます。
