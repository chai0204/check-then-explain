SUID を棚卸しして、仕込まれた1つを無効化します。

    sudo find / -xdev -perm -4000 -type f 2>/dev/null
    #=> /usr/bin/su, /usr/bin/sudo, /usr/bin/passwd ... /usr/local/bin/catfile

    ls -l /usr/local/bin/catfile
    #=> -rwsr-xr-x 1 root root ... /usr/local/bin/catfile

    /usr/local/bin/catfile /etc/shadow | head -1    # 一般ユーザなのに読めてしまう
    #=> root:*:...

SUID ビットだけを外します（実行権は残す）。

    sudo chmod u-s /usr/local/bin/catfile
    ls -l /usr/local/bin/catfile
    #=> -rwxr-xr-x ...（s が x に戻った）
    /usr/local/bin/catfile /etc/shadow
    #=> cat: /etc/shadow: Permission denied

【-perm 4000 と -perm -4000 の違い】

    sudo find / -xdev -perm  4000 -type f 2>/dev/null | wc -l   #=> 0（ちょうど 4000 は無い）
    sudo find / -xdev -perm -4000 -type f 2>/dev/null | wc -l   #=> 15 など

  実在の SUID は -rwsr-xr-x のように他のビットも立っているので「ちょうど 4000」には
  一致しません。「4000 を含む」の -4000 を使います。SGID は -perm -2000、両方は -perm /6000。

【要点】SUID は「実行する人」ではなく「ファイルの持ち主」の権限で動きます。
だから持ち主が root の SUID は、誰が実行しても root になります。棚卸しが要るのはこのためです。
