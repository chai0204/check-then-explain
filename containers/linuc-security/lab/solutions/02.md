退職者 olduser を、鍵を持っていても入れないようにします。

まず、ロックだけでは足りないことを確かめます。

    sudo passwd -l olduser          # パスワードをロック
    sudo passwd -S olduser          #=> olduser L ...（L = ロック）
    sudo grep ^olduser /etc/shadow | cut -c1-20
    #=> olduser:!$y$...             # 先頭に ! が付いただけ

  これではパスワードで入れないだけで、SSH 鍵を持つ人はそのまま入れます。

アカウントそのものに有効期限を切ります。これが本当の無効化です。

    sudo usermod -e 1 olduser       # 有効期限 = 1970-01-02（過去）
    sudo chage -l olduser | grep -i 'アカウント有効期限\|Account expires'
    #=> アカウント有効期限 : Jan 02, 1970

  これで olduser は鍵でも入れません。鍵の認証は通りますが、その後で PAM のアカウント検査
  （pam_unix）が期限切れを見て拒否します（Your account has expired と表示されて切られる）。
  日付で指定するなら chage -E 2020-01-01 olduser でも同じです。

【要点】
  passwd -l … パスワードという「鍵の1つ」を無効にするだけ
  usermod -e / chage -E … アカウントそのものを無効にする（全部の入口が閉じる）
