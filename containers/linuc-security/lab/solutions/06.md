deploy が鍵でログインできるようにします。

    ssh-keygen -t ed25519 -f /tmp/deploy_key -N ''
    sudo install -d -m 700 -o deploy -g deploy /home/deploy/.ssh
    sudo tee /home/deploy/.ssh/authorized_keys < /tmp/deploy_key.pub >/dev/null
    sudo chown deploy:deploy /home/deploy/.ssh/authorized_keys
    sudo chmod 600 /home/deploy/.ssh/authorized_keys

    ssh -i /tmp/deploy_key -o StrictHostKeyChecking=no deploy@localhost id
    #=> uid=1002(deploy) ...

【罠 — 権限が緩いと sshd は鍵を黙って無視する（StrictModes）】
  authorized_keys を置いても、ホームや .ssh や鍵ファイルが本人以外に書ける状態だと、
  sshd はその鍵を使いません（エラーも出さずパスワードを聞きに来ます）。

    ls -ld /home/deploy /home/deploy/.ssh      # /home/deploy は group/other 書き込み不可、.ssh=700
    ls -l  /home/deploy/.ssh/authorized_keys   # 600・持ち主 deploy

【要点】公開鍵認証は「公開鍵を置く」だけでなく「その置き場所を本人しか触れない」ことまで含めて成立します。
