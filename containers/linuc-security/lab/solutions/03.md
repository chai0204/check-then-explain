余計な待ち受け 2323 を止め、二度と上がらないようにします。

    sudo ss -ltnp | grep 2323
    #=> LISTEN ... 0.0.0.0:2323 ... users:(("ncat",pid=...))
    systemctl status lab-echo.service      # これが 2323 を出しているサービス

「いま止める」と「次の起動で上がらない」を両方やります。--now が両方まとめてやります。

    sudo systemctl disable --now lab-echo.service
    systemctl is-active  lab-echo.service    #=> inactive
    systemctl is-enabled lab-echo.service    #=> disabled
    ss -ltn | grep 2323                       #=> （何も出ない）

【片方だけだとどうなるか】
    systemctl stop lab-echo     … いまは止まるが enabled のまま → 次の起動で復活
    systemctl disable lab-echo  … 次の起動では上がらないが、いまは動いたまま
  だから両方、または --now を使います。

【要点】ポート番号 → プロセス（ss -p / lsof / fuser）→ サービス（systemctl status）と辿れます。
