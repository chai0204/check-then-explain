deploy の鍵束で、ファイルを暗号化して復号します。

    sudo -u deploy -i        # deploy のログインシェルに入る

    gpg --batch --pinentry-mode loopback --passphrase '' \
        --quick-gen-key 'Deploy <deploy@linuc.example>'
    gpg --list-keys
    #=> pub ed25519 ... uid Deploy <deploy@linuc.example> / sub cv25519 [E]

    echo '社外秘のメモ' > ~/secret.txt
    gpg --encrypt --recipient deploy@linuc.example ~/secret.txt    # ~/secret.txt.gpg
    gpg --decrypt ~/secret.txt.gpg
    #=> 社外秘のメモ

    ls ~/.gnupg
    #=> pubring.kbx（公開鍵束） private-keys-v1.d（秘密鍵） trustdb.gpg  S.gpg-agent（gpg-agent）

    exit

【要点】
  公開鍵で暗号化し、対応する秘密鍵でしか復号できません（相手に渡すのは公開鍵だけ）。
  鍵束・信頼データベース・gpg-agent のソケットはすべて ~/.gnupg に置かれます。
  TCG の練習機では RSA 4096 の鍵生成に数秒〜十数秒かかります。既定の ed25519 なら 0.1 秒ほどです。
  パスフレーズだけで暗号化する共通鍵方式なら gpg -c（--symmetric）を使います（鍵ペアは要りません）。
