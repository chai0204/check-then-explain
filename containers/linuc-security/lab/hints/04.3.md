効かないときは持ち主と権限です。sudo は other が書けるファイルと、
root 以外のグループが書けるファイルを読まずに飛ばします（root:root の 664 は読まれる）。

    ls -l /etc/sudoers.d/deploy
    sudo chown root:root /etc/sudoers.d/deploy
    sudo chmod 440 /etc/sudoers.d/deploy

確かめ方（deploy になって打つ）:

    sudo -u deploy -i
    sudo -n journalctl -n 1     #=> 通る
    sudo -n id                  #=> a password is required（拒否）
    exit
