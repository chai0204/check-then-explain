この演習で足すのは「2323 を落とす DROP を1行」だけです。INPUT の方針（policy）は ACCEPT のまま変えません。
方針は変えずに、落としたいものだけを足す限り、いま使っている 22 番の ssh は巻き込まれません。

締め出しが起きるのは、INPUT の方針を DROP にしたり、22 番を落とすルールを書いたときです。
方針を DROP にする（許可したものだけ通す）なら、先に 22 番と確立済みの接続を通すルールを入れてから
方針を変える、という順番が要ります。

    sudo iptables -L INPUT -n --line-numbers     # いまは空（policy ACCEPT）
