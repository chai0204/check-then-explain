演習 01 — SUID の棚卸しをする                                     影響度 B / 目安 12分

  この演習はシステム全体を触ります。練習機の中（student@linuc）で作業します。
  戻すには、外の端末で vm reset --yes（練習機が工場出荷時に戻ります）。

【いまの状態を見てください】

  この練習機には、本来 SUID であってはいけないファイルが1つ仕込まれています。
  まず SUID の立ったファイルを全部出してください。

    sudo find / -xdev -perm -4000 -type f 2>/dev/null

  見慣れない1つがいるはずです。それが何をするものか確かめてください。

    ls -l /usr/local/bin/catfile
    /usr/local/bin/catfile /etc/shadow | head -2      ← 一般ユーザなのに読めてしまう

【やること】

  /usr/local/bin/catfile から SUID ビットを外してください（ファイルは消さなくて構いません）。
  外したあと、一般ユーザでは /etc/shadow が読めなくなることを確かめてください。

  なぜ -perm 4000 ではなく -perm -4000 なのか、両方打って数を比べると分かります。

    sudo find / -xdev -perm  4000 -type f 2>/dev/null | wc -l
    sudo find / -xdev -perm -4000 -type f 2>/dev/null | wc -l
