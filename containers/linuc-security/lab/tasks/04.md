演習 04 — sudo を1コマンドだけに絞る                              影響度 B / 目安 12分

  この演習はシステム全体を触ります。練習機の中（student@linuc）で作業します。
  戻すには、外の端末で vm reset --yes。

【いまの状態を見てください】

  deploy というユーザがいます。いまは sudo を一切使えません。

    sudo -l -U deploy

【やること】

  deploy に、ログを読むための journalctl だけを、パスワードなしで sudo で許してください。
  それ以外（sudo id など）は従来どおり拒否されるようにします。

      許す:   sudo journalctl …
      許さない: sudo id / sudo bash / そのほか全部

  設定は /etc/sudoers 本体ではなく /etc/sudoers.d/ に置いてください。
  置いたら必ず検査してください。visudo -c は構文と、ファイルの持ち主・権限を確かめます。
  （いまの sudo は壊れた行を捨てて動きますが、自分を許す行を壊すとその権限を失います）

    sudo visudo -c

【詰まったら】

  書いたのに効かないときは、まずその設定ファイルの持ち主と権限を見てください。
  sudo は、other が書けるファイル（world writable）と、root 以外のグループが書けるファイルを
  読まずに飛ばします（本文の第5章で実測）。推奨は 440・持ち主 root:root です。

    ls -l /etc/sudoers.d/
    sudo visudo -c
