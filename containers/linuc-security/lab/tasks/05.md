演習 05 — ファイアウォールで塞ぐ（管理の ssh は残す）            影響度 B / 目安 12分

  この演習はシステム全体を触ります。練習機の中（student@linuc）で作業します。

  ★この演習はネットワークを塞ぎます。順番を間違えると自分が締め出されます。
    締め出されても練習機は消えません。戻し方を先に覚えてください。
      - 外の端末（lab@host）で:  vm ssh          ← まだ入れるか試す
      - それでも駄目なら:        vm console      ← シリアルコンソール（画面）から入る
      - 最後の手段:              vm reset --yes  ← 練習機を工場出荷時に戻す
    判定（lab check 05）は外のコンテナが qemu-guest-agent 経由で行うので、
    ネットワークを塞いでも採点はできます。

【やること】

  iptables で、2323/tcp への新規接続を落としてください（DROP）。
  ただし 22/tcp（あなたがいま使っている管理用 ssh）は絶対に塞がないこと。

    sudo iptables -L INPUT -n --line-numbers       ← いまのルール（空のはず）

  塞いだら、次の2つを両方確かめてください。

      2323 に繋がらなくなった      例: timeout 3 bash -c '</dev/tcp/127.0.0.1/2323'
      22 はまだ生きている          外の端末で vm ssh が通る

【できたら】
