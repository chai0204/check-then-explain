演習 03 — 使っていない待ち受けを止める                            影響度 B / 目安 10分

  この演習はシステム全体を触ります。練習機の中（student@linuc）で作業します。
  戻すには、外の端末で vm reset --yes。

【いまの状態を見てください】

  この練習機は、22（ssh）と 53（名前解決）のほかに、もう1つ余計なポートで待ち受けています。

    ss -ltn

  2323 が開いています。何のプロセスか、どのサービスから来ているかを辿ってください。

    sudo ss -ltnp | grep 2323
    sudo lsof -iTCP:2323 -sTCP:LISTEN
    systemctl status lab-echo.service

【やること】

  この lab-echo サービスを止めて、さらに再起動しても二度と上がらないようにしてください。
  そのあと ss -ltn に 2323 が出ないことを確かめてください。

  「いま止める」と「次の起動でも上がらない」は別の操作です。両方やってください。

【できたら】

    lab check 03
