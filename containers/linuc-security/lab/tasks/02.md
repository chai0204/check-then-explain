演習 02 — 退職者のアカウントを本当に無効化する                    影響度 B / 目安 12分

  この演習はシステム全体を触ります。練習機の中（student@linuc）で作業します。
  戻すには、外の端末で vm reset --yes。

【いまの状態を見てください】

  olduser という、もう使っていないアカウントがあります。まだ生きています。

    sudo passwd -S olduser        ← P = パスワードが使える
    sudo chage -l olduser         ← 「アカウント有効期限」を見る

【やること】

  olduser が二度とログインできないようにしてください。

  判定は「パスワードをロックしただけ」では通りません。
  それだと SSH 鍵を持っている人はそのまま入れてしまうからです（本文の第2章で実測しています）。
  アカウントそのものを無効化してください。

  ヒントが要るなら:

    lab hint 02

【できたら】

    lab check 02
