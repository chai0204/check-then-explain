演習 06 — SSH 鍵でパスワードなしログインを用意する              影響度 B / 目安 12分

  この演習はシステム全体を触ります。練習機の中（student@linuc）で作業します。
  戻すには、外の端末で vm reset --yes。

【やること】

  deploy ユーザが、パスワードなしで SSH 鍵でログインできるようにしてください。

  1. 鍵を作る（アルゴリズムは ed25519。パスフレーズは空で構いません）
         ssh-keygen -t ed25519 -f /tmp/deploy_key -N ''
  2. その公開鍵を deploy の authorized_keys に登録する
         （/home/deploy/.ssh/authorized_keys）
  3. 鍵で入れることを確かめる
         ssh -i /tmp/deploy_key deploy@localhost id

【詰まったら】

  鍵を登録したのに弾かれるときは、権限を疑ってください。
  sshd は、ホームや ~/.ssh や authorized_keys が本人以外に書ける状態だと、
  鍵を黙って無視します（StrictModes。本文の第8章で実測）。

      /home/deploy          本人のみ書ける（755 以下 / 他人が書けない）
      /home/deploy/.ssh     700
      authorized_keys       600・持ち主 deploy
