演習 07 — GnuPG でファイルを暗号化する                            影響度 B / 目安 12分

  この演習はシステム全体を触ります。練習機の中（student@linuc）で作業します。
  戻すには、外の端末で vm reset --yes。

  この演習は deploy ユーザで行います。まず deploy になってください。

    sudo -u deploy -i        ← deploy のログインシェルに入る（exit で戻る）

【やること】

  deploy の鍵束に鍵を作り、あるファイルを「自分の公開鍵で」暗号化してください。

  1. 鍵を作る（既定のアルゴリズムで構いません。パスフレーズは空で）
         gpg --batch --pinentry-mode loopback --passphrase '' \
             --quick-gen-key 'Deploy <deploy@linuc.example>'
  2. 暗号化するファイルを用意する
         echo '社外秘のメモ' > ~/secret.txt
  3. 自分の公開鍵で暗号化し、~/secret.txt.gpg を作る
         gpg --encrypt --recipient deploy@linuc.example ~/secret.txt
  4. 秘密鍵で復号して、元に戻ることを確かめる
         gpg --decrypt ~/secret.txt.gpg

  鍵束と設定がどこに置かれたかも見ておいてください。

    gpg --list-keys
    ls ~/.gnupg
