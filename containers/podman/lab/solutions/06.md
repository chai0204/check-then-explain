    mkdir -p ~/.config/containers/systemd
    printf '%s\n' '[Container]' 'Image=docker.io/library/busybox:1.38.0' 'Exec=httpd -f -h /etc' 'PublishPort=127.0.0.1:8086:80' '[Service]' 'Restart=always' '[Install]' 'WantedBy=default.target' > ~/.config/containers/systemd/ex06.container
    cat ~/.config/containers/systemd/ex06.container
    systemctl --user daemon-reload
    systemctl --user start ex06.service
    loginctl enable-linger
    curl -s http://127.0.0.1:8086/hostname
    #=> 12桁の16進数（systemd-ex06 のコンテナのホスト名）

    lab check 06

  quadlet は daemon-reload のときに ex06.container を読み、podman run を1行に書いた ex06.service を作ります。
  linger を入れると、student の systemd がログインと関係なく動き続けるので、その下のコンテナも止まりません。
  WantedBy=default.target なので、練習機を起動し直したときにも起動します。
