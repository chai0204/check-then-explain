練習機の中（student@linuc）で打ちます。

    podman run -d --name ex01 alpine:3.24.2 sleep 3600
    pid=$(podman inspect -f '{{.State.Pid}}' ex01)
    ps -o pid,ppid,comm -p $pid
    ps -o ppid= -p $pid | tr -d ' ' > ~/ex01-conmon.txt
    ps -o pid,ppid,comm -p $(cat ~/ex01-conmon.txt)
    #=> COMMAND が conmon、その PPID は 1

    lab check 01

  podman run はコンテナを作り、見張り役の conmon を1つ残して終わります。sleep の親は conmon で、
  podman のプロセスも、頼む相手のデーモンもいません。conmon の親は PID 1（練習機の systemd）です。
