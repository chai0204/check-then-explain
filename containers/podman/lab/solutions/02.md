練習機の中（student@linuc）で打ちます。

    mkdir -p ~/ex02/data
    podman unshare chown 1000:1000 ~/ex02/data
    ls -lnd ~/ex02/data
    #=> drwxrwxr-x … 100999 100999 …        ← 中の 1000 は、外では 100000 + 999（rwxrwxr-x は student の umask 0002 で作ったため）
    podman run --rm --user 1000:1000 -v "$HOME/ex02/data":/data alpine:3.24.2 touch /data/ok
    ls -ln ~/ex02/data
    #=> … 100999 100999 … ok

    lab check 02

  /etc/subuid が student:100000:65536 なので、中の UID 1 から順に外の 100000 から割り当てられ、中の 1000 は外の 100999 になります。
  外の student が 100999 に chown することは許されませんが、podman unshare の中では student が root なので、中の番号（1000）で chown できます。
  片付けるときは、外の student は 100999 の持ち物を消せないので  podman unshare rm -rf ~/ex02  を使います。
