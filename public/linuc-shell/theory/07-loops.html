7. パイプの先で数えた数は、持ち帰れない

ファイルを1行ずつ読んで数える。ループの中では 1、2、3 と増えていくのに、ループを抜けた直後の合計は 0 になる。cat names.txt | while … の while は、パイプの右側として子のシェルの中で回っているからである。繰り返しも分岐も、この章で見るものはすべて「どのシェルの中で回っているか」で結果が変わる。

前提: 第6章まで読了所要 20分影響度 A出題範囲 1.06.2（重要度6）最終検証 2026-10-13

この章のゴール

  • for（並べたものを1つずつ）と while（条件が 0 の間）を書き分けられる。seq で数の列を作れる
  • while read でファイルを1行ずつ読め、パイプの右側に置くと変数が残らない理由を説明できる
  • read が行をどう切って変数に入れるかを言える
  • case で値をパターンに当てはめて分岐できる
ここで覚えなくていいこと: select 文、shopt -s lastpipe、read の -t・-n・-a、case の ;& と ;;&、$(( )) の演算子の全部（+ - が使えれば足りる）。

for は、並べたものを1つずつ

この節で分かること: for の書き方と、並べ方の3つの作り方。

この章も ~/try で作業する。for 変数 in 並び; do …; done は、並びの要素を1つずつ変数に入れて、do と done の間を繰り返す。

$ mkdir -p ~/try && cd ~/try
$ for i in 1 2 3; do echo "i=$i"; done
i=1
i=2
i=3
$ for f in /etc/host*; do echo "$f"; done
/etc/host.conf
/etc/hostname
/etc/hosts

並びは直接書いても、/etc/host* のようなワイルドカードで作ってもよい。数の並びを作るのが seq である。

$ seq 3
1
2
3
$ seq 2 5
2
3
4
5
$ seq 1 2 9
1
3
5
7
9
$ seq -w 8 10
08
09
10
$ seq -s , 5
1,2,3,4,5
$ for i in $(seq 1 3); do echo "$i 回目"; done
1 回目
2 回目
3 回目
書き方出るもの
seq 終わり1 から終わりまで
seq 始め 終わり始めから終わりまで
seq 始め 増分 終わり増分ずつ（seq 1 2 9 は 1 3 5 7 9）
seq -w …桁をそろえて 0 で埋める
seq -s 区切り …改行の代わりに区切り文字でつなぐ

for i in $(seq 1 3) は、第3章のコマンド置換で seq の出力を並びにしている。並びはループが始まる前に1回だけ作られるので、ループの中で元のファイルに書き足しても、回る回数は変わらない。

$ printf '1\n2\n' > list.txt; for x in $(cat list.txt); do echo "$x"; echo 9 >> list.txt; done; cat list.txt
1
2
1
2
9
9

bash には C 言語風の書き方もある。

$ for ((i = 0; i < 3; i++)); do echo "i=$i"; done
i=0
i=1
i=2

while は、条件のコマンドが 0 を返す間

この節で分かること: while と until、ファイルを1行ずつ読む定番の形。

while の後ろに置くのは、if と同じくコマンドである。そのコマンドが 0 を返す間だけ回る。until は逆で、0 を返すまで回る。$(( )) は数の計算を書く書き方である。

$ n=0; while [ $n -lt 3 ]; do echo "n=$n"; n=$((n + 1)); done
n=0
n=1
n=2
$ until [ $n -eq 0 ]; do n=$((n - 1)); echo "n=$n"; done
n=2
n=1
n=0

read は1行読めたら 0、読むものが無くなったら 1 を返す。だから while read と書けば、ファイルの最後で自然に止まる。ファイルは done < ファイル でつなぐ。

$ printf 'alice\nbob\ncarol\n' > names.txt
$ while read -r name; do echo "名前: $name"; done < names.txt
名前: alice
名前: bob
名前: carol
たとえ: for は配られた名簿を上から順に読み上げる係、while は「まだ続けてよい」と言われる間だけ続ける係に近い。名簿の長さは最初に決まっているが、「続けてよい」かどうかは毎回聞き直す。
ただし崩れる点: 人なら「名簿が途中で書き換わった」ことに気づくかもしれないが、for は最初に作った並びを最後まで使う。ループの中で元のファイルを変えても、並びは変わらない。

パイプの右側で回した while は、子のシェルの中にいる

この節で分かること: cat … | while で変数が消える理由と、直し方。

同じことを、cat とパイプで書く人は多い。

ふつうこう考える

cat names.txt | while read … も while read … done < names.txt も、1行ずつ読むことに変わりはない。ループの中で n を増やせば、ループの後の n は読んだ行数になるはずだ。

$ cat > count.sh <<'END'
> #!/bin/bash
> n=0
> cat names.txt | while read -r name; do
>     n=$((n + 1))
>     echo "読んだ: $name (n=$n)"
> done
> echo "合計: $n"
> END
$ bash count.sh
読んだ: alice (n=1)
読んだ: bob (n=2)
読んだ: carol (n=3)
合計: 0
だめな理由: ループの中では n=1・n=2・n=3 と増えているのに、ループの後は 0 である。 bash はパイプ | でつないだコマンドの並び（パイプライン）を、それぞれ別のプロセスで動かす。while はパイプの右側なので子のシェル（サブシェル）の中で回り、 そこで増やした n は子が持っているコピーである。子が終わると一緒に消え、親に戻ってくるのは終了ステータスだけになる（第2章・第3章と同じ形）。

< のリダイレクトは新しいプロセスを作らない。while は親のシェルのまま回るので、n が残る。

$ cat > count2.sh <<'END'
> #!/bin/bash
> n=0
> while read -r name; do
>     n=$((n + 1))
> done < names.txt
> echo "合計: $n"
> END
$ bash count2.sh
合計: 3
たとえ: パイプの右側は別室で数えてもらうのに近い。別室の人はきちんと 1、2、3 と数えたが、部屋を出るときに集計用紙を置いてきてしまう。< でつなぐのは、紙の束を自分の机に持ってきて、自分で数えることにあたる。
ただし崩れる点: 別室の人なら「3 でした」と口頭で伝えられるが、子のシェルが親に渡せるのは終了ステータスという数1つで、それも「最後のコマンドが成功したか」であって数えた結果ではない。
手を動かす: 実践編の演習07は、logs/ の各ファイルの行数と合計を出すはずが、全部 0 と答えるスクリプトを直す課題である。 判定は logs/ を別の場所に写してファイルを1本足し、wc -l の値と比べる。

read は、行を空白で切って変数に入れる

この節で分かること: read に変数を複数渡したときの入り方と、区切り文字の変え方。
$ read a b c <<< "1 2 3 4 5"; echo "a=$a b=$b c=$c"
a=1 b=2 c=3 4 5
$ IFS=: read -r user pw uid rest < /etc/passwd; echo "$user の UID は $uid"
root の UID は 0

read a b c は、行を空白で切って前から順に入れ、余った分は最後の変数にまとめて入れる。IFS=: を前に付けると、その read だけ区切りが : になり、/etc/passwd の欄を取り出せる。-r は \ を特別扱いしない指定で、付けないと \ が消える。ファイルを読むときは付けておくのが定番である。

$ printf '%s\n' 'C:\temp' | { read p; echo "$p"; }
C:temp
$ printf '%s\n' 'C:\temp' | { read -r p; echo "$p"; }
C:\temp

case は、値をパターンに当てはめる

この節で分かること: case の書き方と、パターンの書ける範囲。

入力に応じて分岐する小さなスクリプトを書く。read -p は、端末から読むときに案内を出す。

$ cat > yn.sh <<'END'
> #!/bin/bash
> read -p "続けますか? [y/n] " ans
> case "$ans" in
>     [yY]|[yY][eE][sS]) echo "続けます" ;;
>     [nN]*)             echo "やめます" ;;
>     *)                 echo "y か n で答えてください"; exit 1 ;;
> esac
> END
$ bash yn.sh
続けますか? [y/n] yes
続けます

入力をパイプで流し込むと、案内は出ずに答えだけが出る（read -p の案内は、入力が端末のときだけ表示される）。

$ echo No | bash yn.sh
やめます
$ echo maybe | bash yn.sh; echo "終了ステータス $?"
y か n で答えてください
終了ステータス 1
case 値 in
    パターン1)          コマンド ;;       ← ;; で1つの分岐が終わる
    パターン2|パターン3) コマンド ;;      ← | は「または」
    *)                  コマンド ;;       ← どれにも当たらなかったもの
esac                                       ← case を逆から綴って閉じる

パターンはファイル名のワイルドカードと同じ書き方で、[yY] は y か Y の1文字、[nN]* は n か N で始まる何か、* は何でもである。上から順に比べて、最初に当たった1つだけを実行する。

ループの途中で抜けるのは break、その回を飛ばして次へ進むのは continue である。

$ for i in 1 2 3 4 5; do [ $i -eq 2 ] && continue; [ $i -eq 4 ] && break; echo $i; done
1
3
たとえ: case は郵便の仕分け棚に近い。宛先（値）を上の段から順に棚の札（パターン）と見比べ、最初に合った棚に入れる。どれにも合わなければ一番下の「その他」（*）に入る。
ただし崩れる点: 郵便の仕分けは1通ごとに迷わないが、case は上の段から見るので、* を先頭に置くと全部がそこに入り、下の棚は二度と使われない。順番が意味を持つ。
手を動かす: 実践編の演習06は、Linux を知らない人が番号だけで決まったコマンドを実行できるメニューを、while read と case で作る課題である。 判定は入力を流し込んで実際に実行し、入力が終わったとき（Ctrl-D）に止まるかも確かめる。
確認

1 から 10 までの奇数を1行ずつ出すコマンドを、seq で書け。

答え

seq 1 2 10（または seq 1 2 9）。seq 始め 増分 終わり の形で、終わりを超えない範囲で出す。

$ seq 1 2 10
1
3
5
7
9
確認

次のスクリプトを実行すると、最後の行は何を出すか。names.txt は3行ある。

n=0
cat names.txt | while read -r line; do n=$((n + 1)); done
echo "$n"
答え

0。パイプの右側の while は子のシェルで回り、そこで増やした n は親に戻らない。 while read -r line; do …; done < names.txt と書けば 3 になる。

確認

case "$1" in start) … ;; stop) … ;; *) … ;; esac で、$1 が restart のときに実行されるのはどの分岐か。

答え

*) の分岐。パターンは値の全体と比べるので、start は restart に当たらない。どれにも当たらなかったものが * に入る。

$ case restart in start) echo "start に当たった" ;; *) echo "その他に入った" ;; esac
その他に入った
確認

while true; do read -r ans; …; done と書いたメニューは、入力が終わった（Ctrl-D）あとどうなるか。

答え

止まらない。read は失敗（1）を返し続けるが、while の条件は true なので見ていない。 while read -r ans; do …; done と、read 自身を条件に置けば止まる（演習06 の判定は、ここを5秒で打ち切って確かめている）。

この章で分かったこと

持ち帰ってほしいこと

  • for 変数 in 並び は並びを1つずつ。並びは直接・ワイルドカード・$(seq …) で作れる
  • seq は 終わり / 始め 終わり / 始め 増分 終わり。-w で桁をそろえ、-s で区切りを変える
  • while コマンド は 0 の間、until は 0 になるまで回る。while read -r line; do …; done < ファイル が1行ずつ読む定番
  • パイプの右側の while は子のシェルで回り、増やした変数はループの後に残らない
  • read a b c は余りを最後の変数にまとめる。IFS=: で区切りを変えられる
  • case は上から比べて最初に当たった1つだけ。| は「または」、* はその他、分岐は ;; で閉じ、全体は esac
