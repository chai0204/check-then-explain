このシリーズの約束

本文のコマンドは、あなたの画面に本文と同じ文字を出します。 出なければ教材のバグとして直します。

そのためにイメージのダイジェストと apt の時刻を固定し、 載せる出力はすべてそのイメージの中で実際に打った記録にしています。 AI の回答は毎回違い、公式ドキュメントはあなたの環境を知りません。

向く人: コマンドは打てる。写経すれば動く。でも「なぜ動くのか」を人に説明できない人。
向かない人: いま動かしたいだけの人（公式の Getting Started のほうが速い）／ 答えだけ欲しい人（AI に聞いたほうが速い）。

読み方

やりたいことどうするか
仕組みだけ知りたい理論編を読むだけで完結します。実行ログは本文に載っています
手を動かしたい各テーマの入口にある docker run を1行打ってください。準備は初回3〜5分
詰まったコンテナ内で lab hint NN。使い切れば lab solve NN で解答に到達できます
本文と違う出力が出たそれは教材のバグです。打ったコマンド・本文の出力・あなたの出力・lab env の全文を添えて報告してください

つくりかた

この節で分かること: なぜこの形なのか

各テーマは次の順で作っています。執筆より先に実機で全手順を通し、その実行ログだけを本文の素材にします。 ログに無いコマンドは1文字も載せません。動かない手順が混ざる余地を構造的に消すためです。

各章には「ここで覚えなくていいこと」をゴールと同じ重みで書いています。 初学者が止まるのは知らない語が出たときではなく、 これを知らないまま進んでいいのか分からないときだからです。

壊して覚える ／ 各テーマの検証環境とイメージのダイジェストは、それぞれの入口ページに書いてあります。
