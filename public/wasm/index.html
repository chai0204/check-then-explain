確かめて説明する WASM — 実践編

理論編の各章に対応する演習が5本あります。WAT を手で書き、2つのホストで走らせ、最後は配布されたバイナリを実行せずに調べます。

演習5本合計 約63分影響度 B（コンテナ内のみ）最終検証 2026-09-30

始める

この節で分かること: 1行で始める方法と、終わったときの消し方
docker run --rm -it \
  --name lab-wasm --pull=always \
  -v lab-wasm-work:/home/lab/work \
  -v lab-wasm-state:/home/lab/.lab \
  ghcr.io/OWNER/lab-wasm:1.0.0
入っている道具何に使うか
wat2wasm / wasm2wat / wasm-objdumpテキストとバイナリの往復、中身の調査（wabt 1.0.34）
wasmtimeWASI を持つホスト（49.0.1・バージョンと sha256 を固定）
nodeブラウザ相当のホスト。WASI を持たない側として使う（18.19.1）
xxd41バイトのバイナリを全部見る
Docker Desktop が使えない場合: docker を podman に置き換えてください。 このテーマは podman では未検証です（SQLite 編は podman 5.8.6 rootless で 全演習が通ることを確認しましたが、WASM 編ではまだ試していません）。
後片付け: docker volume rm lab-wasm-work lab-wasm-state

コンテナの中のコマンド

この節で分かること: 覚えるコマンドは4つだけ
コマンド何をするか
lab現在地と次の一手。起動時にも自動で出ます
lab start NN課題を開く。作業場所は ~/work/NN
lab check NN答え合わせ。観測した事実だけを出し、直し方は言いません
lab hint NN詰まったとき。呼ぶたびに深くなります
答えは閉じていません。 ヒントを使い切れば lab solve NN で必ず解答に到達できます。 ただし使ったことは lab ls に ◍ として残ります。

本文と違う出力が出たら

この節で分かること: それは教材のバグとして扱われる

このシリーズは「本文と同じ文字があなたの画面に出る」ことを約束しています。 違ったときは教材のバグとして扱うので、次の4つを添えて報告してください。

  • 打ったコマンド
  • 本文に載っている出力
  • あなたの画面に出た出力
  • lab env の全文（イメージ・ベース・apt の固定日・カーネル・アーキが出ます）
$ lab env
テーマ    : lab-wasm 1.0.0
イメージ  : ghcr.io/<owner>/lab-wasm:1.0.0
ベース    : Ubuntu 24.04.5 LTS
apt 固定  : 20260929T000000Z
カーネル  : 7.2.6
アーキ    : x86_64
ランタイム: docker
特権      : CapEff=0000000000000000 CapBnd=00000000a80425fb

このうちカーネル行だけは、あなたのホストの値が出ます（コンテナはホストのカーネルを使うため）。 podman で起動した場合は ランタイム: podman、CapBnd は 00000000800405fb になります（既定のケーパビリティが Docker より3つ少ない）。 どちらも正常です。CapEff が 0 でないなら、--user 0 などを付けて起動しています。

報告先は こちら。

なお wasmtime run --invoke は 警告を2行出します（引数と戻り値を伴う呼び出しが experimental であるため）。 これは正常です。本文にもそのまま載せてあります。
