この教材が回収する1つの原理

この節で分かること: 5章すべてが、たった1つの事実から出てくること
背骨: WASM は外の世界を一切知らない。できることは全部、 ホストが import として手渡したものだけである。
ただし崩れる点: 「何も渡さなければ安全」ではない。計算だけで CPU を使い切ることはできる。 渡さないことで防げるのは、外への影響だけ。

画面に文字を出すことも、ファイルを読むことも、WASM 単体にはできません。 第2章でそれを実際に確かめ、第5章でそれがセキュリティの道具になることを見ます。
