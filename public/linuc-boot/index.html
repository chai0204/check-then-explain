Linux の起動・仮想化・プロセス

LinuC レベル1 101 主題1.01初級演習あり（仮想マシン）約4時間18分状態: ドラフト

LinuC レベル1 101 試験の主題1.01（インストールと仮想マシン・コンテナ、ブートと systemd、プロセス、デスクトップ）を、コンテナの中で動く仮想マシン（練習機）で確かめる10章。電源を入れ、GRUB でカーネルに引数を渡し、プロセスにシグナルを送るまでを自分の手で打つ。停止の頼みもシグナルもログインも相手に送る合図で、どう振る舞うかは受け取った側が決める。

想定読者

LinuC レベル1（101）の受験者で、出題範囲を読んで「そういうことができるんだな」で止まっている人。端末でコマンドを打てて、docker を動かせることが前提。

得られるもの

  • virsh shutdown と destroy の違いを、受け取る相手の違いとして説明できる
  • コンテナと仮想マシンの違いを、同じコマンドを両方で打った出力で示せる
  • GRUB でカーネル引数を足し、その1回だけシングルユーザモードで起動できる
  • ssh の切断で処理が消える理由を SIGHUP で説明し、nohup や tmux で残せる

進め方

理論編全10章・約2時間52分。1章ごとに「実際に打つと何が出るか」を先に置いてある。 実践編演習7本・約1時間26分。docker か podman で、練習機（仮想マシン）入りの檻を1つ起動する。イメージ約2GB・起動から ssh まで約30秒。KVM も特権も要らない。

完了推定時間（約4時間18分）は、各章の所要時間と演習の目安の合計です。

章

  1. virsh は電源を入れ、止まるよう頼むだけ
  2. 入れるかは受け取る側のファイルが決める
  3. コンテナのカーネルはホストのもの
  4. GUI が無くても既定は graphical.target
  5. ファームウェアが必ず読めるのは FAT の中のファイルだけ
  6. Ubuntu では、root にパスワードが無いとシングルユーザモードは何も聞かない
  7. halt では電源は切れない
  8. kill は止めない、合図を送るだけ
  9. exit では消えず、切断で消える
  10. X では画面の側がサーバー
