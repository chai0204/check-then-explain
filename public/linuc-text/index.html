確かめて説明する LinuC 主題1.03

LinuC レベル1 101 試験・主題1.03「GNU と Unix のコマンド」 （コマンドラインの操作 / フィルタ / ストリーム・パイプ・リダイレクト / 正規表現 / vi）を、 全部コンテナの中で実際に打って確かめます。101 試験でいちばん重い主題（重要度の合計 15）です。 出題範囲が名指しする19個のフィルタは、すべて本文で打っています。

このページのコマンドは、あなたの画面に本文と同じ文字を出します。 出なければ教材のバグとして直します。 AI の回答は毎回違い、公式ドキュメントはあなたの環境を知りません。 ここにあるのは、誰かが実際に一度通した記録です。

この教材が向かない人

  • いま動かしたいだけの人 → 公式ドキュメントのほうが速い
  • 答えだけ欲しい人 → AI に聞いたほうが速く、あなたの語彙に合う

向く人: コマンドは打てる。写経すれば動く。 でも「なぜその出力になるのか」を人に説明できない人。
LinuC を受ける人向けには: 2>&1 の位置や uniq の前の sort を、 覚えた順番ではなく理由で答えたい人。

この教材の檻

檻準備ここで触れるここでは触れない（逃がす先）
一般ユーザのコンテナ2分 bash の対話シェル・history・man・19個のフィルタ・grep sed xargs tee・vim nano emacs（数十 MB あるので入れていない）・GUI のエディタ → 母艦（本文では位置づけとキーだけ説明）

影響度 B（変更はコンテナの中だけ。母艦の設定もファイルも書き換えません）。 権限の追加（--cap-add）も --privileged も要りません。読者は一般ユーザ lab のまま作業します。

はじめる

Docker の場合。1行です。

docker run --rm -it --name lab-linuc-text --hostname linuc \
  -v lab-linuc-text-work:/home/lab/work \
  -v lab-linuc-text-state:/home/lab/.lab \
  ghcr.io/chai0204/lab-linuc:text-1.0.0@sha256:__DIGEST__

入ると現在地が出ます。

── lab-linuc-text 1.0.0 ────────────────────────────────────────
lab-linuc-text  進捗 0/8
  次 → 01 「標準のエディタを vi にする」 (目安 8分 / 影響度 B)
  lab start 01 で課題を開く
  進捗の保存先: /home/lab/.lab/progress.json（消すには docker volume rm lab-linuc-text-state）
  lab ls      演習一覧 / lab start NN  課題を開く / lab check  答え合わせ
────────────────────────────────────────────────────────────

理論編の章は ~/text で打ちます。練習用のファイルが置いてあり、起動し直すたびに元の中身に戻ります （ホームディレクトリはボリュームに置いていません）。どの章の出力も、起動した直後の檻で記録してあります。 前の章で作ったファイルや変数が残っていて本文と違う出力になったら、exit して起動し直してください。 演習の作業場所 ~/work と進捗 ~/.lab だけはボリュームに残ります。

演習

8本あります。判定は観測できる結果だけで行い、コマンドの打ち方は見ません。 詰まったら lab hint NN を何度でも。使い切ったら lab solve NN で模範解答に必ず届きます （見ても構いません。進捗には「solve を見た」として残ります）。

Noやること副題判定が見るもの目安
01標準のエディタを vi にする1.03.1・1.03.5子プロセスから見えた EDITOR と、sensible-editor が実際に起動したエディタの名乗り8分
02自作のコマンドを名前だけで動かす1.03.1/tmp に移ってから名前だけで探して実行した結果10分
03アクセスログのステータスを数える1.03.2答えのファイルの件数を、配ったログを数え直した値と突き合わせる12分
04設定ファイルを sed で書き換える1.03.2・1.03.4書き換えた後の各行と、.bak が配ったときの中身と同じか10分
05出力を2本に分けて保存する1.03.33つのファイルに、どちらの口の行がどの順で入ったか10分
06名前に空白のあるファイルもまとめて消す1.03.3残っている .tmp の数と、消してはいけないファイルの有無12分
07レベルが ERROR か WARN の行だけを抜き出す1.03.4抜き出した各行が元のログの何行目で、レベル欄が何か12分
08vi で TODO を直す1.03.5保存されたファイルの中身（4つの指示ごと）12分

先に読む場合は 理論編（10章）へ。 章と演習は対応しているので、どちらから始めても構いません。

lab reset NN で演習を配られたときの状態に戻すと、~/work/NN はディレクトリごと作り直されます。 そのディレクトリの中にいたなら、続けて cd ~/work/NN と打ち直してください（打たないと No such file or directory になります）。
