ネットワークの基礎

LinuC レベル1 102 主題1.07初級演習あり（仮想マシン）約3時間49分状態: ドラフト

LinuC レベル1 102 試験の主題1.07（プロトコルの基礎、ネットワーク構成、問題解決、クライアント側の DNS 設定）を、仮想マシンの中に作った「社内 LAN」で確かめる9章。壊れて渡される経路と名前解決を、原因を突き止めて直す。ネットワークの見え方は道具が読んだ表で決まり、ifconfig と ip、dig と ping は同じものを別々の表から読んでいる。

想定読者

LinuC レベル1（102）の受験者で、ip と ifconfig、dig と ping のどれで何が分かるかで止まっている人。端末でコマンドを打てて、docker を動かせることが前提。

得られるもの

  • アドレスとマスクから、ネットワークアドレス・ブロードキャスト・使える台数を出せる
  • ping の From と ICMP のエラーから、どこで止まったかを特定できる
  • ss の待ち受けの表から、どのアドレスの何番で誰が待っているかを読める
  • getent ahosts で、/etc/hosts と DNS のどちらが答えたかを特定できる

進め方

理論編全9章・約2時間35分。1章ごとに「実際に打つと何が出るか」を先に置いてある。 実践編演習7本・約1時間14分。docker か podman で、練習機（仮想マシン）入りの檻を1つ起動する。イメージ約2GB・起動から ssh まで約30秒。KVM も特権も要らない。

完了推定時間（約3時間49分）は、各章の所要時間と演習の目安の合計です。

章

  1. アドレスは、分けるたびに減る
  2. ifconfig に見えないアドレスがある
  3. ifup は、自分が付けたものしか知らない
  4. 返事をしたのは、相手ではなかった
  5. traceroute は、断られた返事で道を知る
  6. IPv6 のアドレスは、頼まなくても付いている
  7. LISTEN していても、外からは入れない
  8. resolv.conf に書いた1行は、消される
  9. dig と ping は、別の表を引いている
