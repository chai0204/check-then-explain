理論編 — セキュリティ

LinuC レベル1 102 試験・主題1.10（セキュリティ管理 / ホストの設定 / 暗号化 / クラウド）を、 コンテナの中で動く仮想マシンの練習機で実際に手を動かして確かめる9章。 練習機を壊して自分を締め出す操作（/etc/nologin・ファイアウォール）も、外から安全に戻せる構えで扱います。

このページのコマンドは、あなたの画面に本文と同じ文字を出します。 出なければ教材のバグとして直します。 AI の回答は毎回違い、公式ドキュメントはあなたの環境を知りません。 ここにあるのは、誰かが実際に一度通した記録です。

この9章を貫いている1つの事実

「止めたつもり」は、たいてい止まっていない。Linux の制限は、正しい対象に・信用できる持ち主の設定で書けたときだけ効く。

パスワードをロックしても鍵では入れる。find -perm 4000 では SUID が1つも出ない。 権限の緩い sudoers は丸ごと無視される。iptables -L が空でも firewalld が守っている。 だから監査は、意図ではなくいま実際に効いているものを数えることから始まります。

ここで覚えなくていいこと: 強制アクセス制御（SELinux・AppArmor）、PAM モジュールの細部、nftables のネイティブ構文、 gpg の信頼の輪。どれもレベル1の範囲外で、この9章には深追いしません。

章

  1. SUID は、実行する人ではなく持ち主で動く — find -perm 4000 では0件。SUID はスクリプトには効かない（15分）
  2. 「ロックした」は「無効化した」ではない — passwd -l の後も鍵で入れる。無効化は usermod -e（14分）
  3. 入っている人と、入れる上限 — ハードリミットは一方通行。who は端末ログインしか見ない（14分）
  4. 開いているポートは、数えないと見えない — nmap の SERVICE は当て推量（2323 が 3d-nfsd）。22 は 1/init（15分）
  5. sudo は、許したものだけに絞る — 権限の緩い sudoers は丸ごと無視。visudo が壊れた設定を止める（14分）
  6. シャドウと、使っていないサービスを止める — /etc/nologin は自分も締め出す。xinetd と inetd は同時に入らない（16分）
  7. ファイアウォールは、自分を締め出せる — iptables -L が空でも firewalld が守る。22 を巻き込まない順序（16分）
  8. 鍵は、持ち主で非対称になっている — ed25519 は 86 バイトで RSA 4096 と同等以上。トンネルとGPG（18分）
  9. クラウドでは、守る範囲が分かれている — 到達を決めるのは OS の外。理論のみ（12分）

実務のどこで効くか

場面ここで効く理由見落としやすい点関連する章
