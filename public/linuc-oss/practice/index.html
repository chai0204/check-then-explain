確かめて説明する LinuC 主題1.11

LinuC レベル1 102 試験・主題1.11「オープンソースの文化」 （オープンソースの概念とライセンス / オープンソースのコミュニティとエコシステム）を、 どの Ubuntu にも入っているライセンスの実物を読んで確かめます。 教材は /usr/share/common-licenses/ の条文と、パッケージごとの /usr/share/doc/*/copyright です。

このページのコマンドは、あなたの画面に本文と同じ文字を出します。 出なければ教材のバグとして直します。 AI の回答は毎回違い、公式ドキュメントはあなたの環境を知りません。 ここにあるのは、誰かが実際に一度通した記録です。

この教材が向かない人

  • いま動かしたいだけの人 → 公式ドキュメントのほうが速い
  • 答えだけ欲しい人 → AI に聞いたほうが速く、あなたの語彙に合う

向く人: コマンドは打てる。写経すれば動く。 でも「なぜ動くのか」を人に説明できない人。
LinuC を受ける人向けには: 出題範囲を読んで「GPL というライセンスがあるんだな」で止まっている人。

この教材の檻

檻準備ここで触れるここでは触れない（逃がす先）
素の Ubuntu（公式・digest 固定）1分 common-licenses/ doc/*/copyright --version --help dpkg -s bashbug AGPL の全文・掲示板・OSD の原文 → 本文の表と理論

檻は Docker Hub 公式の素の Ubuntu イメージをダイジェストで固定したもので、このコースのための専用イメージは作っていません。 AGPL の全文・掲示板・オープンソースの定義の原文は手元に実物が無いので、本文では表と理論で扱います。 影響度 A（読むだけ。設定も状態も変えません）。本文のコマンドは手元の Ubuntu や Debian でもそのまま打てますが、 入っているパッケージが違うので、数（copyright 92 個・ライセンスの書き方 155 通りなど）が変わります。 本文と同じ画面にしたいときは、下のイメージを使ってください。

このコースに演習が無い理由

主題1.11 は知識問題で、出題範囲の「詳細」欄に打つコマンドが1つもありません。 このシリーズの演習は、lab check がコンテナの中の状態を実際に観測して合否を出す形で作っています。 ライセンスを理解したかどうかは、状態として観測できません。観測型の判定を持つ演習が作れないので、 演習と専用の檻は作らず、理論編だけのコースにしました。

そのかわり、理論編の端末表示はすべて下のイメージで記録してあり、同じイメージで同じ画面が出ます。 各章の「手を動かす」の欄に、その章で自分の画面に出してほしいコマンドを書いてあります。

はじめる

Docker の場合。1行です。

docker run --rm -it --hostname linuc \
  ubuntu:24.04@sha256:008173c23f95b170204355c12626cb5a965d779a7e1283b09e9cffbb1bf33ca3

root のシェルが開きます。--rm なので、exit で抜けるとコンテナは消えます。 このコースは何も保存しないので、進捗用のボリュームも要りません。 --hostname linuc は、出力に出るホスト名を本文と揃えるためです。 @sha256:… まで書くのは、ubuntu:24.04 という名前の中身が更新で入れ替わっても、本文と同じイメージを取ってくるためです。

Podman の場合（Docker Hub の名前を省略せずに書きます）。

podman run --rm -it --hostname linuc \
  docker.io/library/ubuntu:24.04@sha256:008173c23f95b170204355c12626cb5a965d779a7e1283b09e9cffbb1bf33ca3

podman 5.8.6（rootless）で本文の全コマンドを流し、docker の記録と1文字も違わないことを確かめてあります。

入ったら、まず本文と同じイメージかを確かめます。

$ grep PRETTY_NAME /etc/os-release
PRETTY_NAME="Ubuntu 24.04.5 LTS"
$ dpkg -l | grep -c '^ii'
92

92 と出れば、本文の数字（copyright 92 個など）がそのまま再現します。

本文と違う出力が出たら

教材のバグとして直します。次の4つを貼ってください。

  1. 打ったコマンド
  2. 本文に書いてある出力
  3. あなたの画面に出た出力
  4. 起動に使ったコマンドと、下の2つのコマンドの出力
$ grep PRETTY_NAME /etc/os-release
PRETTY_NAME="Ubuntu 24.04.5 LTS"
$ dpkg-query -W base-files bash coreutils dpkg libc6
base-files	13ubuntu10.5
bash	5.2.21-2ubuntu4
coreutils	9.4-3ubuntu6.3
dpkg	1.22.6ubuntu6.6
libc6:amd64	2.39-0ubuntu8.9

このコースは素の Ubuntu を使うので、他のコースにある lab env はありません。 版が本文と違うときは、起動コマンドの @sha256: 以降が抜けていないかを先に見てください。 Issue を立てる（フォームが3種類あります）。

終わったら

exit

--rm で起動しているので、抜ければコンテナは消えます。 イメージも消すなら docker rmi で（他で使っていなければ）。母艦には何も残りません。
