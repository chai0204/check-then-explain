いまの進み

副題の数ではなく重要度の合計で数えています。公式が副題ごとに付けている重要度は 出題の比重の目安なので、こちらのほうが「合格までどれくらいか」に近いためです。

この表で分からないこと: 出題の実際の配点、合格点、問題の形式。それは公式ページで確認してください。 この表は「手を動かせる教材が在るか」だけを示します。

手を動かせない副題について

この教材の作り方は「実機で打った出力だけを本文に載せる」です。 打つものが無い副題は、同じ作り方では作れません。該当するのは4つです。

副題重要度理由
1.01.5 デスクトップ環境の利用1X / Wayland と GUI が要る。コンテナでも VM でも画面を読者に再現させるのが難しい
1.10.4 クラウドセキュリティの基礎3管理コンソールの操作が対象。アカウント作成と課金が発生するので檻に入らない
1.11.1 オープンソースの概念とライセンス2知識問題。打つコマンドが無い
1.11.2 オープンソースのコミュニティとエコシステム1同じ

このサイトの使い方

  1. 公式の出題範囲を1回読む（101 / 102）。読むだけで頭に入らなくて構いません
  2. 上の表から、いま読める副題を開く
  3. 理論編を読んだら必ず実践編の演習をやる。読むだけでは出題範囲のコマンド名は定着しません
  4. 本文と違う出力が出たら報告する。それが教材の改善になります
