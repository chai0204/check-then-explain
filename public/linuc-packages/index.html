確かめて説明する LinuC 主題1.04

LinuC レベル1 101 試験・主題1.04「リポジトリとパッケージ管理」 （apt / Debian パッケージ / yum / RPM パッケージ）を、 Debian 系と RPM 系の2つの檻の中で実際に打って確かめます。 入れる・消す・調べる・照らし合わせる・署名を確かめる、を全部やります。

このページのコマンドは、あなたの画面に本文と同じ文字を出します。 出なければ教材のバグとして直します。 AI の回答は毎回違い、公式ドキュメントはあなたの環境を知りません。 ここにあるのは、誰かが実際に一度通した記録です。

この教材が向かない人

  • いま動かしたいだけの人 → 公式ドキュメントのほうが速い
  • 答えだけ欲しい人 → AI に聞いたほうが速く、あなたの語彙に合う

向く人: コマンドは打てる。写経すれば動く。 でも「なぜ動くのか」を人に説明できない人。
LinuC を受ける人向けには: dpkg -S と apt-file search、rpm -qf と yum provides の違いを、問題文の言い回しで迷う人。

この教材の檻

檻準備ここで触れるここでは触れない（逃がす先）
Debian 系（Ubuntu 24.04）2分 apt apt-get apt-cache apt-file dpkg dpkg-reconfigure /etc/apt/sources.list 本物の Ubuntu のパッケージに対する apt-file（Contents が約 195MB あるため取らない設定。理論編に理由）
RPM 系（AlmaLinux 9.7）2分 yum（= dnf） yumdownloader rpm rpm2cpio /etc/yum.repos.d/ /etc/yum.conf 今日の最新の AlmaLinux（更新の止まった 9.7 の保存庫に向けてある。理論編第5章に理由）

影響度 B（変更はコンテナの中だけ。母艦の設定もファイルも書き換えません）。 演習は sudo でパッケージを入れたり消したりするので、母艦では実行しないでください。 檻は exit すると消え、次に起動すると最初の状態に戻ります（進捗だけはボリュームに残ります）。

どちらの檻にも、練習用の小さなパッケージとリポジトリが入っています。演習と本文はネットにつながっていなくても同じ結果になります。 本物の Ubuntu / AlmaLinux のパッケージを入れる操作だけは、ネットが要ります。

はじめる

Debian 系の檻（理論編の第1〜4章・演習01〜03）:

docker run --rm -it --name lab-linuc-packages-deb --hostname linuc \
  -v lab-linuc-packages-deb-work:/home/lab/work \
  -v lab-linuc-packages-deb-state:/home/lab/.lab \
  ghcr.io/chai0204/lab-linuc:packages-deb-1.0.0@sha256:__DIGEST__

RPM 系の檻（理論編の第5〜7章・演習04〜06）:

docker run --rm -it --name lab-linuc-packages-rpm --hostname linuc \
  -v lab-linuc-packages-rpm-work:/home/lab/work \
  -v lab-linuc-packages-rpm-state:/home/lab/.lab \
  ghcr.io/chai0204/lab-linuc:packages-rpm-1.0.0@sha256:__DIGEST__

特別な権限は1つも渡しません（--privileged も --cap-add もありません）。 中では一般ユーザ lab として動き、パッケージを入れるときだけ sudo を付けます（パスワードは聞かれません）。 2つの檻は名前もボリュームも別なので、同時に動かしても構いません。

入ると現在地が出ます（Debian 系の檻の場合）。

演習

6本あります。判定は観測できる結果だけ（パッケージの台帳の状態・ファイルの有無・コマンドを実際に動かした結果）で行い、 コマンドの打ち方は見ません。詰まったら lab hint NN を何度でも。使い切ったら lab solve NN で模範解答に必ず届きます （見ても構いません。進捗には「solve を見た」として残ります）。

Noやること檻副題目安
01labsvc を、設定ファイルも一緒に入った依存も残さず消すDebian 系1.04.110分
02リポジトリを足し、名前の分からないパッケージから labcalc を使えるようにするDebian 系1.04.115分
03配られた .deb を、依存関係を満たして動く状態まで入れるDebian 系1.04.212分
04署名の確認を切らずに、別の鍵で署名されたリポジトリから labcalc を入れるRPM 系1.04.315分
05書き換えられた labmotd を、台帳と照らし合わせて入れた直後の状態に戻すRPM 系1.04.410分
06yumdownloader で取ってきた .rpm を、yum を使わず rpm で入れるRPM 系1.04.3・1.04.412分

各檻の lab ls には、その檻の演習だけが出ます。先に読む場合は 理論編（7章）へ。 章と演習は対応しているので、どちらから始めても構いません。
