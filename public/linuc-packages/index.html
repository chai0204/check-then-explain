章

  1. 入っているかどうかは台帳が決める
  2. apt は目録を読んで台帳に書く
  3. 目録は取りに行くまで古いまま
  4. dpkg は依存を読めるが取りに行かない
  5. yum は目録を自分で取りに行く
  6. rpm -V が黙るのは台帳どおりだから
  7. OK は確かめた範囲の OK
