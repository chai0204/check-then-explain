確かめて説明する LinuC 主題1.05

LinuC レベル1 101 試験・主題1.05「ハードウェア、ディスク、パーティション、ファイルシステム」 （ハードウェアの基礎知識と設定 / ハードディスクのレイアウトとパーティション / ファイルシステムの作成と管理、マウント）を、 コンテナの中で動く仮想マシン（練習機）で確かめます。 ディスクを分割し、フォーマットし、マウントし、ドライバを外し、USB メモリを抜き差しします。 練習機は本物の Linux カーネルで動くので、あなたの PC のディスクには何も起きません。

このページのコマンドは、あなたの画面に本文と同じ文字を出します。 出なければ教材のバグとして直します。 AI の回答は毎回違い、公式ドキュメントはあなたの環境を知りません。 ここにあるのは、誰かが実際に一度通した記録です。

この教材が向かない人

  • いま動かしたいだけの人 → 公式ドキュメントのほうが速い
  • 答えだけ欲しい人 → AI に聞いたほうが速く、あなたの語彙に合う

向く人: コマンドは打てる。写経すれば動く。 でも「なぜ動くのか」を人に説明できない人。
LinuC を受ける人向けには: fdisk も mount も、本物のディスクで試したことが無い人。 試そうにも、自分の PC のディスクを分割するのは怖い人。

影響度 B（変更は練習機の中だけ。母艦の設定もファイルも書き換えません）。 練習機には、分割・フォーマットしてよいディスクが5本（virtio 3本・SATA 1本・光学ドライブ1台）と USB の口がつないであります。 読者に権限を渡してもらう必要はありません（--privileged も --cap-add も /dev/kvm も要りません）。 QEMU が CPU を丸ごとソフトウェアで真似する（完全エミュレーション）ので、ホストのカーネルの特権を1つも借りないためです。

はじめる

Docker の場合。2行です。

docker run -d --name lab-linuc-disks --hostname host --stop-timeout 30 \
  -v lab-linuc-disks-vm:/home/lab/vm \
  -v lab-linuc-disks-state:/home/lab/.lab \
  ghcr.io/chai0204/lab-linuc:disks-1.0.1@sha256:a618fb0468bb943a3f95467af45d042cd8772c67e1a6b3014414bd066581fcd3

docker exec -it lab-linuc-disks bash -l
  • コンテナを起動すると、中で練習機も起動します。KVM を使わない完全エミュレーションなので、起動に 40〜90 秒かかります。
  • --stop-timeout 30 は必須です（権限ではありません）。docker stop したとき、練習機を正常に止めるのに約 13 秒かかり、docker の既定の猶予 10 秒では電源を抜かれてしまうためです。
  • Linux で --device /dev/kvm を足すと起動が数秒になりますが、/proc/cpuinfo などの表示が変わります。本文の出力は KVM なしで取ったものです。
  • podman でも、同じオプションのまま docker を podman に替えて起動できるはずです。同じ土台（仮想マシン型の檻の共通部分）を使う別のコースの檻は、podman 5.8.6（rootless）で起動・練習機への ssh・podman stop まで確かめてあります（logs/linuc-machine-podman.log）。このコースの檻そのものは、podman ではまだ確かめていません。

演習

8本あります。判定は観測できる結果だけで行い、コマンドの打ち方は見ません。 lab start NN で課題を開き、lab check NN で答え合わせ（練習機の中でも外でも打てます）。 詰まったら lab hint NN を何度でも。使い切ったら lab solve NN で模範解答に必ず届きます （見ても構いません。進捗には「solve を見た」として残ります）。 章のとおりに打つと、演習02・04〜08 は章の中で達成した状態になります。

やり直したいときは、外で vm reset --yes（練習機ごと最初の状態に戻ります）。 演習を始めるとき lab は「元に戻すには起動し直してください」と出しますが、この檻では起動し直しても練習機は戻りません（ディスクはボリュームに残ります）。戻すのは vm reset --yes です。 先に読む場合は 理論編（8章）へ。
