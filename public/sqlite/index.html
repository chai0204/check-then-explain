確かめて説明する SQLite — 実践編

理論編の各章に対応する演習が5本あります。全部コンテナの中で完結し、あなたのマシンには何も起きません。

演習5本合計 約54分影響度 B（コンテナ内のみ）最終検証 2026-09-30

始める

この節で分かること: 1行で始める方法と、終わったときの消し方
docker run --rm -it \
  --name lab-sqlite --pull=always \
  -v lab-sqlite-work:/home/lab/work \
  -v lab-sqlite-state:/home/lab/.lab \
  ghcr.io/OWNER/lab-sqlite:1.0.0
書いてあるものなぜ書くか
--rm終了でコンテナが消える。あなたのマシンに残骸を残さない
--pull=always手元の古いキャッシュと本文のタグがずれる事故を潰す
-v ...-work作業ファイルの保存先。名前付きボリュームなので、あなたのホームには触れません
-v ...-state進捗の保存先。これを省くと次回起動時に進捗が消えます
Docker Desktop が使えない場合: docker を podman に置き換えれば同じコマンドが通ります。 podman 5.8.6 の rootless で全5演習の判定が通ることを実測しました（2026-10-06）。 Rancher Desktop / Colima は未検証です。
後片付け: docker volume rm lab-sqlite-work lab-sqlite-state

コンテナの中のコマンド

この節で分かること: 覚えるコマンドは4つだけ
コマンド何をするか
lab現在地と次の一手。起動時にも自動で出ます
lab start NN課題を開く。作業場所は ~/work/NN
lab check NN答え合わせ。観測した事実だけを出し、直し方は言いません
lab hint NN詰まったとき。呼ぶたびに深くなります

他に lab ls（一覧）、lab solve NN（模範解答）、 lab reset NN（やり直し）、lab env（検証環境の表示）があります。

答えは閉じていません。 ヒントを使い切れば lab solve で必ず解答に到達できます。 閉じても学習は起きず、読者が別のところへ聞きに行くだけなので、出口は先に見せます。 ただし使ったことは lab ls に ◍ として残ります。

本文と違う出力が出たら

この節で分かること: それは教材のバグとして扱われる

このシリーズは「本文と同じ文字があなたの画面に出る」ことを約束しています。 違ったときは教材のバグとして扱うので、次の4つを添えて報告してください。

  • 打ったコマンド
  • 本文に載っている出力
  • あなたの画面に出た出力
  • lab env の全文（イメージ・ベース・apt の固定日・カーネル・アーキが出ます）
$ lab env
テーマ    : lab-sqlite 1.0.0
イメージ  : ghcr.io/<owner>/lab-sqlite:1.0.0
ベース    : Ubuntu 24.04.5 LTS
apt 固定  : 20260929T000000Z
カーネル  : 7.2.6
アーキ    : x86_64
ランタイム: docker
特権      : CapEff=0000000000000000 CapBnd=00000000a80425fb

このうちカーネル行だけは、あなたのホストの値が出ます（コンテナはホストのカーネルを使うため）。 podman で起動した場合は ランタイム: podman、CapBnd は 00000000800405fb になります（既定のケーパビリティが Docker より3つ少ない）。 どちらも正常です。CapEff が 0 でないなら、--user 0 などを付けて起動しています。

報告先は こちら。
